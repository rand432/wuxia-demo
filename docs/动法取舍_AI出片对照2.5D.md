# 两种动法的取舍（AI 出片 vs 本地 2.5D）

> 2026-09-27 记。**两套都已跑通，可以混用。**

## 各自的成品

| | **2.5D（已出成片）** | **AI 图生视频** |
|---|---|---|
| 手段 | ffmpeg zoompan，程序算 | LibTV Wan 3.0，图生视频 |
| 输出 | `export/开场_成片.mp4`（100 秒全片） | `assets/gen/aivideo/*.mp4`（逐镜） |
| 单价 | **0 元** | 按秒计费（会员 1500 积分/月） |
| 人物会不会"演" | ❌ 不会，只有镜头在动 | ✅ **会**（坠落时会翻滚、会转身） |
| 会不会"化" | ✅ 绝不，画面 100% 是原图 | ⚠️ 5 秒内动作大了会形变 |
| 可控性 | ✅ 参数写死，改一行就改 | ⚠️ 抽卡，失败退分 |
| 速度 | ✅ 全片 17 段几分钟 | ⚠️ 每镜 1–2 分钟 |

## 建议的混用方式

- **需要"人真的在动"的镜**（08 坠落、07b 混战、11 走远、05 拂袖）→ **AI 出片**
- **靠镜头呼吸就够的镜**（01 墨入水、03 碰杯、07f 一刀光、07g 雨空镜、09 没死）→ **2.5D 更稳更省**
- **接不上时**：把 AI 出的片段再拿去做 2.5D 的推拉，两头的好处都吃到

## 本次实测记录

- **08 坠崖**（AI）：镜头自崖顶下摇跟坠，他翻滚着变小，崖与三张面具往上退 —— **效果远超 2.5D 版**
- **07f 一刀光**（AI）：2 秒，3.1 MB
- **11 江湖新客**（AI，早先测试）：背影沿墨痕往前走，雾在飘 —— 但那是旧关键帧，需重出
