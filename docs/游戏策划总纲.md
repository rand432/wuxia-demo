## 一、核心循环

### 1.1 一小时循环

- 出村清缴：选关 → 自动战斗 → 拿银两/经验/宝箱；每清 1 关给 1 个宝箱。
- 一手 0.72 秒（STEP），快进 1× → 2× → 4×（SPEED_STEPS，代码：menu/battle_lite.gd）。
- 游历一趟＝21~41 节；每节办完正事可赶路，也可翻容器搜刮。
- 挂机池在线累积，上限 8 小时（IDLE_CAP_SEC = 28800 秒）。
- 炼丹：一炉 4~20 分钟（按品级），同类型多颗时间 ×N×0.8。

### 1.2 一天循环

- 换日点＝凌晨 4:00（DAY_RESET_HOUR = 4）；0~4 点算前一天。
- 货栈每日限购：凡品残卡 10/种 · 良品残卡 5/种 · 血脉囊 1 · 突破丹凡 3 / 良 2 · 金髓 1 · 鉴宝道具 1~3/件。
- 品酒坊每日限酿 5 坛（WINE_BREW_LIMIT = 5，账存 user://wine.cfg）。
- 挂机池攒满 1 次收取（银两 / 木料 / 经验 / 阅历同一口收）。

### 1.3 长线目标

| 线 | 终点 | 关键闸 |
|---|---|---|
| 等级 | 1000 级 | 每 25 级一次突破，共 39 次 |
| 境界 | 40 重（初出茅庐 … 道法自然） | 突破丹：39 次共 603 颗/人 |
| 爬塔 | 20000 关 | 首领赏四品级各发完一轮 |
| 游历 | 10 档首通 | 前一档清了才开下一档 |
| 器物 | 五星（每星 +20%） | 满星累计 31 只同名 |
| 角色星 | 六星 | 满星 1260 碎片 ＋ 6300 两 |
| 阅历 | 4 支 × 32 段 | 单支 阅历 17,820 ＋ 银两 21,978 |

## 二、战斗

### 2.1 两套引擎与输入方式

| 引擎 | 文件 | 场合 | 输入 | 运签卡 | 倍速 |
|---|---|---|---|---|---|
| battle_lite | menu/battle_lite.gd | 村内爬塔 / 清缴 | 全自动，只能按［快进］ | 不吃 | 1× / 2× / 4× |
| duel_battle | journey/duel_battle.gd | 游历决斗 | 手动出牌（点选或上划发动）或自动 | 吃 | 1× / 2× |

- 两边的小人共用 journey/stick_fighter.gd（火柴人 ＋ 姿态弹簧 ＋ 位移补间队列）。
- 游历普攻接招式表：MOVE_ANIM = true · MOVE_SPEED = 1.8（代码：journey/duel_battle.gd）。
- 塔战没接招式表，用自带 _lunge（x 轴补间 0.10 / 0.18 秒）。

### 2.2 出手与回合

- 一轮 ＝ 全员各出一次手。
- 一手 STEP = 0.72 秒（tuning.cfg 的 combat.step 可覆盖）。
- 出手顺序按速度排序；速度设计量级 **10 ＝ 常人**。
- 村内三人底子 9 / 10 / 12；塔战怪 9~28；游历敌人表写 88~110，引擎先 ÷10 折回（代码：duel_battle.gd _foe_spd）。
- 快过对手 ≥2 倍：每手多打 floor(比值)−1 下**普攻**，封顶 2 下（ATKSPD_MIN_RATIO = 2.0 · ATKSPD_MAX_EXTRA = 2）。
- 武学与大招不吃这条攻速规则（各有冷却与怒气管）。
- 塔战倍速三档 [1.0, 2.0, 4.0]；游历两档 [1.0, 2.0]。

### 2.3 伤害结算

五层结构（谁和谁相加、谁和谁相乘）：

| 层 | 谁 | 怎么合 |
|---|---|---|
| 基础层 | 升级 / 突破 直接写进 role.stats | 相加 |
| 件层 | 兵器 / 护甲 / 玉佩 / 披风 / 武学的 item_stats | 每件先按自己那把的星 ×(1+0.2×星)，再逐件相加 |
| 全队层 | 宠物护主%（气血）/ 青隼%（速度）、羁绊 pct_all ＋ flat | 宠物单独一层乘；羁绊先乘百分比、再加平面值 |
| 战斗层 tfx | 五问天赋 ＋ 角色星 stat ＋ 专武常驻 fx | 同键相加成一个桶 |
| 出手乘区 | 招式倍率 / DMG_MUL / 暴击 / 攻防对拼 / 护体 / 加持 / 自带增伤 | 逐层相乘 |

- 普攻倍率 DMG_MUL = 2.0；大招基准 ULT_MUL = 2.5。
- 暴击是真属性：倍率 ＝ 1.0 ＋ 暴伤/100；默认暴伤 50 → **1.5 倍**。
- 「伤害加成 dmg」是加成一个数、只乘一次：装备 +20% 与角色星 +8% ⇒ +28%。
- 暴伤同理相加；只有角色星「凝息」crit_mul_up 是乘。
- 攻防对拼：挡掉比例 ＝ 防 ÷（攻 ＋ 防），封顶 DEF_CUT_CAP = 0.75。
- 闪避率 ＝ 闪避 ÷（闪避 ＋ 对手命中），对手命中 ＝ 100 ＋ 对手速度×2，封顶 DODGE_CAP = 0.45。
- 减伤（护体 × 加持 × 残血）**相乘不相加**；加持与专武大招减伤取最大值。
- 元素通道：base × 0.8 ×（1 ＋（全伤害 ＋ 该元素伤害）/100）×（1 − 抗性）；**不吃防御、不掷暴击**。
- 抗性封顶 +75% / −60%（RES_CAP / RES_FLOOR）。
- 护体类减伤（cut 值）：铁布衫 22% · 金钟罩 25% · 金刚不坏 27% · 玄武神功 32%。
- 加持类减伤：坚壁旗令 15% · 铁壁合围 20% · 同心结阵 9%。
- 反刺基数按自身气血上限 8%~12%（THORN_HP_LO / THORN_HP_HI，代码：menu/battle_lite.gd）。
- 词缀反伤 12%，一次封顶挨打者上限的 10%（T_THORN_PCT / T_THORN_CAP）。

### 2.4 怒气与大招

- 怒气上限 100；满 100 时本手放大招，放完清零。
- 每手涨 RAGE_GAIN 34 × RAGE_MUL 0.7 ≈ **23.8**；引气归元再 ×1.3。
- 三条大招机制：

| 角色 | 大招 | 形态 | 数值 |
|---|---|---|---|
| 少侠 | 长风破浪 | hit 瞬发 | 对手 >1 人横扫各 ×1.7；只剩 1 人转单体重击 ×2.8 |
| 陈石 | 回马断枪 | aura 持续 | 3 手 · 每手回 8% 气血 · 窗口内挨打反刺 |
| 苏青鸾 | 青鸾出岫 | song 追击 | 先取后排 3 段各 ×0.8；此后 3 手每次暴击追一剑六成力 |

- 剑歌窗口内她自己暴击 +15 个百分点（SONG_CRIT_UP，两套引擎同数）。
- 追剑可暴击但**不连锁**：SONG_CHAIN_MAX = 1（代码：duel_battle.gd / battle_lite.gd）。
- 苏青鸾大招三段取后排，普攻 / 武学 / 大招各段的暴击照追。

### 3.2 等级与境界

- 等级上限 LEVEL_MAX = 1000；每 BREAK_STEP = 25 级一道关，共 BREAK_MAX = 39 次突破。
- 每级只涨气血 LEVEL_GROWTH = {hp: 1, atk: 0} → 1000 级 ＋999 气血（代码：game_state.gd）。

### 3.4 角色星

### 10.4 版本迁移

- save.cfg 版本 SAVE_VER = 2，可迁移最老 SAVE_VER_MIN = 1。
- 比本程序新的档改名 save.cfg.vN.bak 留档，绝不静默丢。
- run.cfg 版本 VER = 1，VER_MIN = 1。
- 读档时按模板整块刷正角色的被动 / 大招 / 自带（_sync_role_kit / _sync_role_innate），改表即对老档生效。
- 成长补课（grow_sync）：根骨或成长类一变，已过的级数一次补齐，结账口在读档与升星等处。
- 回村后台估算 auto_bg 不存档，重启回到屏幕内连打。

### 10.5 探针与体检

- 五个静态体检脚本（放在 %TEMP%，不在仓库里）：gdchk.js（结构）· chkapi.js（跨文件接口）· chkcards.js（卡表自洽）· chkarts.js（武学/专武/角色星单位）· chkexcl.js（专属卡归属）。
- 仓库根另有 probe_map.gd / probe_map2.gd 两个无头探针入口。
- 只读探针口径：跑完存档 MD5 前后一致。
- 无头探针只能验「数据与接线」（哪几条、什么字、什么色、位置、显隐）；像素外观要人工进游戏看。
