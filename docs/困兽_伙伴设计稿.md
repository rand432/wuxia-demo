# 困兽 v2 · 伙伴设计稿

> **v4s 改动**：**暗影裁决 由【上品】降为【下品】并削弱**（用户："暗影调整为下品 适当削弱"）——
> 冷却 **20 → 25 秒**、杀敌生命 **+2 → +1**（每层强化 **+0.5**）。这样它跟另两位下品
> （独眼彪·杀气 +1 攻击／枯荣·纳气 +3% 内力）站在同一条线上。
>
> **v4t 改动**：**陈石 由【下品】升为【中品】并略微加强**（用户："陈石改为中 略微加强"）——
> 反伤 **2% → 2.5% 生命上限**（每层仍 +0.5%，满层 **4%**）、冷却 **20 → 17 秒**、持续 **8 → 9 秒**；
> 同时**伙伴页按品质配色**：**绝品（赤金）＞ 极品（金）＞ 上品（紫）＞ 中品（青）＞ 下品（灰）**，
> 边框粗细也跟着分（绝/极/上 3px，中/下 2px）。

> 用户口径（v4a，已落地）：
> - **基础剑法＝物理伤害**；
> - **暗影裁决【上品】** 技能「**肝**」：持续时间内杀敌，**生命值上限 +2**；耗内力 **100** · 持续 **5s** · 冷却 **20s**
>   可选：**-冷却【提升内力消耗】／+持续【提升内力消耗】／+杀敌生命【提升内力消耗】／-内力消耗**
> - **陈石【下品】** 技能「**刺骨**」：持续时间内被攻击时，对**攻击自己的一名敌人**造成**生命值 2% 的真实伤害**；
>   耗内力 **100** · 持续 **8s** · 冷却 **20s**
>   可选：**-冷却【提升内力消耗】／+持续【提升内力消耗】／+反伤伤害【内力消耗】／-内力消耗／+反伤敌人数量**
> - 先**不做成长／继承**（招募与继承留到第 5 步）。

## 一、规则（怎么放、怎么算）

- **自动释放**：战斗是自动打的，所以"内力够 ＋ 不在冷却"就放，飘一行紫字（肝！／刺骨！）＋ 音效 `skill`；
- **内力**：每秒回 **2**（跟角色页写的一致）；伙伴技能**共用主角这一管内力**；
- **"提升内力消耗"是强化项自带的代价**（用户用【】标出来的）：
  每个"加效果"的层 **+20 内力**，"减内力消耗"每层 **−15**，下限 **40**；
- 冷却/持续/效果都**现算**（`p_mp() / p_cd() / p_dur() / p_kill_hp() / p_thorns() / p_thorn_targets()`），
  改一项不用到处同步。

## 二、两位伙伴的现算数值

| | 暗影裁决【上品】· 肝 | 陈石【下品】· 刺骨 |
|---|---|---|
| 基础 | 内力 100 · 持续 5s · 冷却 20s | 内力 100 · 持续 8s · 冷却 20s |
| 效果 | 持续期间**每杀一只**：生命上限 **+2**（并回同样多的血）| 持续期间**每次挨打**：对攻击者造成 **生命上限 ×2%** 的**真实伤害**（无视防御）|
| 减冷却 | 每层 −3 秒（内力 +20）| 每层 −3 秒（内力 +20）|
| 加持续 | 每层 +2 秒（内力 +20）| 每层 +2 秒（内力 +20）|
| 专属强化 | **杀敌生命** 每层 +1（内力 +20）| **加反伤** 每层 +0.5% 生命上限（内力 +20）|
| | | **反伤敌人** 每层 +1 名（内力 +20）|
| 减内力 | 每层 −15（效果不变）| 每层 −15（效果不变）|

上限：减冷却/加持续/杀敌生命/加反伤/反伤敌人 各 **3 层**，减内力 **3 层**。

## 三、强化项进"升级三选一"

伙伴的强化项**跟主角的招式强化同一个池子**（`SKILL_POOL`），
标记 `req_p` 表示"得先有这位伙伴"；`roll_choices()` 会按 `req_p` 过滤，
`skill_lv()` 同时认得主角项与伙伴项（⚠ 别直接查 `skill` 字典——伙伴的档位不在里面，
直接下标会 `Invalid access to property or key` 并把整次抽取打断）。

## 四、界面

- **角色页 → 伙伴页**（`_fill_mates`）：每位一行卡片——
  名字 ＋**【品质】**（上品紫框／下品灰框）＋ 技能名 ＋ **内力/持续/冷却** ＋ 效果说明 ＋ **档位一览**；
  右上角一个**实时状态**（释放中 / 冷却 Ns / 待机），战斗里放没放一眼看到；
- **基础剑法＝物理伤害**写在角色页脚注；
- 旧版"假队友页"改名 `_fill_mates_old` 留着当参照，不再挂到界面上。

## 五、黑市（v4b/v4c）

- **入口**：右缘圆钮列表最下面一颗（**存档 / 成就 / 黑市**）；
- **钱**：**杀敌数**（`_kills` 自己累加，不再每帧从战场回读——它是可花的钱）；
- 现有货架（**内容暂定**）：文钱 ×200〔50 杀〕· 灵晶 ×10〔200 杀〕· 装备一件〔300 杀〕·
  宝物一件〔400 杀〕· 回满气血〔120 杀〕；买得起是红框红钮、买不起灰掉；
- 换到的东西**像掉落一样飞进对应计数位**（文钱/灵晶→右上 · 装备/宝物→右下）；
- **黑市钮正下方**：一条**小型经验条 ＋ 等级**——**这是黑市自己的等级**（v4d 用户口径）：
  - **每次击杀 1 名敌人 → 黑市经验 +1**；
  - 攒够就升级：`Lv1 要 100`，之后每级 **+50**（100 → 150 → 200 …）；**升级送 1 次刷新**；
  - **每 180 秒自动 +1 次「刷新次数」**（`BM_REFRESH_SEC = 180`），升级也送 1 次；
  - 条子写着 `黑市 Lv N　刷新 M`，条宽按"当前经验/升级所需"走（紫色，跟角色那条蓝的分开）；
- **黑市页顶部**：`杀敌数` ＋ 一行朱红 `黑市 Lv / 经验 / 刷新次数`，下面一行小字说明这两条规则。

**实测**：起始 Lv1 · 0/100 · 刷新 1 → 灌 250 次击杀后 **Lv3 · 0/200 · 刷新 3**（两级各送 1 次）
→ 计时器顶到 180 秒后 **刷新 4** ✓。截图：`.shots/zb1_black_exp.png`。

## 五·五、苏青鸾【极品】技能「飞匕」（v4f/v4i）

**每隔 8 秒生成一枚飞匕，命中最近的敌人**（用户口径）。三项机制各自一本"伤害账"：

| 机制 | 伤害来源 | 说明 |
|---|---|---|
| **飞匕**（首击） | **飞匕伤害** ×0.80 | 基础那一下 |
| **穿透** | **飞匕伤害**（同一本账） | 多穿 1 名/层，穿过时留一道寒光 |
| **弹射** | **弹射伤害** ×0.60 | 命中后拐向下一个敌人，**换成弹射那本账** |
| **多重** | **多重伤害** ×0.80 | 一次多出 1 枚/层，**多出来的那几枚吃多重伤害** |

> **三条账都是物理伤害**（用户："但是都是物理伤害 只不过伤害比例不同"）——
> 都走 `_apply_dmg(..., DMG_PHYS)`，也就是**都吃防御**，只是倍率各算各的。

强化项（都在升级三选一里，标 `req_p = suqingluan`，各 3 层）：
**+穿透** · **+飞匕伤害**(+25%/层) · **+弹射** · **+弹射伤害**(+25%/层) ·
**+多重** · **+多重伤害**(+25%/层) · **-秒数**(−1 秒/层，8→5)。

实测：初始 飞匕×0.8 / 弹射×0.6 / 多重×0.8（1 枚）；各 +2 层后
**飞匕×1.2 / 弹射×0.9 / 多重×1.2（3 枚，穿透 2，弹射 2，间隔 6 秒）**——三条账互不串味。

## 五·五·二、张道陵【绝品】技能「天雷道术」（v4j）

**落下一道天雷砸在最近的敌人身上，范围内一起吃金系伤害**；耗内力 **300** · 冷却 **10s**（用户口径）。

- **范围**：`tl_radius() = 110 + 22×层`——110 像素≈"两个人身位"（简笔小人一人约 50 宽）；
- **金系伤害是新的一类**：`DMG_METAL`——**兵器防御对它无效**（跟物理区分开）；
  给怪留了 `res_metal`（金抗）的乘位，现在默认 0；
- **麻痹**：命中时按几率给怪挂 `para` 秒数——**这段时间它不动、也不打**，头顶跳两下电花；
- **多重施法**：按几率**再落一道**，那道用**另一个伤害比例**（0.60 起，也是金系）。

| 强化项（各 3 层） | 效果 | 代价 |
|---|---|---|
| 天雷·伤害 | +25%/层 | 内力 +30/层 |
| 天雷·范围 | +22 像素/层 | 内力 +30/层 |
| 天雷·麻痹几率 | +10%/层（20% 起）| 内力 +30/层 |
| 天雷·麻痹时长 | +1 秒/层（1 秒起）| 内力 +30/层 |
| 天雷·多重施法 | 额外释放几率 +15%/层（25% 起）| 内力 +30/层 |
| 天雷·多重伤害 | 那一下 +25%/层 | — |
| 天雷·减内力 | −25/层（下限 120）| — |
| 天雷·减冷却 | −1.5 秒/层（下限 3 秒）| — |

**实测**：初始 伤害×1.6 · 范围 110 · 麻痹 20%/1.0 秒 · 多重 25%/×0.6 · 内力 300 · 冷却 10.0
→ 各 +2 层后 **伤害×2.4 · 范围 154 · 麻痹 40%/3.0 秒 · 多重 55%/×0.9 · 内力 610 · 冷却 7.0**；
一次施放实测 **雷柱 2 道、麻痹 2 只**。

**连带改动（重要）**：内力池原来只有 100，**根本放不出 300 内力这一发**——
现在 `mp_max = 300 + 25×等级`、**每秒回 10**；底部内力条显示真实值。
⚠ 如果你把"会+内力"的强化全点到满，消耗会涨到 610，低等级时**放不出来**（这是取舍，不是 bug）。

## 五·五·四、崔三娘【绝品】雾海龙王（v4l）——**召唤物**这一套

- **纳气**：琥珀——脚下一圈**旋转暖环** ＋ 六道**气丝往身上收**（方向跟"肝"的"往上飘"正好相反，
  一眼分得开）；飘字 **"内力上限 +6"**（琥珀）。
- 两套合起来是"**红环在外、暖环在内 + 粒子方向相反**"，即使同时开着也认得出谁是谁。

**实测**：初始 杀气 攻击+1.0/只 · 冷却 25 · 持续 5 · 内力 100；纳气 内力+3/只
→ 各 +1 层后 **杀气 攻击+1.5 · 持续 7 · 内力 145**／**纳气 内力+6 · 持续 7 · 内力 145**；
灌 5 只人头：**攻击 30 → 37**、**内力上限 450 → 480**（数值与飘字都对得上）。

## 五·五·六、法度【中品】怒目金刚（v4o~v4r）＋ 纳气改成百分比

**法度·怒目金刚**：给自己套一层**护盾**（先扣盾、再扣血）；护盾**被击破**时，对**周围一圈**造成
**等于护盾值的土系范围伤害**。基础：护盾 **40% 生命上限** · 持续 **8 秒** · 冷却 **20 秒** · 内力 **150**。

| 强化项（各 3 层）| 效果 | 代价 |
|---|---|---|
| 怒目·护盾值 | +15% 生命上限/层（40% → 85%）| 内力 +20/层 |
| 怒目·破盾伤害 | 破盾那一下 +25%/层（×1.0 → ×1.75）| 内力 +20/层 |
| **怒目·层段** | 护盾**每掉 10%** 就震荡一次，造成"护盾值的 **10%×层**"的土系**范围**伤害 | 内力 +20/层 |
| **怒目·范围** | 震荡半径 +25 像素/层（150 → 225）——**只有法度有这条**（用户："我单指的法度有范围"）| 内力 +20/层 |
| 怒目·持续 | +2 秒/层 | 内力 +20/层 |
| 怒目·减冷却 | −3 秒/层（20 → 11）| — |
| 怒目·减内力 | −15/层 | — |

**范围口径（v4p/v4r 澄清）**：**天雷·范围** 与 **龙王·技能范围**是原本就有的（保留不动）；
**法度·范围**是新增的；其余伙伴（刺骨/飞匕/回春/怒火）**不加范围**（用户："其他照旧"）。

**纳气改成百分比（v4r）**：每杀一只从"+3 固定内力上限"改成"**+3% 原本内力**"（每层 +3%，满层 12%），
涨的是**开局那管内力**（`_mp_base`）的百分比——不滚雪球；飘字也写明 `内力上限 +13（3%）`。

**实测**：护盾 152 → 各 +1 层后 **209**；破盾 ×1.0 → **×1.25**；层段 0 → **10%**；范围 150 → **175**；
持续 8 → **10**；冷却 20 → **17**；内力 150 → **255**。扣掉 45% 触发 **1 次震荡**，
打碎时合计 **3 圈震荡**（含那一记大圈）✓
