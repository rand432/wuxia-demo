## 三、踩过的坑（v213）

1. **`PET_STAR_MAX = 5`，不是 6**（game_state 里写死 5）——品质环一开始画了 6 个星位，对不上账；已改 5。
2. `PetArt` 是内嵌类：`const Ui := preload(...)` **要写在类里面**，不能直接用外层的 `Ui`。
3. 面板加高到 1150 后 top = 65；720×1280 下上下各留 65，够用。
4. 三环画在宠物**之前**（背景层），宠物盖住环心，才有"坐在法阵里"的感觉；环别画在宠物之后。
5. 状态环的虚线是 36 段隔一段画一段，别用 `draw_arc` 一次画半圈——接缝会歪。
