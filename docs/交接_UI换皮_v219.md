## 〇、一句话现状

### 品酒坊 · 斟酒
- 酒壶**缓出端进来 / 缓出撤走**（前 0.18、后 0.14），不再"啪"一下出现又消失。
- 酒流两端收细、渐显渐隐，另加一道高光；杯口有**溅点**与**涟漪**。
- 杯面涨酒改**缓出**（先快后慢），涨的过程有一圈淡环化开。
- 被斟的客人会**往前探一点**；喝完轻轻一顶（0.42 秒的 sin 弹一下）。
- 评语星星**从 1.35 弹回 1.0**（0.36s TRANS_BACK）。

### 鉴宝行 · 开仓揭格
- 买下货仓的弹窗**入场**：0.18s scale 0.965→1 + alpha（和别处面板同一手感）。
- 每件货显形时：scale 0.62→1 带 **5.5% 过冲**，alpha 0.2→1 渐显（原来只有 scale，且从左上角长——pivot 已居中）。

### 炼丹阁 · 炉火
- 炉位进度条重画从 **0.5s → 0.1s**（原来肉眼一格一格蹦）。
- 炉台从"一条 584×92 的宽黑带"改成 **360×140 的居中炉龛**：
  - 三层火苗 + 底光 + 火星（炼制中更多）+ 烟；
  - 丹成时丹丸从炉口升起 + 金环；
  - **起炉/丹成的一圈光**（0.65s 扩散环）；
  - 看火人保留，位置随炉龛重排。
- 丹方弹窗**入场**：0.18s scale + alpha。

## 三、踩过的坑（v219）

1. **别用"读 42 行"当函数边界**：品酒 `_draw_pour` 替换时 offset 读早了几行，把 `_draw_jar` 的后半截一起切了；
   炼丹 `FurnaceScene._draw` 替换时又把类后面的 `var _panel: Panel` / `var _scene` 带走了。
   **改大函数前先确认起止行**（函数头 + 最后一个 `return`/闭合），改完立刻 `--check-only` 该文件。
2. `--check-only` **不报未声明标识符**？这次报了（`_panel`），但有几次只报在探针日志里；
   大改动后**单独 check 被改的文件**，不要只 check `menu_sketch.gd`。
3. `FurnaceScene` 是 Node2D：`Ui.panel` 能用，但**卡片尺寸是画死的**（原来 584×92），改尺寸要同步改所有 y 坐标与下方看火区的位置。
4. 进度条 0.5s 刷新是"看着卡"的根因；10Hz 就够顺，且不会造成明显重建开销。
