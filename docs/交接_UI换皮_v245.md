## 三、踩过的坑（v245）

1. `draw_string` 原来写死 `ThemeDB.fallback_font`，跟纸面标题的 ink 字体不一致；画布绘制也要单独换。
2. 禁用态"墨底"如果 alpha 只有 0.38，压在纸上会变半透明灰；要 **0.88** 才是墨底。
3. 雾区原来只画深色圆，玩家看不出边界；加 `draw_arc` 金环和中心字，既有边界又有提示。
4. 江湖图的按钮是透明命中区，视觉全靠 `_draw_region`；改颜色/字体不会影响点击。
