## 8 · 对「困兽」可直接照抄的六条

1. **六部位 + 双色词条**：部位（武器/吊坠/引擎/徽章/指环/虚步）× 词条色（绿/蓝/紫）→ 天然的"装备广度×深度"矩阵，和困兽的奇物槽位能一一映射。
2. **品质阶梯当物品技能载体**：B/A/S/SS/SSS/神话 每一档配一条"物品技能"，品质不只是数值、而是玩法。
3. **吞噬位**：给重复掉落一个收敛口，同时用"格子数"做付费/成长上限 —— 比直接金币回收更有决策感。
4. **神赋六阶命名**（下→中→上→超→圣→命）：一套现成的 run 内天赋树命名与递进语感，可直接借用来命名困兽的"请神"层级。
5. **颜色天赋池**（绿/蓝/紫/橙/红）：卡池稀有度用颜色而非文字，UI 成本最低。
6. **难度线性乘区**（"+1X难度"）：所有成长数值统一乘难度系数，避免逐条调表 —— 与困兽的"关卡画卷"难度档位可对齐。
