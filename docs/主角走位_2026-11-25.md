# 主角走位：居中偏下（2026-11-25）

> 用户："战斗界面的主角还是很容易跑上面去 我想尽量在居中战斗" → "再下一点 相当于整个界面中等偏下"
> 改动文件：`kushou/kushou_battle.gd`（常量、停距；未改战斗逻辑）

## 问题

1. 主角自动追击天花板只有战场 10%，怪从上面下来时会一路跟到最上沿，屏幕下半空着。
2. 追击范围 260 太大，刚出生的远怪也会去追，交战点被一路顶到上半屏。
3. 弓手/法师停距 146~176、盾兵 96~116、挑战大怪 126~146、冠军 86，
   都超过主角攻击圈（`HERO_REACH+10 = 84`）——主角被天花板卡住时会站在攻击距离外，
   表现成"站着不打"。

## 规则（现行）

| 项 | 值 | 说明 |
|---|---|---|
| 战场高 | 720 | 主角"家" = `HERO_MID=0.80`（y=576，界面中等偏下） |
| 自动追击天花板 | `HERO_TOP=0.72`（y=518） | 自动状态最高到 y=518；手动点地走位不受限 |
| 自动追击范围 | `HERO_AGGRO=200` | 提前迈步接怪，但天花板卡住爬升量（最多 58px） |
| 怪停距上限 | **≤ 84**（主角攻击圈） | 保证主角卡在天花板时也够得到，不会站着不打 |
| 石像类目标 | 天花板放开到 0.28 | 集火站桩目标时允许走到 y≈202，否则够不到 |

## 关于"主角不攻击"（已排查）

两个原因，都已处理或说明：

1. **教学弹窗会暂停战斗**：`_tutorial_pause(true)` 会把外壳与核心的 `_process` 一起关掉，
   直到点目标或「跳过」才恢复。这是既有设计（让玩家读完再打），不是走位问题。
2. **卡距离**：主角被天花板卡住、而怪的停距 >84 时会站在攻击圈外不动——已通过
   "所有怪停距 ≤84" 修掉。
