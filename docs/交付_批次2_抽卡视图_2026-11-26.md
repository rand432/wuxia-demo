- `DrawView.build(charge_text)`：构建一次；`cards` 为 3 个卡控件，`refresh_btn` 暴露给战斗层改文案
- 信号：`card_picked(card)` / `refresh_pressed` / `hide_pressed`
- 方法：`open()` / `close()` / `pop_cards()` / `fly_card(card, target_local, done)` / `fade_cards_out()`
- `var _draw_view: DrawView` 新成员；`_draw_layer` 仍指向视图本身（审计按 `_draw_layer.visible` 判断，保持兼容）
- 卡牌控件类 `DrawCard` **暂留 battle_ui**，由 `card_factory` 注入（后续可单独搬迁）
