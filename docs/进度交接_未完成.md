### 9.3 四条铁律（踩坑踩出来的，别再犯）

1. **草图自己得先是"画"，不能是"示意图"** —— 模型会照描。给几何图形就得到几何图形。
2. **denoise 分档**：构图要精确的（器物/手）用 **0.5–0.6**；要模型发挥的（大场景）用 **0.7**。
3. **主角一致性靠"定版图 + 程序合成"**（`00_主角定版.png` → `tools/composite_crowd.mjs` 贴进草图），不能只靠提示词。
4. **以物代事**：不拍事件，拍事件的**痕迹**（手、酒渍、门缝、一只脚）。
