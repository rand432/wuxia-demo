## 二、通用规格（所有立绘）

| 项 | 要求 |
|---|---|
| 尺寸 | **1080×1920**（或 720×1280），竖构图 |
| 背景 | **透明 PNG 优先**；不行就纯米黄 `#F0E8D8` |
| 构图 | 人物**居中**；头顶留白 ~8%、脚下留白 ~6% |
| **左侧安全区** | 左边 **1/6 宽度**不要放重要内容（游戏里那里叠竖排名牌） |
| **右下安全区** | 右下角 **120×120** 留空（叠品质章） |
| 内容 | **不要文字、水印、边框、UI** |
| 画风 | 国风水墨 + 淡彩：宣纸质感、笔触边缘带墨晕、留白多、细墨线勾轮廓 |
| 色调 | 宣纸米黄打底，墨黑主色，**只用一个点缀色**（见上表） |
| 打光 | 柔和侧光，不要强高光、不要 3D 塑料感 |
| 不要 | 不要欧美厚涂、不要二次元大眼、不要照片写实 |

### 统一风格前缀（每条 prompt 都加）

```
Chinese ink wash painting, xuan paper texture, wuxia, full body character,
soft light, single accent color, fine ink outline, lots of negative space,
transparent background, no text, no watermark, vertical composition
```

## 三、动态版规格（可选）

如果你要做"会呼吸的立绘"：

| 项 | 要求 |
|---|---|
| 时长 | **3~5 秒无缝循环**（首尾帧必须一致） |
| 帧率 | 24 fps |
| 尺寸 | 同立绘，1080×1920 |
| 改动幅度 | **极轻微**：呼吸（胸腹起伏 1~2%）、衣摆/发丝轻飘、灯焰摇曳、眼神微动 |
| 禁止 | 禁止位移、转场、镜头运动、人物转身、表情大变 |
| 输出 | mp4 / webm / 序列帧都行（我会转成 Godot 能用的格式） |

**动态版 prompt 追加**：

```
subtle looping idle animation, gentle breathing, cloth and hair swaying slightly,
seamless loop, first and last frame identical, no camera movement
```

## 七、最容易翻车的四点

1. **透明底**：AI 常给白底或纯黑底 —— 白底还能抠，黑底会毁掉水墨边缘
2. **安全区**：左边 1/6 和右下角会被 UI 盖住，重要内容（脸、手、武器）别放那儿
3. **风格漂移**：11 张必须同一个模型同一段前缀，否则像拼的
4. **动态幅度**：做太大会显得像"鬼畜"，只做呼吸和衣摆就够
