# 十关教学关 · 设计原则

> 2026-11-12 定稿。十关之内是教学弧，十关之后才是正常局。

## 一、核心四句

1. **数值给引导让路**：教学关的怪、收益、难度都可以为“让玩家学会这件事”服务；教学完成后回正常。
2. **根据痛点勾引操作**：不写教程、不弹说明、不教玩家；用资源短缺、怪变多、打不动等压力，让玩家自己去找新功能。
3. **暗调怪物或其他方面**：不改玩家能直接看到的面板，用隐藏易伤、隐藏权重、隐藏收益等方式，制造“用了新功能就变强”的感受。
4. **爽感 / 反馈感**：玩家第一次用新功能，要立刻看到/听到/感到结果；没有反馈的教学等于没教。

## 二、十关的痛点 → 操作

| 关卡 | 新功能 | 痛点 | 暗调 / 引导 |
|---|---|---|---|
| 1 | 强化 / 进阶 / 玉壶 | 第一波后强制暂停；第二波开始吃力 | 第一关特殊曲线；文钱 ×1.8 |
| 2 | 抽卡 / 成长线 | 不成组时怪更硬 | 怪隐藏易伤随组合数提高；击杀 +灵晶 |
| 3 | 宝物 / 经济线 | 灵晶不够用 | 经济线卡组进池；宝物给资源 |
| 4 | 奇遇 / 挑战 / 危途 | 怪少、收益不够 | 危途增怪；挑战怪更强但收益更高 |
| 5 | 请神 / 家传 | 构筑缺质变 | 新请神角色家传卡隐藏权重 |
| 6 | 黑市 / 高级 | 数值上限不够 | 黑市装备；高级卡进池 |
| 7 | 特级 / 装备材料 | 关卡变硬 | 首通给文钱 + 技能材料 |
| 8 | 装备 / 锻造 | 打不动 | 首通装备 + 锻造材料 |
| 9 | 角色进阶 | 家传不够强 | 首通角色进阶 |
| 10 | 新奇物 / 新卡组 | 收尾 | 首通新奇物；Boss 给固定新卡组 |

## 三、暗调清单（不能出现在 UI）

- 第二关：combos × 15% 隐藏易伤，封顶 45%。
- 新请神角色：家传卡临时隐藏权重，让玩家先体验到。
- 第一关：四步教学未完成时的隐藏血量曲线；完成后自动回正常。
- 一切“数值给引导让路”的临时倍率，都必须在教学完成后失效。

## 四、反馈感

- 合成组合：立刻冒字、变色、出特效、伤害数字跳一截。
- 抽到关键卡：卡面/音效/高亮，不能静默进卡组。
- 新按钮第一次：暗屏 + 高亮 + 一行字，点完才继续。
- 暗调生效时：不给数字，只让玩家感觉“这波打得顺/不顺”。
