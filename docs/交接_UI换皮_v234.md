## 〇、一句话现状

- 主界面环境音从"永远刮风"改成：
  - **夏（season == 1）**：`rain`，-25dB；
  - 春/秋/冬：`wind`，-27dB。
- 统一由 `_sync_ambient()` 管：`_start_ambient()`、`_init_season()`、每 30 秒换季、测试键 **N** 都会调它。
- `Audio.play_ambient` 换 key 时会停旧建新；同一 key 直接返回，不会重头播。

## 三、踩过的坑（v234）

1. `_start_ambient()` 是 deferred 的，季节在 `_init_season()` 里才定；所以 `_init_season` 末尾也要调一次 `_sync_ambient()`，否则开局可能先放错。
2. 不要同时叠 wind + rain；`play_ambient` 只有一个通道，换 key 会停旧的——这就是想要的"同时只有一种天气"。
3. 雨声 -25dB 略高于风 -27dB；嫌吵可统一到 -28dB。
