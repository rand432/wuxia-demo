## 〇、一句话现状

- `menu_mist.gd` 在 **season == 1（夏）** 时生成 **26 条斜雨线**：
  - 速度 380~680 px/s，向右下斜落（x 也随速度漂 22%）；
  - 长度 14~30px，宽 1.2，颜色 `0.84/0.89/0.96`，alpha 0.08~0.16；
  - 落到画心底/右缘外就回顶部重来。
- 雨线画在**雾与金尘之后**，压在它们上面；仍受画心 `clip_contents` 裁切，不会漏到桌面。
- 换季时 `_rebuild_parts()` 会 **clear `_rain`**，所以只有夏季有雨。

## 三、踩过的坑（v233）

1. 雨线 alpha 太高会像"划痕"；0.08~0.16 在墨画上刚好是"细雨"。
2. 雨线要画在雾和金尘**之后**；画在雾之前会被雾糊掉。
3. 换季必须 `_rain.clear()`，否则从夏切到别的季，旧雨线还会继续落。
4. 雨线的 x 漂移跟速度绑定（0.22×），不是随机横风；这样斜度看起来一致。
