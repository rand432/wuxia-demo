## 〇、一句话现状

- `Audio` 新增 **循环环境音通道**：
  - `Audio.play_ambient("wind", -27.0)`：Ogg 开 `loop`，挂到 root，跨场景不回收；
  - `Audio.stop_ambient()`：停掉并 `queue_free`。
- 主界面 `_ready` 里 **延后一帧**起风（`_start_ambient.call_deferred()`）；
  离开主界面（`_exit_tree`，进游历/战斗/换场）自动停。
- 音量 -27dB，再乘玩家音效音量；很轻，不会盖 BGM。
- 目前只挂了 **wind**（村景/主界面）；雨/季节音还没接。

## 三、踩过的坑（v230）

1. **直接在 `_ready` 里 `play_ambient` 会 `playing=false`**：根节点/音频还没就绪。
   改成 `call_deferred` 延后一帧，稳定起播。
2. Ogg 循环要显式 `(s as AudioStreamOggVorbis).loop = true`；不设的话 16.5 秒后自然停。
3. 环境音挂 root（Window），不挂 SubViewport/场景；换场不会把它带走，所以必须 `_exit_tree` 手动停。
4. `_ensure_playing` 是异步函数，**不 await 也会跑**（sfx 一直这么用）；但要给它 player 在树里。
