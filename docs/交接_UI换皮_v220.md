## 〇、一句话现状

- **画卷松手吸附**：封面页 ↔ 村景页拖到一半松手，不再停在"半卷"状态；
  过 45% 就归到村景，没过就弹回封面，0.32s 缓出；下一次按下会打断吸附。
- **顶栏钱数滚动**：银两/元宝目标值变了，数字从旧值**滚**到新值（0.5 左右一档），
  同时两条墨牌的**金边亮一下**、数字往金色偏；首次进入直接显示，不滚。
- **底栏金线**：哪个面板开着，对应底排那一格顶沿亮一道**金线**（0.2s 缓入缓出）。
  仓库/商店这类没盖住底栏的面板能直接看到；角色/炼丹这种满屏面板盖住了底栏，属正常。
- **顺手补洞**：`_insight_panel`（阅历线）原来没算进 `_any_panel_open()` / `_top_panel()`，
  开着时底下还能点；现在补上了。

## 三、踩过的坑（v220）

1. **`_init` 是 GDScript 保留方法名**：`MoneyHud` 里写 `var _init := false` →
   `Parse Error: Member "_init" is not a function`，整个 `menu_sketch.gd` 加载失败，
   探针拿到的是一棵没有脚本的 Control、空白截图、`_process` 永远不返回 → 卡到超时。
   改名 `_seeded`。**探针一定要加 `frames > N` 兜底退出**。
2. `--check-only` 只 check 你点名的脚本；`menu_hud.gd` 被 `menu_sketch.gd` 引用，
   但**不会**跟着一起报错。改完 HUD 也要单独 check 一次。
3. 吸附用 `tween_property(self, "_sc", ...)` 时，下一次按下要 `kill()`，不然手 drag 和 tween 抢同一个变量。
4. 底栏金线在**满屏面板**下看不见是正常的——那些面板把底栏盖住了；别为了看见它去改面板层级。
