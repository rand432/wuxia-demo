## 三、踩过的坑（v239）

1. `_result_panel` 必须加在 `_result_lb` **之前**，否则框会盖住字。
2. 原来 `_result_lb.visible = true` 在两处（延迟/立即），现在都改调 `_show_result()`，别只改一处。
3. 框的 `pivot_offset` 在 `_show_result` 里按 `size*0.5` 设；建框时 size 还没布局好，提前设会偏。
4. 探针强制 `_end(true)` 不会真的结算奖励，只演结算画面；别拿它验数值。
