## 〇、一句话现状

- **百工坊门厅**：三张纸卡 → **墨底金线卡**；自定义 96 高刊头（毛笔「百工坊」+ 副题），
  左侧 88 图标槽（酒坛/药草/令牌），名字改毛笔金字，未开张的作坊整卡压暗，右下「进 ▸」。
- **炼丹阁 · 炼制丹药弹窗**：660×660 的旧弹窗 → **680×660 的三栏骨架**：
  - **左**：可滑的丹方列表（选中的深底、料不够标「料不够」）；
  - **右**：产出（丹丸图标 + 名称 ×N + 「产出」小字）+ 材料/现有一行、炉时、下到几号炉；
  - **底**：颗数 −/输入/＋、×1/×3/×5/满，最下面 **开始炼丹**（朱砂）+ 取消。
- **品酒坊 / 鉴宝行没有硬套**：品酒是五人桌游（点桌斟酒、品评、卖酒），鉴宝是货仓信息流；
  硬套"左配方右产出"会把玩法做没。这两页先保留各自流程，下一轮只做配色/字体统一。

## 三、踩过的坑（v215 新增）

1. **TextureRect 的老坑又踩了一次**：丹丸图标先给 `size` 再给 `expand_mode`，贴图最小尺寸把它顶回 128×128，
   直接盖住右边文字。顺序永远是 `expand_mode → stretch_mode → texture → size`（v212 已记过一遍）。
2. **`_skin_pass` 会给"标题是深色"的面板补自动刊头**：百工坊三张卡里，
   未开张的「鉴宝行」名字被 refresh 压暗（v<0.6），于是 `_skin_pass` 在卡片里补了一条 78 高的自动刊头，
   在墨底卡上只剩一条横贯卡片的金线。**给卡片也打 `skin_header` 标记**就干净了。
3. 品酒/鉴宝不套三栏骨架是**有意的**——它们的交互是桌游与信息筛选，不是配方→产出。
