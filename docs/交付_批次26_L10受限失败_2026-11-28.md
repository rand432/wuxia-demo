## 2. 失败点

- 两局都跟到第 18 波首领，**主角气血先归零**（`[BOSS_END] hero_hp=0/302`、`0/314`）
- 首领仍存活：
  - s1116：`hp=678/2352`（剩 28.8%），有效命中 59 次、累计伤害 1674
  - s1117：`hp=1273/2448`（剩 52.0%），有效命中 46 次、累计伤害 1175
- **不是超时**：分别死在 364.9s / 341.1s，远早于 600s 上限
- 首领战前主角已残血（s1116 最后一秒 `hero=1/302`；s1117 `hero=53/314`），进首领时没有回复资源

## 3. 归因

- **数值/构筑强度是主因**：同种子把 `-BasicSkillLevel` 从 0 提到 50（只改这一个条件，仍不点强化），立刻从 LOSE 变 WIN，用时 350.5s，首领战 31.0s 且主角存活；对照 auto 用 142 级强化把首领战压到 4.3s
- **目标选择无异常**：`[BOSS]` 伤害事件都落在首领身上（59/46 次），没有把输出打在召唤物上
- **机制执行无卡死**：首领正常入场、正常出手；失败是气血耗尽，不是免疫/免伤/无法结算
- **计时门槛无关**：两局都远未到超时
