## 〇、一句话现状

- `_pbtn()` 是 v2 所有弹窗页内的按钮口子（卡组页签、黑市「买」、局终两颗、各种确认钮）。
  之前它只给朱砂 `seal` 走红底，**非 seal 仍是旧灰蓝**（局终的「退出」就是灰蓝的）。
- 现在皮肤下：
  - `seal == true`：红底、米白字（保留"花钱/主操作"语义）；
  - `seal == false`：**墨底金线 + `Ui.GOLD_HI` 字**，跟外壳/关闭钮一致。
- 卡牌详情页本来就是纸面深字，这轮验收没发现要改的；局终页的「退出」已从灰蓝变墨金。

## 三、踩过的坑（v236）

1. `_pbtn` 是全弹窗共用的，改一处所有页内按钮都会变；**别把 seal 也改成墨金**——
   红「买/再来一局」是功能色，不是装饰。
2. `_pbtn` 与 `_mk_btn` 是两套口子：外壳按钮走 `_mk_btn`，弹窗页内走 `_pbtn`；
   以后加新页要按场景选对。
3. 卡牌详情页文字是深色（纸面），别再给它加亮金字；只有弹窗标题可以"墨字描金边"。
