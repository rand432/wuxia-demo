## 〇、一句话现状

- 所有标准 `Button`（全局 `node_added` 挂载）现在按下会缩到 **0.95**（0.06s 缓出），
  松手弹回 1.0（0.12s `TRANS_BACK`）——跟点击音一起，变成"按下去"的手感。
- **满屏遮罩类按钮不缩**：`size.x > 620` 或 `size.y > 1180` 直接跳过
  （弹窗背后那颗全屏 closer 缩了会露边）。
- 按钮隐藏时自动把 `scale` 复位成 1.0，避免"按着的时候面板关了，再开时按钮还是小的"。

## 三、踩过的坑（v225）

1. `button_down/button_up` 只对 `BaseButton` 有；挂载前判 `n is Button`。
2. 满屏 closer 必须跳过：它们也是 Button，缩 0.95 会在屏幕边露一圈。
3. 面板关闭时若按钮还处于按下状态，`button_up` 不一定发；用 `visibility_changed` 复位。
4. 快速连按时每次按都新建 tween（旧 tween 会继续跑）——目前手感没问题；
   将来若发现抖动，可把 tween 存进 meta、按之前先 `kill()`。
