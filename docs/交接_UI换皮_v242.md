## 三、踩过的坑（v242）

1. `paper_box` 是**全局公共底**，改一处 32 个弹窗一起变；只改圆角/边色，不动底色，深色字照样能读。
2. `journey_stage.gd` 原来只 preload `UiKit`；用 `Ui` 前要补 preload。
3. 行装卡标题里有「（凡品）」「+190」这类数字/括号，**不要上毛笔字**，否则会糊；只给页面大标题用毛笔。
4. 这轮没动行囊面板/角色钮——它们有自己的 StyleBox，不在 `paper_box` 管辖内。
