## 〇、一句话

**挑战 = 花冷却换资源**：按下就额外刷一群（或一只）挑战怪，打完给对应资源。不花文钱、不花灵晶，代价是**怪会占场、还随波变强**，打不动就是亏。

## 四、界面

点左缘「挑战」→ 浮出 **2×3 面板**（五格 + 右上关闭）：

| 状态 | 显示 |
|---|---|
| 已解锁 · 就绪 | 金色描边，名字 + 奖励预览 |
| 已解锁 · 冷却中 | 灰色，压一层半透明，中央大数字 **剩余秒数** |
| 未解锁 | 更暗，名字下面写「第 N 波解锁」 |

面板**不遮暗、不暂停**（跟抽卡 / 进阶 / 宝物页同一套手感），点空白处不收，点关闭才收。

## 五、自动挑战

面板底部一颗大开关：

- 勾上后每 **0.5 秒**检查一次，按 **0→4 顺序**挑第一个「已解锁 + 冷却好」的按下去
- 不额外消耗任何资源（挑战本来就是冷却制）
- 关闭面板后继续生效（跟旧版一致）
