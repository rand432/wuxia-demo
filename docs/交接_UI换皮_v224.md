## 〇、一句话现状

### 按钮音分流
全局点击挂载从 `_ui_click_sound()` 改成 `_ui_click_sound(b)`（`pressed` 时绑定按钮）。
按键面文字分流（**在按下时读**，因为很多按钮是 add_child 之后才 set_text 的）：

| 文字里含 | 音 |
|---|---|
| `关闭` / `返回` / `退出` / `×` | `ui_back`（-12dB） |
| `购买` / `买` / `购入` / `兑换` | `coin`（-12dB，pitch 1.0~1.06） |
| `‹` / `›` | `paper`（-19dB） |
| 其他 | 原来的 `ui_click` |

> 已用探针核对：仓库的 关闭/×/退出 → ui_back，货栈的 购买 → coin，关闭 → ui_back。

### 货栈切页
- `_on_tab` 换页后，货架 `_list` 从 alpha 0 / scale 0.985 淡入到 1 / 1（0.14~0.16s）。
- 买货后的 `refresh()` 不触发这个淡入，只有**切页**触发。

## 三、踩过的坑（v224）

1. **不能在 `node_added` 时按 text 分类**：很多按钮先 `add_child` 再 `text = ...`，
   那时 text 还是空的。分类放到 `pressed` 回调（`_button_sfx`）里做。
2. 中文按钮里有全角空格（`关　闭`），分类前先 `.replace(" ", "").replace("　", "")`。
3. 只认"买"字有风险：以后若有"买卖/买价"这类按钮也会走 coin；目前货栈只有购买/兑换，够用。
4. 切页淡入用 `_list` 的 `modulate` 和 `scale`，**不要动 position**——它在 ScrollContainer 里，位置会被容器重排。
