# 新独立模式「困兽」· 设计稿（v1 · 待定稿）

> 来源：用户提出的"狗头人战纪4"模式移植（【先讨论】阶段 · 未动代码）
> 定位：与「游历」「爬塔」并列的第三种玩法 —— **武学构筑波次生存**
> 一局 **20~30 分钟** · 三个门派试水 · 彩蛋表外隐藏 ✓
> **剧情壳**：击败匪徒后（中间那段未设计 ✗ 留钩子）主角一行人被掳进**私人死牢**，
> 被当作**斗兽场**的玩物供人取乐——牢里藏龙卧虎，拜师傅、偷学武、守波次、活下去。

---

## 一、一句话

**选门派 → 抽武功卡 → 凑武学谱系 → 彩蛋合璧 → 守波次打 BOSS**

## 二、一局流程（35 波 ✓）

| 波 | 内容 | 说明 |
|---|---|---|
| 开局 | 选 1 名角色（**少侠 / 陈石 / 苏青鸾**，Lv1 初始属性）＋ 拜 1 个门派 ＋ 挑 1 张**开局签**（可不挑）| 玩家初始生命 **100** ✓ 文钱 **5000** ✓ |
| 1~9 | 小怪波（**三怪轮替**：几轮循环出 ✓ 无 Boss）| 击杀给文钱＋经验 |
| **10** | **Boss ①** | 保底高品卡 1 张 |
| 11~14 | 小怪波 | — |
| **15** | **Boss ②** | — |
| 20 / 25 / 30 | **Boss ③④⑤** | **15 波之后每 5 波一个 Boss** ✓ |
| **35** | **最终 Boss（通关）** | 7 阶强度 ✓ |

- **文钱消费**：**刷新**卡池 **500 文** ／ **抽卡 1000 文**（两个价 ✓ 开局 5000 ≈ 5 抽 ✓）＋ 商店卖「**断绝杂学**」**2000 文**（把杂学/散卡从本局卡池删掉 ✗ 池子更纯、本派卡出得更快 ✓；**再点一次花 2000 文重新开启** ✓ —— 可来回切 ✓ 原作"删除入口"同款 ✓）
- **装备**：Boss 与特殊波掉落**兵器/护甲**（和武功卡分开的两条获取线 ✓）
- 波 8 / 16 / 24：武学格 **+1**（开局 **24 格** ✓ 9×5 一屏装不下就滑 ✓）
- **战斗＝全自动火柴人对打** ✓（玩家只抽卡凑线，不出手 ✓）

**开局签（自虐换收益 · 可不挑 · 原作"开局天赋"照抄 ✓）**

| 签 | 好处 | 代价 |
|---|---|---|
| 「**受咒的赏钱**」| 每波结算 **+1000 文** | 开局生命 -2，此后**每累计 5000 文结算再 -2** ✗（越贪越短命 ✓）|
| 「**傲骨**」| 击杀概率掉 200 文／刷新／抽卡（**随机三选一**）| 进攻怪难度 **+50%** ✗ |
| 「**贪功**」| Boss 关**武学格 +1** | **永久删 1 个随机门派**（原作删 2 个入口 ✗ 咱们 3 派删 2 太狠 ✗）|
| ~~胆小~~ | 移除待定 | 用户看完原作再定 ✗ |

## 五、数值公式（照抄截图 · 数值 ×0.2 起）

- **两套生命，分开算**（用户重点提醒 ✓）：
  - **玩家生命**（初始 **100**）：死牢里的那条命 ✗ —— 对赌、自爆、扣血签都扣它；归 0 = 浴血免死 +1 成长 ✓
  - **角色属性**（气血/攻/防…）：上阵那个人的战斗面板 ✓ —— 武功卡加的"生命"加在**角色**上，卡面写清楚加谁 ✓
- **伤害链**（从左往右 ✓）：`(攻＋附伤) × 物/法伤害 × 伤害增幅` → 防御：`无视防御 − 穿透` → 减免：`物/法减免 − 伤害减免`
- 攻速上限 500% · 每秒出手上限 43 次 · 会心 = 暴击 × 爆伤（基础 150%）
- **三怪轮替**：小怪三只一组循环（几轮几轮 ✓），Boss 波换 Boss 面板（减免/闪避/护甲逐阶涨 ✓）
- 装备：兵器/护甲两条掉落线，加成并入角色面板 ✓
- ⚠ **不搬 70 亿亿** ✗ 本局上限压在"成型 ×2~3 倍伤害"的爽点 ✓
