# 羁绊（宝物）总表

> 2026-11-10 重做：卡池已按**线**分类（10 线 × 4 阶），羁绊跟着线走；效果一律只是**对应组合的数值加成**，没有任何特殊效果。
> 依据代码：`kushou/battle_ui.gd`（BOND_POOL）· `kushou/card_data.gd`（普通卡 10 线）· `kushou/ancestor_data.gd`（家传）

## 〇、规则

| 环节 | 规则 |
|---|---|
| 机会 | 开局 1 次，每清一波 +1 |
| 抽取 | 三选一；按钮 `刷新 · N 次`（次数型）/ `隐藏` / `放弃 +1 刷新` |
| 品质 | 随波数升：1-2 波良 · 3 波玄 · 4-5 波地 · 6 波起天；只是把数值 ×1 / 1.5 / 2 / 3 |
| 结算 | **普通卡羁绊** → 点名组合每次触发 ×(1+boost)；**家传羁绊** → 该祖宗本命技 +boost% |
| 取整 | 整数类（+1 文钱 / +2 只怪 / +1 张吞噬…）的小数**攒着**：+50% 作用在 1 上，每两次触发多给 1 点 |
| 消耗 | 凑齐即生效并**消耗掉这张羁绊**，所以不占格子、没有携带上限 |

## 五、待定

1. 线羁绊要**一条线四阶全通**（3+4+5+6 = 18 张），一局 5 波基本吃不满，是长线目标；要不要改成「前两阶 / 后两阶」两段式？
2. 家传羁绊只有 3 条：物理 4 位两两还能再配 5~6 条。
3. 叠加：同一套组合最多被 **2 条**羁绊点名（线羁绊 +50 与跨线羁绊 +40），合计 **+90%（×1.9）**；例：三锋 ← 剑道+50 / 攻守+40，铁壁 ← 铜墙+50 / 攻守+40。没有更深的堆叠，暂不需要上限。
