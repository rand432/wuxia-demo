# 羁绊（宝物）总表

> 生成日期：2026-11-10 · 依据代码：`kushou/battle_ui.gd`（BOND_POOL）· `kushou/card_data.gd`（5 系组合）· `kushou/ancestor_data.gd`（家传组合）
> 旧版资料来自 git 历史（提交 `2f606fa^`），文件本身已在 11-06 清理中删除。

## 〇、一句话规则

**宝物 = 卡组羁绊**：凑齐它点名的组合 → 那几套组合（或那几位祖宗的技能）永久增幅，羁绊**当场消耗**，所以不占格子、没有携带上限。

| 环节 | 规则 |
|---|---|
| 机会 | 开局 1 次，每清一波 +1 |
| 抽取 | 三选一，`刷新 · N 次`（只靠放弃 +1）/ `隐藏` / `放弃 +1 刷新` |
| 品质 | 随波数升：1-2 波良 · 3 波玄 · 4-5 波地 · 6 波起天，数值 ×1 / 1.5 / 2 / 3 |
| 结算 | 5 系羁绊 → 该组合每次触发 ×(1+boost)；家传羁绊 → 该祖宗本命技 +boost%（写进 `_anc_mod.dmg_pct`） |
| 查看 | 顶栏［总计］→ 宝物页，图标墙上点开看进度与缺哪套 |

## 五、缺口与可选方向

1. **后加的 5 系（内力 / 群 / 险 / 财 / 经验）一条羁绊都没有** —— 内力（凝息·聚气·通脉·化虚）、群（蜂拥·潮涌·蜂起·倾巢）、险（赏金·晶簇·遗珍·王座）、财（进账·利市·日进·万贯）、经验（奋起·精进·顿悟·悟道）。
2. **家传羁绊只有 3 条**：13 位祖宗里 物理 4（主角/小乞儿/滚地龙/苏青鸾）· 木系 3（柳卿卿/柳卿卿医/明烛）· 真实 2（陈石/陈石石皮）· 召唤 2（崔三娘/纸鸢）· 金系 1（张道陵）· 火系 1（季沧海）。光物理 4 位两两配对就能再出 5~6 条。
3. **旧版的多样条件没继承**：杀敌 / 文钱 / 存活 / 入队 / 装备六格 / 武器等级 / 境界 —— 现版本没有这些系统，若要沿用需先补系统。
4. 羁绊强度上限：同一套组合可被多条羁绊叠加增幅（三锋 被 开门三式40 + 锋芒40 + 攻守35 + 同源40 点名，叠满 **+155%（×2.55）**）。要不要设上限待定。
