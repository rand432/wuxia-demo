## 一、系统定位

**请神 = 原「伙伴」系统改成「祖宗上身」。**

- 局内请到一位祖宗 → 他的**本命技**进「技能栏」，本局有效，换局清零
- 每位祖宗同时带一条**家传卡组**，抽卡抽到、集齐触发组合
- 祖宗本人的**星级**与**进阶**是局外持久养成的

三层结构：

```
① 请神     升级 → 底栏「请神」钮亮 → 三选一 → 技能进技能栏
                      ↓
② 家传卡组  请到的祖宗解锁家传套 → 抽卡抽到 → 进卡组 → 三张成组
                      ↓
③ 炫卡      抽卡时 4% 彩蛋 → 独立一张超强卡 → 吞尽家传换资源
```

## 六·五、伤害类型共享（「众」的规则）

**不是"元素"共享，而是"伤害类型"共享。** 可共享的类型不止五行：

| 类型 | 谁在用 |
|---|---|
| 金 · 木 · 水 · 火 · 土 | 五行祖宗 |
| **物理** | 兵器类祖宗 |
| **召唤** | 召唤物祖宗（崔三娘） |
| 真实 | 无视减伤的那类 |

**统一规则：每位祖宗的四档 = 它自己的伤害类型 +15%（众）**，同类型祖宗互相吃。

| 祖宗 | 伤害类型 | 四档 |
|---|---|---|
| 张道陵 | 金系 | 金系伤害 +15%（众） |
| 崔三娘 | **召唤** | **召唤伤害 +15%（众）** |
| 季沧海 | 火系 | 火系伤害 +15%（众） |

实现上就是 `_elem_mod` 以「伤害类型字符串」为键，施法时按技能自己的 `dtype` 取。

## 七、炫卡（彩蛋）

### 触发

```
抽卡 → 三张里出现某位祖宗的家传卡
      ↓ 对该祖宗掷 4%
      中 → 该祖宗的「炫卡」进入卡池
      ↓
刷新（5 灵晶）→ 很大几率刷出来
      ↓
抽到 = 拿到
```

- **一局只出一次**
- 不进家传档位，不占三张成组的位置

### 卡面

与普通卡**同尺寸 200×300、同排版**，只有边框换成**七彩**（六层描边由外向内，实机做成流动渐变）。

### 特别表现（动画 + 音效）

**① 出现（进池 / 刷新刷出来）**

| 表现 | 做法 |
|---|---|
| 边框 | 七彩**流动渐变**：六层描边色相循环，每帧偏移 |
| 出场 | 从右侧滑入 + 七彩拖尾，卡面轻微过曝再回正 |
| 光晕 | 呼吸式外发光，节奏比其他卡快一倍 |
| 音效 | `sword_draw` + `bell`（错开 0.1 秒） |

**② 抽到（飞向卡组格）**

- 全屏**白闪 0.08 秒** → 七彩波纹从卡位扩散
- 飞行拖尾是七彩的（普通卡是虚线）
- 音效：`ult_ready`

**③ 吞噬（进卡组瞬间自动触发）**

```
全部家传卡从格子里飞向炫卡
      ↓ 每吞一张
卡缩成光点被吸进去 → 灵晶/文钱数字往上跳 → 屏幕轻震
      ↓ 吞完
炫卡自己炸成一片七彩碎光，边框熄灭
```

| 节点 | 音效 |
|---|---|
| 每吞一张 | `coin`（音高递增）+ `hit_heavy` |
| 吞完炸开 | `drum` + `fall_down`（长尾） |

> 音效全部取自 `assets/audio/sfx/` 现成的 26 条，**不新增素材**。

#### 季沧海 · 焚天

"慢跑引擎"：不靠一次爆发，靠**越杀越宽**。

| 项 | 内容 |
|---|---|
| 单卡数值 | 火焰伤害 **+10%** |
| 特殊效果 ① | **灼烧层数无上限叠加** |
| 特殊效果 ② | **每击杀 15 名敌人 → 随机吞噬卡组里一张卡** |
| 特殊效果 ③ | **每吞噬一张 → 引燃目标永久 +1** |
| 吞噬规则 | **随机一张、不限类型、不限次数**；**效果与进度全部保留**；**不返还资源** |

成长举例（一局约 60 杀）：

```
60 杀 ÷ 15 = 吞 4 张
引燃目标 1 → 5
火焰从"烧一个"变成"一次点五个"，灼烧还能无限叠
```

> 注意它的隐性收益：因为**效果保留**，被吞的卡等于"不占格、效果还在"——
> 焚天跑久了会把你的卡组一路腾空，等于把 10 格慢慢变成永久加成。
> 这是它比噬雷更狠的地方（噬雷只吞一次）。

> ⚠ **阻塞**：依赖「灼烧（DoT）」和「引燃」两套机制，战斗里都还没有。

### 张道陵的炫卡「噬雷」

| 项 | 内容 |
|---|---|
| 单卡 | 天雷伤害 +10% |
| 触发 | **进卡组瞬间自动触发**，一次 |
| 吞 | 吞掉卡组内**全部家传卡**，**进度与效果全部保留** |
| 每吞一张 | 灵晶 +20 · 文钱 +150 · 天雷伤害 +10% |
| 收尾 | 吞完**自身也被吞掉**，永久离场 |
| 出现 | 一局只出一次 |

例：卡组里有 6 张家传时抽到噬雷 → 返还 120 灵晶 + 900 文钱，天雷伤害 +10% + 60%，噬雷消失。

### 它带来的玩法

**「不合」是玩家的主动选择**：抽卡是 3 选 1，只拿各档的**入口卡**、不拿后续卡，就永远合不上 —— 于是可以攒着等炫卡一次性全吞。

代价：不合 = 档位组合一个都不生效，等于半裸打；而彩蛋一局只出一次，没出就白攒。

- `kushou/ancestor_data.gd`：张道陵 + 崔三娘 **2 位 × 18 张 = 36 张**家传卡，6 套/人，入口卡解锁同档其余

### 已实现（波次 / 等级 —— 请神的前置）

- **波次推进**：`_core.wave_cleared()` 成立 → `set_wave(+1)` + `wave_reset_quota()` → 进下一波；满 **5 波**收工
- **经验**：杀 1 只 **+20** · 清一波 **+50**
- **升级**：需求 `100 + 50×(级−1)` → 100 / 150 / 200 / 250 …
- **每升 1 级 → 请神次数 +1**
- **底栏**：Lv 与经验条接真实数据；「请神」钮在次数 >0 时亮起，角标显示累积次数
- 实测：杀 5 只 → Lv2 · 请神 1 · 钮亮；波次 1→2 定额正常重置（8/8 刷完清场即换波）


### 战斗界面「请神」改版（2026-11-11，已实现）

**和抽卡/进阶/宝物页同一套排版**：战场不遮，卡片浮在上面。

| 项 | 内容 |
|---|---|
| 卡片数 | **二选一**（原来是三选一） |
| 卡片尺寸 | **260×390**（放大，图标跟着变大；GodCard 全部按比例绘制） |
| 横幅 | 「请神 · 剩 N 次」 |
| 按钮 | **刷新 · N 次** / **放弃 +1 刷新** / **隐藏** |

- **刷新**：次数型，用一次少一次；次数为 0 时按钮置灰
- **放弃**：这一手不要（**不消耗请神次数**），换 1 次刷新，次数攒着
- **隐藏**：收起来；再点「请神」看到的是**同一手**（同一个请神次数内不重掷，防白刷）

实测（headless）：
- 隐藏再开 → 同一手（`SAME_HAND true`）
- 放弃 → 刷新次数 0→1、请神次数不变（3）
- 再开 → 刷新按钮亮起「刷新 · 1 次」
- 点刷新 → 次数回到 0、换了一手新卡（仍是 2 张）

### 已实现（请神三选一 + 技能栏 + 内力）

- **三选一弹窗**：点「请神」→ 暗底 + 绯红横幅 + 祖宗卡（品阶色边框 / 祖宗名 / 图 / 本命技 / 伤害类型 /「点击请神」）
  - 候选池 = 本局还没请过的祖宗；不足 3 位就全给
  - 选中 → 请神次数 −1 → 技能进技能栏 + 家传初级入口卡进池
- **技能栏**：战场右缘竖排，54×54，最多 6 格；格内显示技能字 + CD 倒计时 + 内力消耗角标
- **内力**：上限 `300 + 25×(等级−1)`，每秒回 `20 + 2×(等级−1)`；血条下面那条接成蓝条
- **施法**：各自 CD 到 + 内力够 → 自动打最近的 N 名敌人（伤害 = 主角攻击 × 倍率），飘技能名
  - 张道陵·天雷道术：金系 ×1.6 · 3 目标 · CD 10s · 内力 300
  - 崔三娘·雾海龙王：水系 ×2.5 · 1 目标 · CD 60s · 内力 500（低等级内力不够，放不出来 —— 设计如此）
- 实测：请到两人 → 技能栏出现「海」「雷」两格；张道陵按 CD 正常放、内力被扣；崔三娘因内力上限不足始终不放

### 已实现（组合加成落地 / 第三位祖宗 / 炫卡）

**① 组合加成真正生效**

`ancestor_data.gd` 里每档多了 `effects` 字段，组合激活时累进两张修正表：

| 字段 | 含义 |
|---|---|
| `dmg_pct` | 本技能伤害 +X% |
| `cd_pct` | 本技能冷却 −X% |
| `mp_flat` | 本技能内力 −X |
| `elem_pct` | `{元素: X}` —— **该元素所有祖宗共享** |
| `para_s` | 命中麻痹 X 秒 |
| `para_amp` | 麻痹期间受伤 +X% |

> 所以「杀敌数加成」不是空转的卡 —— 它加的是能拿去换东西的货币。
| 项 | 内容 |
|---|---|
| 触发 | **合成经济系**（文钱 / 灵晶）的卡组时，**3%** 几率出 |
| 效果 | 选中一张卡 → **10% 复制一张**；**复制出来的那张再独立掷 10%**，可以一直链下去 |
| 自我复制 | 选中「重利」本身时它立即生效，**自己也掷一次** —— 中了就是两张 |
| 叠加 | 手里有 **n 张重利 → 每次抽卡掷 n 次**（每多一张就多一次独立判定） |
**复制体立刻被吞噬**：复制出来的那张卡**不进卡组格**，当场被吞噬 —— 但**进度和效果全部保留**。

| 复制到 | 结果 |
|---|---|
| 普通卡（攻/防/血/内…） | 属性直接加上，不占格 |
| 家传卡 | 计入该档的 x/3 进度（可能直接凑齐成组） |
| 炫卡 | 机制翻倍（见上表） |

> 副作用：**集三张有机会变成集两张** —— 复制到一张家传卡就等于白送一格进度。

> 只做这一张，不分群/险。

**链式判定**（每张独立，不是一次算完）：

```
选 1 张 → 掷 10%
   ├─ 不中：就 1 张
   └─ 中了：变 2 张
            ↓ 第 2 张再独立掷 10%
            ├─ 不中：2 张
            └─ 中了：变 3 张 → 第 3 张再掷 ……
```


**✅ 已实现（2026-11-09）**

- 卡表从 6 系扩到 **8 系**：全部 **392 张 / 110 套**
- 群/险 的组合都是**常驻型**（trigger=`常驻`），组合完成的瞬间生效一次
- `_wave_quota_for(w) + wave_extra` → 每波定额；实测 8 → **13**
- `extra_diff_mul` 乘在 `_spawn_foe` 的血量与攻击上；实测怪血 28 → **34**（+18%）
- 险系怪物类型：`_spawn_typed_foes()` 在换波时额外刷带 `rtype` 标签的怪，
  `_tick_rtype()` 用 `_tid` 消失判定死亡并结算：文钱怪 +20、灵晶怪 +2（都吃宝物%）
- 重利：合成 gold/crystal 套时 3% 入池；抽卡选中后按持有张数掷 10%，中了复制一张
  （**复制体当场吞噬、不进卡组格、效果与进度保留**），复制体再独立掷 → 链式

实测：
- 群初级齐 → 每波 +5、定额 8→13、难度 ×1.05
- 险中级齐 → 灵晶怪 +5、难度 ×1.13
- 险初级齐 → 文钱怪 +5、难度 ×1.18；怪血 28→34
- 重利 1 张：200 次抽卡复制 **19** 次（≈10%），攻击 12→32，**卡组格数不变**
- 重利 3 张：100 次抽卡至少中一次 **29** 次（≈27%）

## 九、关卡骨架（后续设计，暂未实现）

### 结构

```
普通波 ×5 → Boss → 普通波 ×5 → Boss → ……
                ↓
        ① 进化资格 / 进化材料
        ② 大额灵晶 + 文钱
        ③ 首通奖励（卡 / 配方 / 新祖宗）
```

- **每 5 波一个 Boss**
- **卡进化**：部分卡需要**击败首领**才可进化（门槛型，不额外加材料）
- **Boss 奖励**：灵晶 / 文钱 / 进化资格 / 首通奖励

### 回潮 × Boss（已拍板）

**回退 5 波后重打 Boss，奖励照给。**

于是回潮的真实价值 = **把一整轮 Boss 收益再吃一遍**：

```
回退 5 波 → 重打普通怪 + Boss → 灵晶/文钱/进化资格 全部再来一次
                                  ↓
                        抽卡 / 强化 / 请神 / 进化
                                  ↓
                              整局变强
```

它撬动的是**经济**，不是数值 —— 属性卡只加一个数，回潮多给你一段局。
所以 **5% + 一局一次** 这个稀有度是合理的（效果强到离谱）。

叠加链条：**回潮（多刷）→ 焚天（越杀越吞）→ Boss 奖励（进化）**，三个一起才是这局的极限形态。
