## 一、系统定位

**请神 = 原「伙伴」系统改成「祖宗上身」。**

- 局内请到一位祖宗 → 他的**本命技**进「技能栏」，本局有效，换局清零
- 每位祖宗同时带一条**家传卡组**，抽卡抽到、集齐触发组合
- 祖宗本人的**星级**与**进阶**是局外持久养成的

三层结构：

```
① 请神     升级 → 底栏「请神」钮亮 → 三选一 → 技能进技能栏
                      ↓
② 家传卡组  请到的祖宗解锁家传套 → 抽卡抽到 → 进卡组 → 三张成组
                      ↓
③ 炫卡      抽卡时 4% 彩蛋 → 独立一张超强卡 → 吞尽家传换资源
```

| 怪物 | 固定曲线吸收膨胀：基础血 34→42、攻 4.5→5.0、每波 ×1.12 / ×1.10 |

## 四、家传卡组

| 项 | 定稿 |
|---|---|
| 每位祖宗 | **6 档 × 每档 3 张 = 18 张** |
| 每档 | 第 1 张是**入口卡**，拿了它同档另外 2 张才进池 |
| 随机 | 入口卡是唯一的门槛，同档另两张谁先来都行 |
| 集齐 | 3 张齐 → **组合生效 → 清空这 3 格 → 下一档入口进池** |
| 卡组 | 沿用战斗界面那条 **10 格 / 2 页** |
| 自然上限 | 10 格 ÷ 3 张 = **最多同开 3 档**，想开第 4 档必须先合掉一档 |
| 卡面 | **与 5 系卡完全同排版**（品阶色边框 / 名称 / 图 / 效果），不加特殊框 |
| 展示 | 卡组格只画图 + 品质边框；点开是普通卡的小详情 |

**所有祖宗统一 18 张**，品质只影响数值：

|---|---|---|
| 凡（下） | 0.75 | 0.75 |
| 良（中） | 0.88 | 0.88 |
| 玄（上） | 1.00 | 1.00 |
| 地（极） | 1.12 | 1.12 |
| 天（绝） | **1.30** | **1.30** |

## 七、炫卡（彩蛋）

### 触发

```
抽卡 → 三张里出现某位祖宗的家传卡
      ↓ 对该祖宗掷 4%
      中 → 该祖宗的「炫卡」进入卡池
      ↓
刷新（5 灵晶）→ 很大几率刷出来
      ↓
抽到 = 拿到
```

- **一局只出一次**
- 不进家传档位，不占三张成组的位置

### 卡面

与普通卡**同尺寸 200×300、同排版**，只有边框换成**七彩**（六层描边由外向内，实机做成流动渐变）。

### 特别表现（动画 + 音效）

**① 出现（进池 / 刷新刷出来）**

| 表现 | 做法 |
|---|---|
| 边框 | 七彩**流动渐变**：六层描边色相循环，每帧偏移 |
| 出场 | 从右侧滑入 + 七彩拖尾，卡面轻微过曝再回正 |
| 光晕 | 呼吸式外发光，节奏比其他卡快一倍 |
| 音效 | `sword_draw` + `bell`（错开 0.1 秒） |

**② 抽到（飞向卡组格）**

- 全屏**白闪 0.08 秒** → 七彩波纹从卡位扩散
- 飞行拖尾是七彩的（普通卡是虚线）
- 音效：`ult_ready`

**③ 吞噬（进卡组瞬间自动触发）**

```
全部家传卡从格子里飞向炫卡
      ↓ 每吞一张
卡缩成光点被吸进去 → 灵晶/文钱数字往上跳 → 屏幕轻震
      ↓ 吞完
炫卡自己炸成一片七彩碎光，边框熄灭
```

| 节点 | 音效 |
|---|---|
| 每吞一张 | `coin`（音高递增）+ `hit_heavy` |
| 吞完炸开 | `drum` + `fall_down`（长尾） |

> 音效全部取自 `assets/audio/sfx/` 现成的 26 条，**不新增素材**。

### 张道陵的炫卡「噬雷」

| 项 | 内容 |
|---|---|
| 单卡 | 天雷伤害 +10% |
| 触发 | **进卡组瞬间自动触发**，一次 |
| 吞 | 吞掉卡组内**全部家传卡**，**进度与效果全部保留** |
| 每吞一张 | 灵晶 +20 · 文钱 +150 · 天雷伤害 +10% |
| 收尾 | 吞完**自身也被吞掉**，永久离场 |
| 出现 | 一局只出一次 |

例：卡组里有 6 张家传时抽到噬雷 → 返还 120 灵晶 + 900 文钱，天雷伤害 +10% + 60%，噬雷消失。

### 它带来的玩法

**「不合」是玩家的主动选择**：抽卡是 3 选 1，只拿各档的**入口卡**、不拿后续卡，就永远合不上 —— 于是可以攒着等炫卡一次性全吞。

代价：不合 = 档位组合一个都不生效，等于半裸打；而彩蛋一局只出一次，没出就白攒。

## 八、已实现 / 待做

### 已实现（本稿落地部分）

- `kushou/ancestor_data.gd`：张道陵 + 崔三娘 **2 位 × 18 张 = 36 张**家传卡，6 套/人，入口卡解锁同档其余
- `kushou/battle_ui.gd` 接线：
  - 家传卡并入同一张卡表（90 张 5 系 + 36 张家传 = **126 张**）
  - `_grant_ancestor(aid)`：请到祖宗 → 初级入口卡进池
  - `_activate_ancestor_set()`：集齐 3 张 → 登记组合 → 清空 → 下一档入口进池
- **占位**：战斗开始时固定 `_grant_ancestor("zl")`，等请神接上后改成由请神驱动

### 已实现（波次 / 等级 —— 请神的前置）

- **波次推进**：`_core.wave_cleared()` 成立 → `set_wave(+1)` + `wave_reset_quota()` → 进下一波；满 **5 波**收工
- **经验**：杀 1 只 **+20** · 清一波 **+50**
- **升级**：需求 `100 + 50×(级−1)` → 100 / 150 / 200 / 250 …
- **每升 1 级 → 请神次数 +1**
- **底栏**：Lv 与经验条接真实数据；「请神」钮在次数 >0 时亮起，角标显示累积次数
- 实测：杀 5 只 → Lv2 · 请神 1 · 钮亮；波次 1→2 定额正常重置（8/8 刷完清场即换波）

### 已实现（请神三选一 + 技能栏 + 内力）

- **三选一弹窗**：点「请神」→ 暗底 + 绯红横幅 + 祖宗卡（品阶色边框 / 祖宗名 / 图 / 本命技 / 伤害类型 /「点击请神」）
  - 候选池 = 本局还没请过的祖宗；不足 3 位就全给
  - 选中 → 请神次数 −1 → 技能进技能栏 + 家传初级入口卡进池
- **技能栏**：战场右缘竖排，54×54，最多 6 格；格内显示技能字 + CD 倒计时 + 内力消耗角标
- **内力**：上限 `300 + 25×(等级−1)`，每秒回 `20 + 2×(等级−1)`；血条下面那条接成蓝条
- **施法**：各自 CD 到 + 内力够 → 自动打最近的 N 名敌人（伤害 = 主角攻击 × 倍率），飘技能名
  - 张道陵·天雷道术：金系 ×1.6 · 3 目标 · CD 10s · 内力 300
  - 崔三娘·雾海龙王：水系 ×2.5 · 1 目标 · CD 60s · 内力 500（低等级内力不够，放不出来 —— 设计如此）
- 实测：请到两人 → 技能栏出现「海」「雷」两格；张道陵按 CD 正常放、内力被扣；崔三娘因内力上限不足始终不放

### 已实现（组合加成落地 / 第三位祖宗 / 炫卡）

**① 组合加成真正生效**

`ancestor_data.gd` 里每档多了 `effects` 字段，组合激活时累进两张修正表：

| 字段 | 含义 |
|---|---|
| `dmg_pct` | 本技能伤害 +X% |
| `cd_pct` | 本技能冷却 −X% |
| `mp_flat` | 本技能内力 −X |
| `elem_pct` | `{元素: X}` —— **该元素所有祖宗共享** |
| `para_s` | 命中麻痹 X 秒 |
| `para_amp` | 麻痹期间受伤 +X% |

施法时结算：`伤害 = 主角攻击 × 倍率 × (1 + (自身加伤 + 元素加伤)/100)`，冷却与内力同步打折。

**② 第三位祖宗：季沧海 · 怒火焚身**（火系 · 地品）
六档：燎原 / 疾焰 / 传火 / 火德 / 焚身 / 火葬。三选一现在能凑满 3 张。

**③ 炫卡全流程**

- **掷**：抽卡时若三张里出现某祖宗的家传卡 → 对该祖宗掷 **4%**（一局每位一次）
- **进池**：中了 → `shiny_<aid>` 进池 + 播 `ult_ready` + 提示「彩蛋！」
- **高权重**：池里有炫卡时，**80%** 直接排到抽卡页第一张
- **吞噬**：抽到 → 进卡组瞬间自动触发
  - 吞掉该祖宗**全部家传卡**（进度与效果保留）
  - 每张返还 **灵晶 +20 · 文钱 +150**，并给该祖宗 **+10% 伤害**
  - 自身离场（一局一次）
  - 表现：**白闪 0.06s 起 → 0.30s 淡出 + 震屏 9 + `coin`/`hit_heavy` → 0.12s 后 `drum`**
- **卡面**：七彩描边（六层由外向内），抽卡页与卡组格都生效

**实测**（卡组 2 张家传时抽到噬雷）：
文钱 0→**300**、灵晶 80→**120**、张道陵 `dmg_pct` 20→**40**、卡组 **0/10**、炫卡出池。

> ⚠ 待补：技能格还没有"内力不足"的灰显；吞噬提示文字较长时会盖住顶栏，需要收窄。
