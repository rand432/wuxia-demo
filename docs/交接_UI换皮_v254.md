## 三、踩过的坑（v254）

1. **Godot 4.7 的 `Label` 没有 `fit_content`**！赋值会报
   `Invalid assignment of property 'fit_content' on Label`。
   要用 **`RichTextLabel`**：`fit_content = true`、`scroll_active = false`、`bbcode_enabled = false`。
2. RichTextLabel 的字体/字号主题键是 `normal_font` / `normal_font_size`，颜色是 `default_color`，
   不是 Label 的 `font` / `font_size` / `font_color`。
3. 正文宽要留出滚动条：容器 540，正文 **526**；否则右边一列字会压在滚动条下面。
4. 后记原来的「再入江湖」在 y760，正好落在旧正文 700 高范围内；改成滚动区 640 高（112–752），
   按钮才不被 ScrollContainer 挡点击。
5. 滚动条样式只覆盖 `scroll / grabber / grabber_highlight / grabber_pressed` 四个键。
