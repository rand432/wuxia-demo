## 0. 一句话

**局外是村子和塔，局内是一张随机世界；进去采、杀、遇人、拜宗门，资源烧完出来；东西带走，人留下；世界不毁灭，关系网就不清零。**

## 2. 三个词

- **自由**：没有强制路线；良民 / 悍匪 / 捕快 / 宗主 / 独行客都能活；每个问题至少有两条解法；失败不是删档，是代价。
- **开放**：村子、塔、世界、宗门、聚落、关系网互相喂；塔解锁内容，但不是唯一的路；玩家可以按自己的顺序玩。
- **有灵性**：NPC 有状态、日程、记忆、反应、传闻、连坐；世界会记仇，也会记得你的好；**不做离线模拟**，灵性发生在你在线的时候。

### 三词验收

| 功能 | 玩家有得选？ | 咬得上？ | 世界记得？ |
|---|---|---|---|
| 地图探索 | 采 / 杀 / 帮 / 绕 / 回 | 材料喂锻造、NPC 喂关系 | 案底、传闻、NPC 变脸 |
| 对话 | 谈 / 骗 / 吓 / 送 / 打 | 善恶、声望、奖励、任务 | 好感、仇、传话 |
| 牢房 | 等 / 保释 / 劳役 / 越狱 | 资源、银两、通缉、黑市 | 守卫记脸、狱友记人 |
| 锻造 | 造什么、卖给谁 | 吃地图材料、NPC 订单 | 铁匠记得你上次要什么 |
| 宗门 | 入哪派、学哪功、叛不叛 | 正邪、声望、功法、宗门战 | 门规、追杀、师门态度 |

## 3. 局内：一趟怎么跑

### 3.1 进入

- 点「游历」→ 出征屏：**上人**（角色）、**上宠物**、看行动资源池；进图。
- 地图上**只显示主角一个人**；队伍在战斗里出现。
- 目的：地图是「一个人的江湖」，省掉跟随寻路与卡位；战斗是「一群人的仗」。

### 3.2 世界

- 随机生成：地形 / 环境、聚落、NPC、事件、Boss、材料、掉落；按世界的生成池抽。
- 地图上点击移动、点击交互；站着不动**不消耗**行动资源；一行动就烧。
- 行动资源烧完 = **安全出来**，**战利品全留**；不丢装备、不删档。
- 世界有日历（年 / 月 / 日）、昼夜、天气；灵草按天生长，环境按季节变。
- **离线 = 退出这个模式**：世界不推进、灵草不长、NPC 不动、牢房不烧；**离线只有塔在产资源**。

### 3.3 聚落与区块

| 类型 | 有什么 | 王法 | 主要给什么 |
|---|---|---|---|
| 荒野 | 废墟、营地、隐士、矿脉、怪物、Boss | 无 | 材料、风险、稀有遭遇 |
| 村落 | 几个 NPC、小货摊、村长 / 民兵、零散任务 | 弱 | 消息、小任务、基础货 |
| 小镇 | 商铺、酒馆、守卫、牢房、行会、任务板 | 中 | 买卖、任务、情报 |
| 城市 | 多势力、大市场、官府、牢房、竞技场、高阶任务 | 强 | 稀有货、高阶任务、宗门 |
| 宗门 | 功法、丹药、传承、门规 | 门规 | 功法、身份、靠山 |

- 每个区块 = 地形 + 聚落类型 + NPC 密度 + 危险度 + 特产 + Boss。
- 有的区块没有聚落，纯荒野；有的区块城郊都有。
- **玩家村 = 家 / 作坊；世界聚落 = 别人家 / 市场 / 关系**。

### 3.4 世界重开

- 爬塔解锁更多区块 / 环境 / 内容；但**当前世界不会自动长出新内容**。
- 想吃到新内容：花**舆图**重开一张新世界；不花就继续在老世界玩。
- 新世界**包含旧材料 + 新材料**（不然旧配方断料）。
- 重开 = 替换当前世界：旧地形、探索度、Boss、NPC、灵草、日历、关系网全部没；村子 / 装备 / 锻造 / 角色保留。
- 建议**先看后换**：舆图展开候选世界，看世界档 / 环境 / 资源预览，确认才替换；不确认保留旧世界（是否消耗舆图待定）。
- 关系网**只在世界毁灭时清零**。

## 4. 资源、失败、法律

### 4.1 行动资源

- 塔挂机产出；游历里按行动消耗；站着不动不扣。
- 空了 = 出来；战利品全留。
- **离线不消耗、不推进**；离线只有塔在产。
- 牢房**在线**才烧；下线暂停。

### 4.2 失败

- 战斗打输：建议**被抬出来 / 重伤**，这一趟结束，战利品全留；具体待定。
- 不做永久死亡；不做删档。
- 坐牢、通缉、商人敌对，都是**代价**，不是 game over。

### 4.3 村内法律

- 村里有王法：当街杀人 → 守卫来 → 打不过进牢房；打得过变通缉。
- 牢房出路：等（烧行动资源）/ 保释（银两）/ 服劳役（时间）/ 越狱（风险）/ 贿赂（钱货）/ 见狱友（黑市、任务）。
- 越狱成功 = 通缉，村子敌对；失败 = 加刑。
- 守卫能打、能跑、能投降、能塞钱；打死守卫掉装备 / 银两，但官府声望掉底。
- 通缉**分地方、分势力**；能洗（赔钱 / 跑腿 / 找关系 / 灭口 / 坐牢 / 易容 / 时间 / 栽赃），洗起来贵。

## 5. 战斗与队伍

- 出征屏选人 / 选宠物；地图只显示主角；战斗队伍全员上场。
- 沿用两套引擎：杂兵可自动（battle_lite 系），关键战 / 精英 / Boss / 事件可手牌（duel_battle 系）；具体分工待定。
- 世界 NPC 默认不帮你打；好感 / 声望 / 人情 / 钱 / 任务到位，才可能帮一次。
- 世界 NPC 自己会打：守卫打山贼、宗门打宗门、商人保镖打劫匪；玩家可帮 / 看 / 捡漏。
- 宠物世界内能打，不跨世界；星 / 血脉是否跟世界走待定（建议跟世界走）。

## 6. NPC 与社会

### 6.1 五个动作

| 动作 | 能拿到 | 代价 |
|---|---|---|
| 对话 | 善恶、声望、情报、任务、折扣、放行 | 说错话、得罪人 |
| 送礼 | 好感、折扣、任务、传功机会 | 东西 |
| 交易 | 货、材料、配方 | 钱 |
| 查看 | 名字、门派、境界、装备、脾气、大概的货 | 无 |
| 杀死 | 尸体、货、钱、装备 | 声望、通缉、商人网络、仇 |

### 6.2 对话是社交战斗

- 看状态：你的善恶 / 声望 / 装备 / 同伴 / 前科；他的好感 / 恐惧 / 贪财 / 门派 / 记忆。
- 选项：套话、商量、奉承、威胁、送礼、撒谎、勒索、认错、动手。
- 结果：给东西、涨价降价、给任务、叫人、放你走、打起来。
- **同一个 NPC，善恶 / 声望不同，看到的选项不同。**
- 对话能给：银两、丹药、配方、武学、装备、情报、折扣、任务、带路、放行、免打一架。
- 善恶 / 声望能在对话里涨；也能在对话里掉。

### 6.3 灵性七条

1. **状态**：怕、怒、贪、伤、醉、忙。
2. **日程**：白天巡逻 / 摆摊 / 串门，晚上收摊 / 睡觉 / 喝酒；守卫换班。
3. **记忆**：送礼、杀人、越狱、帮忙；下次见面话不一样。
4. **反应**：你强他怂，你弱他宰，你臭名远扬他跑 / 叫人。
5. **传闻**：村口杀的人，村尾知道；商队、官府、宗门各有消息。
6. **连坐**：杀商人，商人网络不卖你；杀守卫，官府通缉；帮人，有人替你说话。
7. **战斗**：会打、会跑、会求饶、会喊人。

### 6.4 商人与黑市

- 商人买卖；买不起可以走，也可以动手。
- 商人是一个网络；杀一个，全网络降声望；到敌对，不卖你、见你就打、发悬赏。
- 留一条**黑市**：只认钱不认人，价格翻倍；悍匪线能玩下去。
- 声望能修：赔钱、跑腿、找关系、时间。

### 6.5 关系网

- 节点：NPC、势力（官府 / 商人 / 门派 / 山寨 / 黑市）。
- 边：亲戚、雇主、仇人、债主、同门、线人。
- 案底记四样：谁记的、为什么、到什么程度、谁知道。
- 程度：怀疑 → 通缉 → 追杀 → 悍匪。
- 传播：目击 → 传话 → 势力记账 → 来人；可分地方、分势力；能跑出地界、能灭口、能栽赃。
- 只有世界毁灭才清零。
- 后续可做「江湖关系图」UI；先不做。

### 6.6 NPC 投放与世界的惊喜

- **不是每个世界都有同一个 NPC**：每个世界从池子里抽一部分；有名有姓的 NPC 是**稀有抽取**，这次没有，下次可能有。
- **保证有小惊喜**：每张世界至少埋 1~2 个「惊喜点」——一个稀有 NPC、一段隐秘事件、一处秘境、一个稀有商人、一个变种 Boss、一门失传功法、一张残图。
- **惊喜不标箭头**：玩家走到、问到、碰到才发现；没发现就留给下一张世界。
- **旧内容是抽奖池**：三角色 / 28 伙伴 / 64 事件 / 25 Boss / 5 宠物 / 15 血脉都是池子；世界档越高，池子越大。
- **世界毁灭才换池子**：旧世界没遇到的 NPC / 事件，跟着旧世界一起没；新世界是新抽。
- **不做空世界**：再荒的区块也至少有 1 个可交互的惊喜点（隐士 / 废墟 / 游商 / 兽巢），不让玩家白跑。

### 6.7 Boss 也是活的

- Boss 不是站在房间里的木桩；它有**日程和状态**：睡、巡、猎、宴、伤、怒、迁。
- 例：山君白天在洞里睡，黄昏出去猎食，夜里拖猎物回来；寨主白天巡寨，晚上喝酒，隔几天去村里收贡；鬼将只在夜里出没，白天墓是空的。
- **Boss 不在，洞不是空的**：小怪、宝藏、俘虏、陷阱还在；玩家可以摸进去、救人、偷东西；Boss 回来时，要么打，要么跑。
- **能追踪**：脚印、拖痕、吃剩的猎物、小怪的动向、村民的传言；没有箭头，自己拼。
- **情报**：旧的 Boss 情报窗可以复用——查状态、看弱点、看地盘、看它什么时候回来；情报靠侦察 / 传闻 / 查看，不是白给。
- **记忆**：你打过它、抢过它、杀过它的小弟，它记得；会追你、堵你、换窝、叫帮手。
- **死亡会改变区块**：小弟散、势力弱、村子松口气、掉落进包；也可能有新的东西来占窝（待定）。
- **Boss 也分稀有**：不是每张世界都有同一个 Boss；有的这次没有，下次有；世界档越高，池子越大。
- **Boss 也能谈**：寨主、宗门长老、妖王这类有脑子的，可以先谈 / 送礼 / 接任务；野兽就只能打或躲。
- **Boss 和关系网**：Boss 是网里的节点；杀它，它的势力 / 仇人 / 盟友都会变；悬赏、报复、接班人都记在账上。

## 7. 宗门

- 三类：正派 / 邪派 / 中立；各有专长（剑 / 刀 / 拳 / 毒 / 医 / 阵 / 暗器 / 佛 / 道……）。
- 给功法的四道门：
  1. **好感**：送礼、跑腿、办事。
  2. **声望**：宗门地位 / 贡献。
  3. **正邪**：你是什么人，宗门是什么派。
  4. **考验**：脏活 / 难事 / 投名状。
- 四个都够才给真功法；缺一个给残页 / 指点 / 外围功夫。
- 宗门是地方：山门 / 道观 / 剑冢 / 毒谷；有掌门、长老、师兄、藏经阁、演武场、禁地。
- 能干的：拜师、接任务、换功法、买丹药、打擂台、偷秘籍、叛门。
- 宗门有规矩：欺师灭祖、外传功法、动同门 → 逐出 / 追杀。
- 宗门之间会打：正邪、地盘、功法、人；玩家可站队 / 墙头草 / 摸鱼 / 卖消息。
- 旧 **57 门通用武学 / 15 类**（3 门专武砍掉）→ 各宗门看家本领；旧 ART_CAT 可改为宗门专长；**不新增功法**。

## 8. 锻造与经济

- 锻造是**稳定上限**：想造什么造什么；地图掉落是惊喜，建议封顶比锻造低半档（待定）。
- 材料：草药、矿、木、怪物掉落、Boss 材料、NPC 交易 / 事件。
- 掉落：残页 / 残兵 / 残装 / 成品 / 图谱 / 配方；重复可拆回材料。
- 银两：交易、保释、贿赂、锻造、任务。
- 舆图：世界重开的钥匙；来源建议塔里程碑 / 村庄打造 / Boss 掉落（待定）。
- **战利品全留**；难度只决定能不能清掉，不决定会不会破产。

## 9. 难度

- 四个静态旋钮：**区域档**（近郊 / 深山 / 绝地 / 禁地 / 剑冢）、**深度**（外圈 / 中圈 / 深处 / 巢穴）、**凶险度**（1~5）、**环境**（昼夜 / 天气 / 命数）。
- 一个动态旋钮：**警戒 / 杀气**（0~100，打架 / 挖矿 / 开箱涨，过阈值刷精英 / 追兵，到 100 引 Boss）。
- **固定档，不做敌人跟随等级暗调**；玩家变强，旧区域自然变菜。
- 推荐战力挂在塔层 / 境界上；具体待定。
- 失败 = 被抬出来，战利品全留；难度只决定清不清得掉。
- 旧数值（四品级 / 三模式 / 追剿曲线 / 境界压制 / 五行 / 词缀 / Boss 特性）可作底表。
- **世界档是内容，不是难度**；区域危险才是难度。

## 11. 已定 / 待定

### 已定

- 地图单人显示，战斗队伍上场。
- 资源空 = 安全出来，战利品全留。

## 15. 模式外：日常 / 挂机 / 离线

> 游历是“出门”，村子 + 塔是“在家”；这三样都在模式外。

### 15.1 三层

| 层 | 在哪 | 玩家干什么 | 时间 |
|---|---|---|---|
| **日常** | 村子 | 收挂机、看市场、锻造、炼丹、接消息 | 5~10 分钟 |
| **挂机** | 塔 / 村子 | 自动爬塔、产资源、产材料 | 离线也走 |
| **游历** | 世界 | 出门、采、杀、遇人、打 Boss | 10~30 分钟一趟 |
| **离线** | 全部 | 只有塔 / 村子产出；世界不动 | 8 小时封顶 |

### 15.2 日常循环

- 上线四件事：收挂机、看塔、看市场 / 村况、决定今天干嘛。
- 日常不是任务：没有“每日必做”；不做不惩罚。
- 每日刷新：货栈限购、酒坊限酿、市场价、塔产出。
- 世界事件按日子来；错过就错过。
- 节奏：上线 → 收挂机 → 看市场 → 锻造 / 炼丹 → 出门 / 下线；10 分钟能做完家里的事。

### 15.3 挂机

| 线 | 在哪 | 产什么 | 干什么 |
|---|---|---|---|
| **爬塔** | 村外塔 | 行动资源 / 银两 / 经验 / 宝箱 | 解锁世界档 / 内容 |
| **村子** | 村里 | 木料 / 银两 / 经验 / 材料 | 建设 / 锻造 / 炼丹 |

- 爬塔是主挂机：自动战斗、自动翻层；产行动资源（游历门票）。
- 村子是副挂机：建筑产出、工匠干活；产基础材料。
- 离线也走：8 小时封顶；上线一口收。
- 挂机不替代游历：只产资源，不自动通关。

### 15.4 离线

- 离线 ＝ 退出模式：世界不推进、灵草不长、NPC 不动、牢房不烧。
- 只有塔 / 村子在产：行动资源、银两、木料、经验；8 小时封顶。
- 回来：一口收 + 离线汇总；世界还是走时的样子。
- 不惩罚离线：没有“错过一天就亏”；只有“少挂几小时”。
- 离线汇总例：塔推到 37 层，产行动资源 240、银两 180、木料 40。

### 15.5 一句话

**游历是“出门”，塔和村子是“在家”；离线是“家里还在过日子，外面按了暂停”。**
