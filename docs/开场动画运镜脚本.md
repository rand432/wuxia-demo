## 二、叙事设计

**视点**：第一人称追述。全片旁白是**主角自己在回忆**；**最后一句换成一位老人** —— 暗示这是很多年后有人在讲当年的事。

**七段情绪曲线**：

1. **起**（0–33s）天下病了 → 荒原流民 → 纸醉金迷 → 他把刀擦了又擦
2. **承**（26–47s）一身武艺换了个人情 → 守着门 → **走出门的人变成了他自己**
3. **转·黑幕**（52s）「这酒，你喝还是不喝？」→ 碎杯 → 喊杀
4. **转·厮杀**（55–72s）我们的混战 → 《剑意》0:07–0:13 → 靠树喘息 → 坠崖
5. **转·师父**（72–86s）黑幕「我要死了吗？」→ 师父出现 → 五问
6. **合**（86–108s）师门焚毁 → 刀插地 → 黑幕「不甘心」→ 那只手
7. **收**（107–135s）《剑意》酒肆行侠 → 刀光小舟 → **一笔墨路**（老人旁白）

## 三、铁律（血泪换的）

1. **视频提示词必须每条都带画风锚** —— 「中国水墨画风格…不是真人实拍，不是照片，不是3D渲染」。
   漏了它，模型就按写实先验跑（04/05/08 第一版全成了实拍）。
2. **草图自己得先是"画"** —— 模型会照描，示意图只能得到示意图。
3. **denoise 分档**：0.5–0.6 求精确（手、器物），0.7 求发挥（场景、人群、火）。
4. **角色一致性靠"定版图 + 程序合成"**，不靠提示词。
5. **以物代事** —— 不拍事件，拍事件的痕迹（手、酒渍、门缝、一只脚）。
6. **借来的片段必须统一调色**，否则"两张皮"。
7. **`libtv download --without-ai-watermark --vip`** —— 水印是下载时加的，不是烧进文件的。
8. **借用素材必须逐帧检查有没有"自带字幕卡"** ——
   《剑意》在 1:14–1:16 有一张黑屏卡「师弟，江湖风波险恶…」，
   被切进了 69–75s 的片段里带进成片。**查自己的字幕没用，得查素材本身。**
   切段前先 `ffmpeg -vf "crop=...:fps=2,tile=..."` 扫一遍字幕区。

## 四之二、声音设计（v11）

**原则**：独白 + 音效 + BGM + 画面是**一个整体**。该留白留白，该加音效加音效，该音乐音乐。

| 段落 | 响度 | 独白 | 音效 | 音乐 |
|---|---|---|---|---|
| 01 墨入水 | −23.5 | 天下病了 | 一滴墨 → **留白** | 4.5s 后 `乐_起` |
| 02 荒原流民 | **−19.5** | 王在宫里互砍 | **8 层编曲**：风沙 + 推搡 + 脚步 + 哀鸣 + **老人咳嗽** + **婴儿啼哭** + **病痛哀嚎** + **有人倒地** | `乐_起` |

**做"距离感"的公式**（`audio_mix.json` 的 `af` 字段）：
```
volume='max(0.05,1-t/9)':eval=frame,lowpass=f=3000
```
音量线性衰减 + 低通滤波 —— **只衰减会像"拧小音量"，加了低通才像"远了"**。

**人声电平逐条归一化**：生成素材原始电平相差 30 dB（最轻的 −47.6 dB），
现在全部落在 **−20 ~ −24 dB**。改人声素材后必须重新测并更新 `audio_mix.json` 的 `vol`。

## 四之三、配音要「要情绪」，不能「描述状态」（v19 教训）

**反例**（得到平淡朗读）：
> 一个年轻男人虚弱地喃喃自语，气息很弱，几乎是在哭：师父，我好想你…

**正例**（得到颤音与哭腔）：
> 一个年轻男人**濒死之际的哭喊**。声音**剧烈颤抖**，带着**浓重的哭腔和鼻音**，
> 气息**断续**，一句话要分好几次才说得出来，越说越**哽住**，最后几乎变成**呜咽**：师父……我好想你……

**区别**：前者在描述"他是什麼状态"，后者在**直接要声音的物理特征**（颤抖 / 哭腔 / 断续 / 哽住）。

| 句子 | 要不要情绪 |
|---|---|
| 旁_01–07（追述） | **克制**，只 04 / 06 带一点自嘲与苦涩 |
| 声_我1「师父我好想你」 | **最需要** —— 颤音 + 哭腔 + 断续 |
| 声_我2「我应该死了吧」 | 茫然、飘、尾音散掉 |
| 声_我3「我不甘心啊」 | 牙缝挤出、一字一顿、胸腔逼出 |
| 旁_尾（老人） | 留余味、轻轻落下、像叹一口气 |

## 四之五、每段都要「编曲」——自查方法（v20）

**别凭感觉。用程序过一遍每段的"声层数"，薄的地方会自动暴露。**

判据：**一段里同时响着的声音少于 4 层，就是薄的**。

```js
// 伪代码：对每一段，数一数有多少声音元素覆盖它
for (段 of 全片) {
  hit = 全部声音元素.filter(e => e.at < 段.end && e.at + 素材时长 > 段.start)
  若 hit.length <= 3 → 标为"薄"，必须补
}
```

**v20 靠这个查出并修掉的**：
| 段 | 修前 | 补了什么 | 修后 |
|---|---|---|---|
| 婚礼 | 3 层 | 喜房（红烛 + 远处喜宴） | 5 层 |
| 门外护卫 | 3 层 | 宫廷夜（更鼓/风铃）+ **门轴吱呀** | 5 层（−28.3 → −21.1 dB） |
| **师门焚毁** | **2 层** | **火焰燃烧 + 牌匾坠落** + BGM 托底 | 6 层（**−28.5 → −15.3 dB**） |
| 刀插地 | 2 层 | **剑插入土的闷响** + 余火 | 7 层 |

**另一条自查：素材串场。** 长素材（7–30 秒）若只做淡出，会拖进下一段。
用 `dur` 字段**硬截断**（`atrim`），只留 1 秒交叉淡出。
v20 查出 02 荒原的 8 层音效**拖了 6 秒**进"纸醉金迷"。

## 五之二、字幕与配音同步（方法论）

**字幕拆段必须按音频实测的停顿点，不能凭感觉。**

```powershell
ffmpeg -i 旁_06.wav -af "silencedetect=noise=-40dB:d=0.25" -f null -
```

例：`旁_06`（10.1s）实测停顿在 **2.20–3.71s**（1.5 秒的句号停顿），
所以拆段点是 **+3.71**，不是凭感觉写的 +6.6 —— 差 1.4 秒就是"先出声后出字"。

**人声电平同理**：生成素材的原始电平能差 30 dB（实测最轻 −47.6 dB），
必须逐条量、逐条反推增益，否则"声音时大时小"。
