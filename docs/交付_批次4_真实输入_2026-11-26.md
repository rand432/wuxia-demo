## 2. 图形分支覆盖

1. **胜**：真实点击「再来一局」→ 断言切到新战斗场景
2. **败**：真实点击「回主界面」→ 断言切到 `main_home`
3. **快速连点**：同一按钮连续两次真实点击 → 断言只落到一个目标场景
4. **保存失败**：注入损坏的 journal → 真实点击「回主界面」→ 断言仍在结算页可操作；
   恢复写入后再次真实点击 → 断言只切一次
5. **延迟揭幕释放**：`_build_result(true, 0.5)` 建立延迟揭幕 → 立即 `queue_free()` →
   等待超过原定揭幕时刻 → 断言场景已释放、能重新进战斗、无脚本错误

通过标记：`[GRAPHICS] real click replay/home/save-fail/double-click/delayed-release PASS`
