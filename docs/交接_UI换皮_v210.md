## 三、踩过的坑（照做，别重犯）

1. **`Skin` 是引擎内置类名**，`const Skin := preload(...)` 直接报「shadows a native class」→ 改名 `Ui`。
2. **类型推断炸全链**：`var x := _art_cells[3].get_child(0)`（无类型 Array → Variant）会编译失败，
   连锁导致 `menu_sketch.gd` 也失败 → **主界面白屏，只剩牌子在飘**。
   写法：`var x: Node = ...`。
   ⚠ **验收必须查 `menu_sketch.gd`**，单查子面板是干净的，会漏。
3. **卡片和底同色＝白画**：`Ui.card` 第一版填充 `#F5F0E5` 和面板底一样，肉眼完全看不见。
   规矩：卡片必须比底深或浅一档（现在卡片 `#E2DBCC`）。
4. **亮金不能压在宣纸上**：`#F0D68A` 放在 `#EDE7D8` 上几乎隐形（封面书名踩过）。
   纸面上的「金字」＝**墨字描金边**（`draw_string_outline` 金 + 填墨）。
5. **毛笔小字会糊**：Ma Shan Zheng 笔画细，19px 加 2px 描边会被暗边吃掉。
   ≤20px 一律用回常规字体，毛笔只给标题。
6. **刊头不能矮于 78**：标题 34 号从 y18 起，52 高的刊头会把字切掉下沿。
7. **探针输出有延迟**：pwsh 返回时 PNG 常常还没落盘。要 `for` 轮询 `Test-Path`（最多 120 次）。
   并且**每次用不同文件名**（`probe_xx_<随机>.gd`），否则读到上一轮旧图。
8. **探针脚本名不能与已删文件同名**：`write` 会报「file no longer exists」→ 换个名字。
9. 探针用完删掉（`probe_*.gd` 已进 .gitignore，但别留在工作区）。
10. **`E:` 解压出来的素材挡在库外**：`.yingzhi/` 已写进 `.gitignore`；`.yanyu/` 本来就有。
    不然 30 分钟一次的 autocommit 会把 222MB＋585MB 推上 Gitee。

## 六、工作方法（**必须照做**）

```powershell
$godot = 'C:\Users\zq300\Desktop\Godot_v4.7.2-stable_win64.exe'
# ① 解析检查——**永远查 menu_sketch.gd**，它加载全部面板
& $godot --headless --path D:\1\wuxia-demo --check-only --script res://menu/menu_sketch.gd 2>&1
# ② 探针截图（每轮换文件名 + 轮询等文件）
```

探针模板（存 `probe_x.gd`，跑完删）：

```gdscript
extends SceneTree
var frames := 0
var ps: Node = null
const OUT := "res://.shots/x.png"
func _initialize() -> void:
	ps = load("res://menu_sketch.tscn").instantiate()
	get_root().add_child(ps)
func _process(_d: float) -> bool:
	frames += 1
	if frames == 90 and ps != null:
		ps._sc = 0.0          # 切到村景页（封面页是默认）
		ps._hint_used = true
	if frames == 190:
		var img := get_root().get_texture().get_image()
		img.save_png(OUT)
		return true
	return false
```

常用入口：`_open_char_panel()` / `_open_warehouse()` / `_open_shop()` / `_open_out()` / `_open_advance()`。

## 七、用户偏好（这一轮摸出来的）

- **口径**：牌子/功能栏/大碑这类结构改动直接做，做完给图。
