## 三、踩过的坑（v238）

1. `_auto_btn` 原来**根本没上 `_style_btn`**，是 Godot 默认灰钮；这次顺手补上。
2. 绿钮不能用金字——`_style_btn` 按 `base.g > base.r` 判：绿底给米白，其余给 `Ui.GOLD_HI`。
3. 战报小条要加在 `_log_lb` **之前**，否则会把字盖住（Control 后加在上）。
4. 探针退出时 Godot 会报 ObjectDB/资源未释放——是战斗节点未等帧释放的旧现象，不是运行时报错。
