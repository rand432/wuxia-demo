# 「① 乱世」Seedance 2.5 · 30 秒提示词

```
【风格】中国水墨动画短片，宣纸上作画，墨色有浓淡干湿，笔触有飞白皴擦，留白占七成，冷青灰为基调，血红是唯一的暖色。电影感，慢镜头，画面中绝不出现任何文字、数字、字幕或logo。16:9横画幅。

【30秒四个镜头，用墨的形态变化自然串联】

镜头一（0-6秒）：纯黑画面。一滴浓墨自画外坠入一泓清水，墨入水即散，缓缓晕成烟丝状向四周铺开，水中只有一丝冷光。极慢镜头大特写，画面中没有任何人物。
散开的墨丝慢慢填满整个画面，化作——

镜头二（6-14秒）：水墨荒原大远景，一场大饥荒之后的荒原上挤满枯瘦如柴的流民，浩浩荡荡却杂乱无章。人们佝偻着身子相互推挤，有的匍匐爬行，有的伏地不起，有的拄着木杖，有的抱着襁褓，队伍缓慢地向远处挪动。旗帜和破布被风吹得猎猎翻动，尘土与烟尘一阵阵卷起。画面右侧一棵枯死的树，远处地平线上一座低矮的中式城郭，天边一轮血红的残阳是全图唯一暖色。镜头缓慢横移跟拍人流。
风沙漫过整个画面，沙尘化作——

镜头三（14-22秒）：宫殿深处的酒宴，俯视特写。案上摆着一叠残破的书和一只倒下的陶壶，画面正中是两只中国古代的陶制酒盏，宽口浅腹的陶器，盏身厚实、底下只有很短的圈足。两只盏从左右倾斜着举起，盏沿在画面正中相碰，盏里鲜红的酒在相碰的一刻从盏沿炸开溅出，酒液顺着桌沿往下滴。四周安静得诡异，案前空无一人。
镜头极缓推近那滩酒渍，酒渍慢慢扩大，化作——

镜头四（22-30秒）：空无一人的昏暗室内，一个年轻刀客跪坐于地，侧身半剪影，头戴斗笠压低遮去半张脸，双膝并拢跪地，上身挺直如松，双手置于膝上，一手虚按膝前横放的长刀刀鞘。他握着布，一遍一遍缓慢地擦拭刀身，动作极慢极稳，指节泛白。镜头从他身后缓缓绕到侧面，最后停在他的手与刀上。

【节奏】全程缓慢克制，没有快切，没有激烈动作，情绪是压抑的、无声的。
```
