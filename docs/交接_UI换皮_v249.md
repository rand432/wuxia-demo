## 三、踩过的坑（v249）

1. 打开地图面板时 `_hide_for_side()` 已把 `_busy` 置真；［世界］按钮若直接调 `_open_region_panel()` 会被 `if _busy: return` 挡掉——要先放行一次。
2. `_on_map_closed` 原来一律 `_return_village()`；从地图进的世界页取消会直接回村。加了 `_world_from_nav` 标记，取消走"回地图"。
3. 回到地图后要把 `_on_side_closed()` 刚恢复的 HUD 再 `_hide_for_side()` 藏回去，否则地图上会露出顶栏和底部按钮。
4. 地图的"黑"其实是未探索区；不是缩放错。铺暗格比纯黑更像一张图，也不会泄露地形。
5. 这些是 `_nav_layer` 的 `draw_string`，不是 Label；字体只能靠 `UI_FONT` 传进去。
