# 即梦 4 秒 · 两条测试提示词

> 4 秒 ≈ 96 积分。20 元 = 200 积分 = **2 条 4 秒**。每日免费 66 积分 ≈ 1.5 天一条。
>
> **4 秒里只放一个动作、一个运镜**，别塞第二个镜头。

---

## 测试一 · 03 纸醉金迷（验证「掺水」猜测）

**看什么**：它出的是**陶盏**还是**玻璃高脚杯**。

LibTV 上这一镜连着两次都画成玻璃高脚杯 —— 如果即梦一次出对，说明是渠道掺水；如果它也错，说明是模型先验。

```
【风格】中国水墨动画短片，宣纸上作画，墨色有浓淡干湿，笔触有飞白皴擦，留白占七成，冷青灰为基调，血红是唯一的暖色。电影感，慢镜头，画面中绝不出现任何文字、数字、字幕或logo。16:9横画幅。

宫殿深处的酒宴，俯视特写。案上摆着一叠残破的书和一只倒下的陶壶，画面正中是两只中国古代的陶制酒盏，宽口浅腹的陶器，盏身厚实、底下只有很短的圈足。两只盏从左右倾斜着举起，盏沿在画面正中相碰，盏里鲜红的酒在相碰的一刻从盏沿炸开溅出，酒液顺着桌沿往下滴。

镜头固定，相碰的瞬间画面轻微一颤，之后极缓推近那滩酒渍。四周安静得诡异。
```

## 测试二 · 07b 混战中刀（看运动质量）

**看什么**：4 秒里动作连不连贯、人物有没有变形、刀光干不干净。

```
【风格】中国水墨动画短片，宣纸上作画，墨色有浓淡干湿，笔触有飞白皴擦，留白占七成，冷青灰为基调，血红是唯一的暖色。电影感，慢镜头，画面中绝不出现任何文字、数字、字幕或logo。16:9横画幅。

水墨画，一个头戴斗笠的年轻刀客被七八个纯黑的剪影从四周围攻，那些敌人只有墨黑的轮廓与刀影，没有五官没有细节。他在画面正中挥刀格挡，刀锋划出一道纯白的弧线，墨点向四周飞溅。

镜头快速环绕他半圈，配合他的一次转身。动作干净利落，水墨飞溅。
```

## 判断标准

| 看到什么 | 结论 |
|---|---|
| 陶盏对了、笔触干净、动作连贯 | ✅ **这条路通** → 开火山引擎 API 出全片 |
| 陶盏对了，但动作糊 | ⚠️ 画质够、运动不够 → 试试 2.5 |
| 还是玻璃高脚杯 | ❌ **是模型先验问题，跟渠道无关** → 这段得换设计思路 |
| 完全不像水墨 | ❌ 提示词风格锚没吃住 → 加重风格描述再试 |
