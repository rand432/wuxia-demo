## 三、踩过的坑（v253）

1. 斑点用固定算式（`si*137 % 660` 等），不要用 `randf()`，否则每帧重绘会闪。
2. 未探索格的明暗差必须压得很低（≤0.02），否则会像"有地形"，泄露未探索信息。
3. 纸面斑点只画在纸面区域，不画到地图视口里，免得和格线混在一起。
