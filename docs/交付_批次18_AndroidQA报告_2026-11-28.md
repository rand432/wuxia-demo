## 1. 差异

`tools/android_qa_device.ps1` 重写判定：

- 初装 / 覆盖安装分开：未预装走初装，`覆盖安装存档保留` 记 SKIP，不再把「已安装」当失败
- 覆盖安装前记录 `max_unlocked` 与 `first_clear[<CheckLevel>]` 的实际值，安装后逐项比对；测试档缺失或字段缺失记「覆盖存档用例未执行」SKIP；值变化记 FAIL
- 安装失败：保存 `install_fail.txt` 与 `install_fail_logcat.txt`，返回非零
- 每次运行独立目录 `.shots/android_qa_device/<时间>/`，内含 `report.md`、`results.json`、`screen_cold/resume/relaunch.png`、`logcat.txt`
- 「命令发出」与「进程到前台」分开：冷启动、HOME 返回、force-stop 重开各记 命令 / 进程(pidof) / 前台(mResumedActivity) 三项
- 记录设备序列号、型号、Android 版本、APK SHA-256；logcat 扫描 `FATAL EXCEPTION` / `ANR in com.wuxia.demo.qa`
- 结果分级 PASS / FAIL / SKIP；任一无设备/跳过不影响退出码，出现 FAIL 才返回 1
