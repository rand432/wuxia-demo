## 工具（可直接用）
```
tools/w3x/mpq.mjs        MPQ v1 读取器：哈希表/块表（含标准 key 解密）、zlib / PKWARE (explode) 解压、
                         单扇区/多扇区、加密块与 FIX_KEY、w3i 与 wts 解析（UTF-8/GBK 自动判别）
tools/w3x/pkw.mjs        PKWARE DCL explode（从 StormLib pklib/explode.c 移植，binary 模式）
tools/w3x/w3x-extract.mjs 命令行：解包一张地图
tools/w3x/scan.mjs       批量扫描目录内所有地图 → tools/w3x/map-index.json
```

用法：
```
node tools/w3x/w3x-extract.mjs <地图.w3x> <输出目录>
node tools/w3x/scan.mjs          # 扫 D:\1\魔兽争霸3冰封王座\Maps
```

抽出内容：`war3map.w3i`（图名/作者/描述）、`war3map.wts`（全部游戏内文本 → `strings.txt`）、
`war3map.j/lua`（JASS 脚本）、`war3map.wtg/wct`（触发器）、`war3map.w3u/w3t/w3a/w3h/w3b/w3d/w3q`
（单位/物品/技能/科技/破坏物/装饰/升级）、`(listfile)`、地形/小地图等。

## 已知限制
- PKWARE **ASCII 模式**（ctype=1）未实现——MPQ 实际只用 binary 模式。
- 受保护地图：哈希表/块表可解，但若数据块用非标准 key 加密（本机 17 张属此类）则 w3i 读不出。
- MPQ v4（>4GB / Reforged）只做了基础兼容。
