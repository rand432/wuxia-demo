## 三、踩过的坑（v228）

1. `_bar()` 的高光是一条**固定宽度的顶线**，不跟填充宽度走——它表示"槽的金属边"，
   不是"已填充量"；以后若想改成随填充走的亮边，要把它挂到 fill 的尺寸变化里。
2. 血条颜色由 `hp_color(ratio)` 每帧改（绿→黄→红），**不要**在 `_bar` 里把它覆盖成金色。
3. 头像框是在 `av` 之前 `_panel()` 的，层级正好在头像下面；顺序反了会把头像盖住。
