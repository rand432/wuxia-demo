## 〇、一句话现状

- 困兽 v2 的「卡组」页，十张卡从 **2×5 格子**改成 **一道浅弧的扇形手牌**：
  - 以卡片底边中点为轴，十张卡沿弧线排开，角度从 −0.234 到 +0.234 弧度；
  - 卡与卡横向叠压（步长 52），每张露出左侧一条；
  - 收窄的露出条上补一枚 **卡名首字**（朱砂大字，压在卡名与图标之间的空带），一眼认得出是哪张；
  - 色带字改**左对齐**，扇形里露出的是「力量/踏云/铁壁…」的开头，不再是居中切出来的碎片。
- **换卡模式仍是格子**（`_pending_card != ""`）：那种场景每张卡下面要挂［换这张］，扇形会互相压住。
- 点击：命中钮放在旋转的 holder 里，跟着卡一起转；点露出的条即可开详情。

## 三、踩过的坑（v216）

1. **替换函数时把"return 之后的死代码"切了一半**：原 `_fill_deck_slots` 末尾有一整段
   `var tip := Label.new()…`（永远跑不到），我的 old_string 只切到 `return`，`var tip` 被带走、
   后面 `tip.xxx` 留下 → `Parse Error: Identifier "tip" not declared`。
   **改大函数前先把"return 之后还有没有东西"看一眼**；这次直接删掉了那段死代码。
2. 旋转卡面：**卡面是普通 Control，不是 Button**。要转就包一层 `holder`，`pivot_offset` 设成底边中点，
   命中钮放进 holder（跟着转），否则点在旋转后的位置对不上。
3. 十张卡挤在 640 宽里必然叠得很厉害：只靠"露出左边一条"会看到空白。
   两招：**色带字左对齐** ＋ **露出条补卡名首字**。
4. 换卡模式不能扇形——每张下面的［换这张］会被下一张压住，所以保留格子。
