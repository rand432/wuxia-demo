# 拼接指南（不用写代码）

> 目标：把 `assets/kit/` 里的素材，像贴纸一样摆进场景里。
> 你只做"摆位置"这件事，**接进游戏那步交给我**。

---

## 一、先打开这个文件

1. 打开 Godot → 打开工程 `D:\1\wuxia-demo`
2. 左下角「**文件系统**」面板里找到 `scenes` 文件夹
3. **双击 `拼场景.tscn`** —— 这就是给你准备的"拼接场地"

打开后你看到四块：

| 位置 | 是什么 |
|---|---|
| **左侧 · 文件系统** | 素材都在这（`assets/kit/`），往下看有分类说明 |
| **中间 · 2D 视图** | 就是画布，你要在这里摆东西 |
| **右侧 · 检查器** | 选中某个东西后，这里能看/改它的数值（位置、缩放） |
| **顶部 · 工具栏** | 有 Q / W / E 三个按钮，管"选中/移动/缩放" |

---

## 二、把图拖进去（核心动作，就一步）

1. 左侧「文件系统」点开 `assets` → `kit` → 比如 `build`
2. 看到 `house_cottage.png` 这些图 —— **用鼠标把它拖到中间的 2D 视图里松手**
3. 松手后它就在场景里了，**这是 Sprite2D 节点**（画面上的一个图层）

重复这个动作，想要几件拖几件。

---

## 三、摆位置 / 改大小

- **移动**：按 `W`（或点顶部工具栏的移动按钮），拖动图上的箭头
- **缩放**：按 `E`，拖角落的方块；或者右侧检查器里直接改 `Scale` 的 x / y
- **精确摆**：选中图 → 右侧检查器 → `Position` 填数字（x 往右、y 往下，屏幕是 720×1280）
- **谁盖住谁**：选中图 → 检查器里找 `Ordering` → `Z Index`，数字大的盖在上面
- **删除**：选中按 `Delete`

> 💡 图看着太大/太小是正常的：素材原始尺寸和游戏尺寸不一样，用 `Scale` 调。
> 参考：草屋 `scale=2.4`、树 `scale=2.0` 是我调好的样例，照着感觉调。

---

## 四、保存 & 让游戏用上

1. `Ctrl + S` 保存（保存的就是 `拼场景.tscn` 这个文件）
2. **想让它出现在真正的主界面/村子里**：跟我说一声"把拼场景接进主界面"，
   我来接（大概是把你摆的节点搬进 `menu_village.gd` 那一层）

## 六、几个坑（踩过）

1. **拖进去看不见**：可能是图太小或在画面外 —— 检查器里把 `Position` 改成 `x=360, y=640`（屏幕正中）
2. **图糊了**：别用缩放硬拉，宁可告诉我"要多大"，我按尺寸重新出图
3. **改完游戏里没变**：游戏要**重开**才生效
4. **别动** `素材/` 那个大文件夹（922MB，我已经让 Godot 忽略它了，只当仓库用）；
   要用的图**都已经抠好放在 `assets/kit/` 里**了
