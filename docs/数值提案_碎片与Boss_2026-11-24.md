# 数值提案 · 碎片产出与 Boss 上限（2026-11-24）

> 两处都是「改指数不如改产出/阀门」的问题。先给数字，等你选方案再动手。

## 一、请神碎片：全流程只够升 1 星

**现状数据**

| 角色 | 当前碎片来源 | 可升星 |
|---|---|---|
| 主角 zhujue | 初始 60 + L8 首通 30 = **90** | 1 星（每星 60） |
| 柳卿卿 / 青鸾 / 小乞儿 / 滚地龙 / 明珠 | **0** | 0 星（按钮永远灰） |

**消耗**：每星 60 碎片 + 500 文钱；5 星满 = 300 碎片/人，六人共 **1,800** 碎片。
**供给**：90。缺口 95%。

**方案**

| 方案 | 做法 | 首通后总量 | 复刷 |
|---|---|---|---|
| A（最小） | L8/L9/L10 首通给**全员** 30 / 45 / 60 碎片 | 主角 225、其余 135（约 2 星） | 无 |
| B（推荐） | A + 复刷 L8+ 每次 +5 碎片（该关对应角色） | 同上 | 有长线 |
| C（大改） | 把碎片改成通用货币（「香火」），黑市/奇遇产出 | 可调 | 可控 |

我倾向 **B**：不动已有首通结构，只补产出点，复刷有动力且不爆量。

## 二、Boss 上限：后期没有压力

**现状**（`kushou/kushou_battle.gd`）

- Boss 单下伤害 ≤ 主角气血上限 **5%**
- Boss 血量 ≤ 主角 **20 秒 DPS**

**后果**：自动跑测 L5–L7、L9、L10 收尾满血；「关卡变硬」在体感上不存在。

**方案**

| 方案 | 阈值 | 风险 |
|---|---|---|
| A | 维持 5% / 20s | 后期继续无压力 |
| B（推荐） | L1–6：5%/20s；L7–8：6.5%/25s；L9–10：8%/30s | 中；只影响后四关，可回滚 |
| C | 全关卡线性 5%→9% / 20s→35s | 高；前六关也会变难，教学节奏受影响 |

建议先上 **B**，跑 `run_playthrough 1-10` 看收尾气血与用时，再决定是否加码。
