## 三、踩过的坑（v214）

1. **抽屉要建在面板最后**（`_panel.add_child(_drawer)` 在所有控件之后），否则会被格子/礼包条盖住。
2. `refresh()` 必须在列表变化时 **`_close_drawer(true)`**——不然抽屉里那件可能已经不在新列表里，`_drawer_idx` 越界。
3. 抽屉的两个钮是复用的：`_drawer_idx` 指当前那一件；**材料/丹药要 `_drawer_btn2.visible = false`**，不然"知道了/关闭"两个钮干同一件事。
4. 品级色条不是 StyleBox 的边（StyleBox 不能单边换色），是格子里单加的一条 **ColorRect**（y=CELL-4，高 3），刷新时按 `ItemIcons.quality_col_of` 上色。
5. `Ui.panel` 的角标会画出四角 L 标；抽屉只有 320 高，角标臂长 14 刚好，不要加大。
