## 三、踩过的坑（v221）

1. `hide_panel` 只对 `visible` 的面板生效；面板自己的 `close()` 里**别提前**把 `visible=false`，
   否则 helper 直接返回、等于没做动画。
2. 收起期间面板还 visible——这是故意的，防止 0.13s 内点到背后。别把这个当成"面板没关"。
3. 全局点击音是 `node_added` 事件挂的：**已经存在的 Button 不会补挂**（本场景里 Button 都在
   `_ready` 之后才建，所以全覆盖；以后若有 .tscn 里预放的 Button，要手动挂一次）。
4. 三个面板的 `close()` 都还有自己的 `closed.emit()`，现在信号立刻发、画面 0.13s 后才消失；
   这三个面板当前没人监听 `closed`，所以没影响。
