# 批次 15 准备 · Android QA 安装与生命周期用例入口

对应交接：`docs/交接_DeepSeek战斗界面工程任务.md` 第十五批。当前无 ADB 设备，本批只交付可复用入口与结果清单，真机验收留待设备接入。

## 1. 新增

`tools/android_qa_device.ps1`：

- 参数：`-Adb`（默认 `D:/Android/platform-tools/adb.exe`）、`-Apk`（默认在 `.shots/qa` 下取最新 QA APK）、`-Serial`、`-OutDir`
- 无设备时输出 `DEVICE=0 SKIP=1` 与报告，退出码 0（明确区分“工具已生成”和“手机验收未执行”）
- 有设备时按顺序执行并逐项记 PASS/FAIL：
  1. 已安装 QA 包检测 + 安装前 `level_state.cfg` 长度
  2. `adb install -r` 覆盖安装（同包名 `com.wuxia.demo.qa`）
  3. 覆盖后读存档并核对 `first_clear|max_unlocked` 可读
  4. `force-stop` → `monkey` 冷启动 → 截图
  5. HOME 切后台 → 重新进入
  6. `force-stop` 杀进程 → 重开
  7. 拉取 800 行 logcat，检查 `FATAL EXCEPTION` / `ANR in com.wuxia.demo.qa`
- 每次运行生成 `report_<时间>.md`、`results_<时间>.json`、`cold_<时间>.png`、`logcat_<时间>.txt` 到 `.shots/android_qa_device/`

## 3. 设备接入后的操作

```
powershell -ExecutionPolicy Bypass -File .\tools\android_qa_device.ps1
# 或指定包/序列号
.\tools\android_qa_device.ps1 -Apk .shots\qa\<runId>\wuxia_qa_android.apk -Serial <serial>
```

仍需人工补：底栏抽卡/请神/宝物/玉壶、主界面到第六关、胜败结算、安全区与系统返回、多次进出战斗后的音乐与面板状态。脚本已留截图与 logcat 落点。
