## 〇、一句话现状

- **右栏退休两个一次性入口**：`cave`（山洞）和 `treasure`（藏宝阁）不再常驻右栏。
- 改成 **画里的白纸牌**（`page: village`，跟着画卷走）：
  - **藏宝图**：在 `map_found && !b2_built` 时出现，位置 (0.660, 0.660)，"照图起一间 · 木料 x/8"；
  - **山洞**：在 `b2_built && !cave_opened` 时出现，位置 (0.660, 0.560)，"扒开荒草 · 木料 x/6"。
- 用掉后直接 `set_vis(false)`，不留"洞里很凉 / 图收在里头"的死按钮。
- **后山**：白狐＋青隼都收完就隐藏（`hill_done`），不再留"白狐的老家"占位。
- 右栏 `layout_rail` 自动补位：开局通常只有 **商店/困兽** 两格；山洞过完后 **百工坊** 顶上第三格。
