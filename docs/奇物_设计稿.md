# 奇物 设计稿

> 2026-11-11 讨论稿（未开始实现）· 依据：`kushou/battle_ui.gd` 现有「玲珑玉壶」实现、`menu/partner_home.gd`（请神页）版式、`shared/ui_kit.gd` 骨架
> 状态：设计与页面版式已过目；强化材料、奇物来源**暂不设计**；本稿不改代码

## 〇、一句话

**奇物 = 一局只能带一件的「破规则道具」**：不做纯数值（那是羁绊），全部自动触发、玩家不操作；局外可按固定 5 级路线强化。

## 一、核心规则

| 项 | 结论 |
|---|---|
| 携带数量 | **单槽，一局只能带 1 件**（局外选择，局内不能换） |
| 触发方式 | **全部自动**：主动型 = 自动触发 + 冷却；被动型 = 常驻 |
| 强化 | **局外强化，固定 5 级路线，不可洗点** |
| 强化材料 / 奇物来源 | **暂不设计**（本稿留空） |
| 强度基准 | Lv1 ≈ 1 张羁绊 · Lv3 ≈ 2 张 · Lv5 质变 |
| 数值边界 | 不做纯数值件；恢复「命」不设上限；刷新类必须封顶 |

### 自动触发两条铁律

1. **永不亏**：触发条件要写"智能"（血量/怪数/是否有读条），不能"冷却好就放"
2. **看得见**：每次触发都要有格子闪光 + 音效 + 轻微画面反馈，否则玩家会忘了自己带了奇物

## 二、奇物目录（15 件）

> 图标先用字形占位（壶/葫/剑…），后续换道具美术，版式不动。

### A. 保命线

**玲珑玉壶** · 主动 · 自动 CD 60s · 格闪 + 治疗光 + `drink`
触发：气血 ≤30%，或 ≤50% 且有怪贴身。

| 级 | 效果 |
|---|---|
| 1 | 气血 +25%、内力 +25% |
| 2 | 回复量 25% → 30% |
| 3 | 喝完后 4 秒内受到伤害 −20% |
| 4 | CD 60 → 45 秒 |
| 5 | 气血低于 15% 时额外触发一次（不占 CD，每局 1 次） |

**续命灯** · 被动（清波结算）· 文钱浮字 + 金色光
触发：每清波自动结算。

| 级 | 效果 |
|---|---|
| 1 | 每清 3 波，命 +2 |
| 2 | 每清 2 波，命 +2 |
| 3 | 首领击杀：命 +5 |
| 4 | 每清 2 波，命 +3 |
| 5 | 每清 1 波，命 +2 |

> 恢复「命」**不设上限**：带续命灯 = 把"命的压力"换成"清波速度的压力"。

### B. 输出线

**血葫芦** · 主动 · 自动 CD 45s · 格闪 + 红色气浪 + 低音鼓
触发：气血 ≤70% 且 300px 内有怪。

| 级 | 效果 |
|---|---|
| 1 | 8 秒内攻击 +60%，代价：烧当前气血 10% |
| 2 | 持续 8 → 11 秒 |
| 3 | 期间每击杀延长 0.6 秒（最多 +4 秒） |
| 4 | 攻击 +60% → +80% |
| 5 | 代价改为「已损气血的 10%」（越残越省） |

**铜钱剑** · 被动 · 出镖一声"叮"
触发：常驻（普攻附带）。

| 级 | 效果 |
|---|---|
| 1 | 普攻附带 1 枚铜钱镖（射程 +120px，伤害 35%，不消耗文钱） |
| 2 | 伤害 35% → 45% |
| 3 | 每 3 次普攻额外补一枚 |
| 4 | 射程 +120 → +200px |
| 5 | 穿透 1 个目标，第二目标吃 50% |

**醉翁壶** · 被动（击杀触发）· 状态图标 + 酒红气
触发：每累计击杀 10 只。

| 级 | 效果 |
|---|---|
| 1 | 进入「醉」8 秒：攻击 +30%、攻速 +10% |
| 2 | 持续 → 10 秒 |
| 3 | 醉期间暴击率 +10% |
| 4 | 攻击 +30% → +45% |
| 5 | 醉期间每次暴击延长 1 秒（最多 +5 秒） |

### C. 控制线

**惊堂木** · 主动 · 自动 CD 35s · 格闪 + 定格特效 + 木击声
触发：场上 ≥2 只怪；优先选**正在读延迟技**的怪。

| 级 | 效果 |
|---|---|
| 1 | 最近的怪定身 2 秒，可打断延迟技 |
| 2 | 定身 → 2.5 秒 |
| 3 | 定身期间受到伤害 +30% |
| 4 | 同时定身 2 只 |
| 5 | 定身结束时炸一次 80% 攻击的冲击 |

**寒玉扳指** · 被动（暴击触发）· 冰屑粒子
触发：暴击时给目标叠「寒」。

| 级 | 效果 |
|---|---|
| 1 | 暴击叠 1 层「寒」：减速 10%，持续 3 秒 |
| 2 | 3 层冻结 0.8 秒 |
| 3 | 冻结期间受到伤害 +25% |
| 4 | 减速 10% → 15% |
| 5 | 冻结结束时冰屑炸开，对周围 60% 伤害 |

### D. 经济线

**聚宝盆** · 被动（清波结算）· 文钱跳数字 + 金色浮字

| 级 | 效果 |
|---|---|
| 1 | 每清一波 +3×波数 文钱 |
| 2 | +3 → +4×波数 |
| 3 | 每波结束 10% 概率 +1 灵晶 |
| 4 | +4 → +5×波数 |
| 5 | 文钱 ≥1000 时，每波额外 +2% 当前文钱 |

**万应符** · 被动 · 刷新按钮旁"+N"角标
> 五种刷新：抽卡 / 宝物 / 请神 / 进阶 / 挑战奖励。

| 级 | 效果 |
|---|---|
| 1 | 五种刷新各 +1 次 |
| 2 | 各 +2 次 |
| 3 | 每波结束随机给某一种刷新 +1 |
| 4 | 各 +3 次 |
| 5 | 刷新有 25% 概率不消耗次数 |

> **封顶规则**：次数加成与"不消耗"取一，不允许叠出无限刷新。

## 三、局外页面（奇物页）

**完全复用主界面的顶栏与底栏**，只做两件事：
1. 底栏**增加一个「奇物」页签**并重排版

## 五、与现有系统的关系

| 系统 | 关系 |
|---|---|
| 羁绊（16 张宝物） | 羁绊管数值成长，奇物管规则/装置/经济 —— **不重叠** |
| 挑战 | 奇物可以影响挑战收益（聚宝盆/万应符），但不替代挑战 |
| 奇遇 | 镇魂铃是唯一关联件；奇遇本身无队列 |
| 命 | 续命灯无限续命 → 难度压力转移到"清波速度"，波数设计时需配套 |
| 经济（文钱/灵晶） | 聚宝盆、铜钱剑读取经济数据，但**不消耗**关键资源（铜钱剑已改为不花钱） |
