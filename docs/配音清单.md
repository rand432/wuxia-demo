# 配音清单 · 命名与接线

> v82 建的系统。**音频文件一放进 `assets/voice/` 就会自动播**，不用改代码。
> 系统对缺文件**静默跳过**——没录的地方照常走文字，不会卡。

---

## 一、命名规矩

```
assets/voice/<说话人>_<两位序号>.ogg
```

| 说话人 | 前缀 | 例 |
|---|---|---|
| 旁白 / 独白 | `narr` | `narr_01.ogg` |
| 主角（江湖新客）| `player` | `player_01.ogg` |
| 陈石 | `chenshi` | `chenshi_01.ogg` |
| 苏青鸾 | `qingluan` | `qingluan_01.ogg` |

格式：**Ogg Vorbis**（Godot 原生支持，mp3 也能放但 ogg 更稳）。
```powershell
ffmpeg -i 录制.mp3 -ar 44100 -ac 1 -c:a libvorbis -q:a 4 assets/voice/narr_01.ogg
```

## 二、代码怎么调

```gdscript
const Voice := preload("res://shared/voice.gd")
Voice.say("narr", 1)          # 旁白第 1 句
Voice.say("chenshi", 3)       # 陈石第 3 句
Voice.say_file("player_02")   # 直接按文件名
Voice.stop()
Voice.has("narr_01")          # 这一句录了没
Voice.timing_bonus("narr", 1, 1.5)   # 这句该停多久（按音频长度算，没录就返回 1.5）
```

**已经接好的地方**：开场五页（每翻一页念 `narr_01`~`narr_05`）。

## 五、两条通道的实测结论（2026-10 更新）

### MiniMax（原方案）
- 配置：`https://api.minimax.io` ＝ **国际站 ＝ 美元计价**（用户："这玩意是美元啊"）
- 直连接口实测：`status_code=1008 insufficient balance` → **账户余额不足**
  （端点本身是对的：换国内站会报 `2049 invalid api key`，说明这枚 key 是国际站的）
- 想省钱：改用**国内站** `https://api.minimaxi.com`（人民币、送新人额度）
  —— 需要在 platform.minimaxi.com 重新注册拿 key，然后改渠道的 `apiUrl` 即可，代码不用动

### Edge TTS（免费方案，实测走不通）
- 原理可行（Node 24 自带 WebSocket，`tools/edge_tts.mjs` 已写好），但微软 2025 年起
  给这个接口加了 **DRM / 令牌校验**：`Sec-MS-GEC` 算对了、握手头也带全了，
  **仍然一律 403**（三个客户端版本串都试过）。`edge-tts` 那个 Python 包现在同样是 403。
- 结论：**这条路暂时别指望**，工具留着（`tools/edge_tts.mjs`），哪天微软松了就能用。

### Windows 自带语音（免费·即时·音质一般）
- `Microsoft Huihui Desktop`（zh-CN 女声）——**已经用它把开场五句录进 `assets/voice/`** ✔
- 音质是"能用"级别，不是"好听"。等 MiniMax 通了直接覆盖同名文件即可。

## 六、⚠ 原卡点记录：MiniMax 余额（已查明）

实测：**所有模型**（speech-2.8-hd / 2.6-hd / 02-hd / 01-turbo）× **所有音色**
（male-qn-qingse / female-shaonv / audiobook_male_1）**全部失败**，
错误只有一句 `Audio generation failed.`——没有细节。

排查方向（按可能性排）：
1. **密钥/额度**：MiniMax 控制台看一眼这枚 key 还在不在、余额够不够；
2. **区域端点**：现在配的是 `https://api.minimax.io`（**国际站**）。
   如果 key 是**国内站**（minimaxi.com）注册的，端点要换成国内那个——这是最常见的一条；
3. 换一个 TTS 渠道（ElevenLabs 等）也行——插件支持多渠道。
