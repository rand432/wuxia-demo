# 批次 21 交付 · Android 覆盖安装使用真实存档格式（P1）

对应交接：`docs/交接_DeepSeek战斗界面工程任务.md` 第二十一批。

## 1. 真实格式对齐

隔离档实际内容（`%APPDATA%/wuxia-audits/cand19/wuxia-regression/level_state.cfg`）：

```
[levels]
version=2
current=6
max=10
first_clear={}
tutorial_done={...}
```

脚本改为先截取 `[levels]` 段，再解析 `max`（不是 `max_unlocked`）与 `first_clear={...}` 内 `"<关卡>": true/false`；缺字段不再与「初装」混在一起。

## 2. 安装前包名核验

- 新增 `-Aapt2`（缺省自动取 `D:/Android/build-tools` 最新版），安装前 `aapt2 dump badging` 校验包名必须为 `com.wuxia.demo.qa`
- 用正式包 `D:/1/wuxia-export/wuxia.apk` 测试：退出 **2**，不进入安装

## 3. 判定

- 初装（未预装）：跳过覆盖对比（SKIP），其余安装/启动照常
- 安装前样本缺 `max` 或目标关卡 `first_clear`：SKIP「覆盖存档用例未执行」
- 覆盖后读取失败、字段消失、值变化：一律 **FAIL** 并返回 1（不再把丢字段误记 SKIP）
