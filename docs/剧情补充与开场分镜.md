## 第二部分：开场分镜 · 详细脚本（古风水墨 · 约 115 秒）

> **v3 大改（2026-09-27）**：本部分按实际出图结果重写。凡标【v3 改】的，都是看了成图之后改的，
> 与原 v2 不同。**可信度最高的一节是"〇之二 制作管线"——那四条铁律是踩坑踩出来的。**

### 〇、全片总则（v3 · 照此统一，别破）

- **画幅**：1664×928（16:9）。**帧率**：24fps。**总长**：约 **115 秒**（07 扩写为七段之后）。
- **画面**：中国古风水墨；**宣纸质感**（暖白底 + 纸纤维，别用纯白）；浓淡墨五层；**大面留白**；
  **冷青为底**；**血红为唯一暖色**（唯一例外见 07d 的橙金火光）。
- **人物（【v3 改】重要）**：原设"**人物一律剪影、无五官细节**"**已废止**。
  原因：实测压不住（LoRA 先验就是画脸），且与情感表达冲突（参考片《剑意》恰恰靠一张老妇人的脸立住情感）。
  改为 —— **半写实人物**，全片以 `assets/gen/keyframes/00_主角定版.png` 为**唯一权威外观来源**。
- **转场**：以**墨晕转场**为主（上一镜的墨迹化开成下一镜的物形）；07d 焚门允许硬切；08→09 允许一次硬切。
- **字幕**：旁白以**竖排瘦硬字体**出现在画面左侧留白处；无 logo、无其他文字。
- **声音**：箫为主、雨声垫底；07 段全程雨声；08 一声鼓；10 起加入极轻的人声气音。

### 〇之二、制作管线（【v3 新增】四层，每层的"谁说了算"必须明确）

| 层 | 工具 | 谁说了算 |
|---|---|---|
| ① **构图** | `tools/make_sketches.ps1` 程序画构图草图（1664×928） | **构图归我们** |
| ② **关键帧** | LiblibAI `tools/gen_keyframes_liblib.mjs`（草图当垫图，img2img） | **风格归水墨 LoRA，人物归定版图** |
| ③ **视频** | LibTV 图生视频 / 混合参考（Wan 3.0 等） | **动势与质感归参考素材，内容归我们的关键帧** |
| ④ **终剪** | ffmpeg | 转场、字幕、声轨 |

**四条铁律（全部是踩坑踩出来的，别再犯）**

1. **草图自己得先是"画"，不能是"示意图"。**
   模型会**照描**草图：给它几何图形，就得到几何图形；给它带飞白的笔触，才得到水墨。
   ——反面教材：03 曾出过一张"四条均匀黑色斜条"，被用户一眼看出"很违和"。
2. **denoise 分档**：需要**构图精确**的（物件特写、手、器物）用 **0.5–0.6**；
   需要模型**自由发挥**的（大场景、人群、火焰）用 **0.7**。denoise 越低越听话、也越"描图"。
3. **主角一致性靠"定版图 + 程序合成"**，不能只靠提示词。
   做法：从 `00_主角定版.png` 抠出正面/背影人形 → 用 `tools/composite_crowd.mjs` 贴进该镜草图 → 再垫图出图。
4. **以物代事**：不拍事件，拍事件的**痕迹**。
   纸醉金迷＝几只碰杯的手＋酒渍＋垫桌脚的残书；婚礼＝门缝一线红光＋门外一双脚；
   没死＝黑暗中一只手扒住岩壁。**画面里不出现人，只出现人做过的事。**

**已知未解 / 妥协点**
- 水墨 LoRA 有强先验（人物偏"体面"、爱给斗笠），提示词压不动；要彻底解决需换底模或降 LoRA 权重。
- `FillPath` 偶发不生效 → 大面积填墨一律改用**密集墨块铺面**。
- LiblibAI 单张 ≈ 18–19 分；失败不退（LibTV 失败退分）。
