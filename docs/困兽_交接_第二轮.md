## 4. 踩过的坑（**必读，能省几小时**）

### 4.1 最严重：用 PowerShell 写源文件，把 `kushou_battle.gd` 写成了 1467 字节

- 原本 **5395 行 / 293KB**，被 `[System.IO.File]::WriteAllText()` 覆盖成 **28 行**
- **根因**：PowerShell **变量名不区分大小写** —— 写了 `$T = [char]9`（制表符）和 `$t = 文件内容`，
  `$T` 把 `$t` 覆盖了，写进去的是一个字符
- **靠 git 恢复**（上一个提交是完整的），但丢了半轮工作，全部用 `edit` 重做
- **教训**：**永远不要用 PowerShell / 脚本写 `res://` 下的源码。**
  只用 `write` / `edit`（它们校验 `old_string` 唯一性，写坏立刻发现）。
  **PowerShell 只用来读**（grep / 统计 / 跑 Godot / git）。

### 4.2 "改名字忘了改读取方" —— 这一类连踩四次

| 症状 | 真因 |
|---|---|
| 三选一"选了没反应" | `_wpn_take` 判 `_popup_kind == "成长武器"`，但页面早改名 `"成长武器详情"`（**4 处**） |
| "法师和弓箭应该会在后面攻击" | `f["stop"]`（每只怪自己的停距）**被写入 5 处却从没被读过** |
| 三种挑战怪长得一样 | `kind == "chal"` 全落在火柴人分支，那套画法白写了 |
| 小乞儿是白板 | `gold_lv` 从没被读过 |

→ **改动后一定 grep 一遍**：旧名字还有没有残留？新字段有没有人读？

### 4.3 其它（都当场发现了）

1. **RichTextLabel 不设 `size` 就是 0 高，一个字都不画** —— 黑市"没有价格"的真因
   （我第一次修错了：以为是"两行赋值覆盖"，改完没用，第二次才找到 size）
2. **行高写死 = 文字必然重叠** —— 武器详情页、技能页各踩一次
   正确写法：`ly += maxf(基准, l.get_minimum_size().y + 8.0)`
3. **`edit` 的 `old_string` 只覆盖半行会留残渣** —— 出现过 `})1.0))` 这种
   改完**立刻 `--check-only`**
4. **探针自己的坑**：
   - `var x := <无类型>` → "Cannot infer the type"，要写 `var x: int =`
   - 探针里调 `_restart_run()` 会**关掉弹窗** → 会误判 `boot_popup` 没生效
   - 想改 `hero["atk"]` 加速测试**没用** —— 外壳每帧 `_sync_battle_stats` 会覆盖
   - `Engine.get_frames_per_second()` 在 `--fixed-fps` 下没参考价值
5. **PowerShell：`foreach ($f = @(...))` 少写 `in` 会让整条命令不解析**（不是只报一行错）
6. **给 boss 表插新行后，`_boss_pick` 的 `*3/%3` 必须同步改成 `*4/%4`** —— 否则选不到新的
