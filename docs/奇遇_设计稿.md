## 〇、一句话

**奇遇 = 打到一半冒出来的限时任务**：顶部滑一条横幅，自动进任务栏，做完给厚赏，限时没做完就没了。

- 不弹窗、不暂停、不打断战斗
- 全程自动战斗，**没有任何手动操作**
- 接了奇遇，AI **自动优先去做**；做完 / 失败 / 放弃就回默认

## 一、触发与形态

| 项 | 定稿 |
|---|---|
| 触发 | **每 75 秒**一次（一局约 5~6 次，大致一波一次） |
| 形态 | 顶部横幅，不弹窗不打断 |
| 接取 | 自动进任务栏，**最多 2 个**进行中；满了就顺延到下一次 |
| 放弃 | 任务栏里点［放弃］→ **+10 灵晶**（半个抽卡） |
| 失败 | 限时到点没完成 → 自动消失，**什么都不给** |
| 完成 | 横幅 + 奖励飞向对应计数位 |
| 记录 | 「奇遇」钮点开 = 本局账（完成 x · 放弃 y · 失败 z） |

## 二、难度按波次上调

| 波次 | 简单 | 普通 | 困难 | 特殊 |
|---|---|---|---|---|
| 1-2 波 | 45% | 55% | — | — |
| 3 波 | 20% | 50% | 30% | — |
| 4-5 波 | 10% | 35% | 40% | 15% |

## 四、四类特殊机制的场上布置

| 原型 | 场上加什么 | 核心接口（已存在） |
|---|---|---|
| **破阵** | 3 座石像（可被打碎），活着的石像给半径 160 内的怪攻速 ×1.3、减伤 20% | spawn_statues / clear_statues / statues_left |
| **占点** | 半径 150 的法阵，站圈内累计，出圈半速回退；站圈时只打圈里的怪 | spawn_zone / clear_zone / zone_prog / _in_zone |
| **守护** | 牢车（木车 + 绿血条），怪在「主角 / 牢车」里挑最近的打；牢车血随波涨、不回血 | spawn_guard / clear_guard / guard_hp_ratio |
| **单挑** | 高手大怪（体型 1.6、带名字），**不清场**，普通怪照刷 | spawn_champion / clear_champion |
| 三英 | 一次性刷 3 只精英 | spawn_elite(3) |

完成 / 失败 / 放弃三条路都要跑一遍收场（清石像 / 清圈 / 清牢车 / 清高手）。

## 五、自动战斗：奇遇优先

**没有手动操作**。AI 只有两层：

    奇遇目标  >  默认自动（打最近的怪）

每 0.3 秒驱动一次：

| 奇遇 | 自动行为 |
|---|---|
| 破阵 | 还有石像 → 走过去集火拆；拆完回默认 |
| 占点 | 进度没满 → 走进法阵站住 |
| 守护 | 集火离牢车最近的怪 |
| 单挑 / 猎杀 / 走狗 | 集火那只大怪 |
| 不杀 / 苦役 | 只走位、不主动开挑战、不击杀 |
| 计数类（杀 N 只 / 抽卡 / 强化…） | 不需要驱动，照常打 |

**不加保命阈值**（用户：「不加 全看数值」）—— 残血也照做，成败全看数值。

**顺手要修**：现在战场 _gui_input 还挂着 tap_at / order_move / order_focus，等于藏了手动操作。实现奇遇时把外壳 _core.mouse_filter 改成 **IGNORE**，让点击直接穿透。

## 六、界面

1. **顶部横幅**：【奇遇·困难】牢车将倾 —— 60 秒内别让它碎 · 奖 灵晶 100
2. **任务栏**：战场左下两条小条（任务名 + 倒计时 + 目标进度），点开详情
3. **奇遇弹窗**：左缘「奇遇」钮 → 本局账（完成/放弃/失败）+ 当前任务

## 七、落地清单

1. 任务框架：计时触发 → 按波掷档 → 掷任务 → 自动接（上限 2）→ 进度钩子 → 完成/失败/放弃
2. 进度钩子要埋到：抽卡 / 黑市 / 宝物 / 挑战 / 强化 / 请神 / 升级 / 击杀 / 大怪击杀 / 倒下
3. 四种特殊机制的场上布置 + 收场
4. 奇遇驱动 AI（0.3 秒一拍，目标变了才改指令）
5. 关掉战场手动点击
6. UI：横幅 / 任务栏 / 弹窗

## 八、待调

- 触发间隔 75 秒、奖励数字，先按这套跑
- 「不杀」和「清道夫 / 越狱」会不会互相打架，实测看
- 「献祭」扣血会不会直接送进浴血，实测看
- 任务栏位置（左下两条 vs 顶部横幅下面一条）
