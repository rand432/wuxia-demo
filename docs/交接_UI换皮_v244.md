## 三、踩过的坑（v244）

1. 新面板的标题是**居中**的，右上再放功能钮会直接压字；这类页面标题要么左对齐，要么把钮挪到标题下方。
2. 有些按钮按状态隐藏（战报/洗白/赔礼），截图里只剩两颗是正常的，不是丢件。
3. 面板标题没有统一加金边——新面板用的是 `make_label` 的 ink.ttf，观感已接近毛笔；不要强行逐个改字体。
4. 战线页 close 与面板底之间空白偏大，属布局取舍，不是裁切 bug。
