## 一、想做大厂 PV 质感，先明白差距在哪

| | 现在的做法 | 大厂 PV 的做法 |
|---|---|---|
| **画面** | 文生图 → 图生视频，一镜一图 | 3D 场景 + 分层渲染，或高质量实拍合成 |
| **墨** | 平面贴图 | **流体/烟雾模拟**（Houdini Pyro 那类），墨有体积、有光 |
| **笔** | 没有笔 | **3D 毛笔模型**在场景里真实运动 |
| **一致性** | 靠定版图 + 垫图硬凑 | 3D 资产天然一致 |
| **光影** | 水墨本来就是平的 | 有景深、有体积光、有材质 |

**你给的 KeiKanamori 那条参考就是标准答案**：3D 毛笔 + Pyro 烟雾 + 多层 sim 合成。
**如果目标是那个质感，纯靠出图平台是到不了的** —— 要么上 3D/流体，要么在合成阶段下重手。

## 七、自己上手的五条建议

1. **先在画布上试一镜**：挑「07b 混战中刀」（动作最明确）或「02 荒原流民」（大场面），出 5 秒，看质感对不对。
2. **别一上来就追求全片** —— 平台抽卡，一镜出 3–5 版挑一版是常态。
3. **每一镜的第一帧最关键**：图生视频的质量 90% 由首帧决定。首帧不满意，视频一定不满意。
4. **人物一致性靠垫图，不靠文字描述**。文字只能描述类型，垫图才能锁定这一个人。
5. **画面里出现违和的东西，先查提示词**（我们的高脚杯就是这么来的 —— 提示词里白纸黑字写着高脚酒杯）。
