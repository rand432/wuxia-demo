# 困兽 v2 · 技能（基础剑法）设计稿

> 用户口径（定稿）：**基础剑法＝主角普攻本体**，升级它＝改造普攻的形态与手感。
> 可选项（用户给的池子）：
> 伤害提升 / 攻速提升 / 溅射（降低伤害·可同时攻击敌人）/ 溅射伤害提升 /
> 剑气（命中后弹出一道飞剑，飞向最近的另一个敌人）/ 剑气穿透（可穿透一名敌人，伤害降低）/ 剑气伤害提升

## 一、升级流程

```
打怪 → 经验 → 升级 → 技能钮右上角亮「＋」（1 点）
  → 点开［技能］ → **三选一** → 选完**立刻生效**（数值变了，动作也跟着变）
```

- **点从哪来**：每升 1 级给 1 点（`kushou_v2._on_kill` 里升级时 `_skill_pts += 1`）；
- **三选一规则**：从"还能拿的"里抽 3 个，**不重复**；若还有没解锁的**机制**，保证**至少出现 1 个机制**
  （免得一路只给数值，玩着没变化）。

## 二、七个选项（第一版就这七个）

| # | 选项 | 类型 | 层数 | 效果 | 动画怎么变 |
|---|---|---|---|---|---|
| 1 | **伤害提升** | 数值 | 5 | 每层 **+12%** 伤害 | 刀光更长更亮；第 5 层带白芯 |
| 2 | **攻速提升** | 数值 | 5 | 每层 **+8%** 出手速度 | 挥砍幅度变小变快；3 层起带残影 |
| 3 | **溅射（范围）** | 机制 | **5** | 解锁**横扫**：**命中点周围 R 以内的敌人全扫上**，每个 **70%** 伤害；**每级 R +26**（Lv1 84 → Lv5 188 像素）| 突刺改**扇形光幕横扫**，**半径随等级变大**；被扫到的每个都闪白＋击退＋炸环；另画一圈**范围边界**让人看清打到哪儿 |
| 4 | **溅射伤害提升** | 数值（需先拿溅射）| 3 | 被溅到的目标 **+15%/层**（基础 70%）| 弧光变亮，边缘多一圈光 |
| 5 | **剑光** | 机制 | 1 | 解锁：出手时 **20% 几率**甩出一道**月牙剑光**，**缓慢向前推**（190 像素/秒），碰到敌人造成 **80%** 伤害；**穿透 0 ＝ 碰一个造成一次伤害就散** | 一道**月牙**（三层弧光）慢慢推出去 |
| 6 | **剑光·几率** | 数值（需剑光）| 3 | 触发几率 **+15%/层**（20%→65%）| 月牙出得更勤 |
| 7 | **剑光·伤害** | 数值（需剑光）| 3 | 剑光伤害 **+25%/层** | 月牙更亮，命中炸环更大 |
| 8 | **剑光·宽度** | 数值（需剑光）| 3 | 月牙更宽（**+35%/层**），扫到的敌人更多 | 月牙变宽变厚 |
| 9 | **剑光·穿透** | 数值（需剑光）| 3 | **可多穿 1 名敌人/层**（0 就是碰一个伤一次即散）| 穿过敌人时留一道残影 |
| 10 | **剑光·速度** | 数值（需剑光）| 3 | 推进速度 **+60/层** | 推得更快，拖尾更长 |

> **剑气那三条（剑气／剑气穿透／剑气伤害提升）已从池子里撤下（v3d）**——
> 用户："剑气去掉【内容保留】"：**代码、数值、飞剑的画法与穿透逻辑全都留着**（`_qi_list`/`_spawn_qi`/
> `_update_qi`/`_draw_qi` ＋ `skill` 里的 `qi/qi_pierce/qi_dmg`），将来想放回来，
> 只要把 `SKILL_POOL` 里那三条加回去就行。

**为什么这样分**：1/2/4/7 是"数值"（不用新画动作，零成本），3/5/6 是"机制"（各要一套动作）。
溅射与剑气**先解锁、再强化**——这样玩家能感到"招式长出来了"，而不是只涨数字。

## 三、数据结构

``gdscript
# 战斗里这一份就是"主角现在会什么"
skill = {
  "dmg_lv": 0, "aspd_lv": 0,          # 数值层
  "splash": 0, "splash_dmg_lv": 0,    # 溅射线
  "qi": 0, "qi_pierce": 0, "qi_dmg_lv": 0,   # 剑气线
}
# 实时算出来的（每次出手现算，改数值不用到处同步）
atk_mul   = 1.0 + 0.12 * dmg_lv
aspd_mul  = 1.0 + 0.08 * aspd_lv
splash_n  = 1 + (1 if splash else 0)                 # 同时打几个
splash_mul= (1.0 - 0.25) * (1.0 + 0.15 * splash_dmg_lv)
qi_mul    = 0.60 * (1.0 + 0.20 * qi_dmg_lv) * pow(0.80, qi_pierce)
```

## 三·五、已经落地的部分（v3a）

- **数据与效果**在 `kushou/kushou_battle.gd`：`skill{}` ＋ `SKILL_POOL` ＋ `roll_choices()` ＋ `apply_pick()`；
  `atk_mul()/aspd_mul()/splash_max()/splash_mul()/qi_mul()` 现算，改数值不用到处同步；
- **出手**统一走 `_hero_strike()`：算伤害（技能＋暴击＋重击）→ 横扫（溅射多目标，各自闪白/击退/飘字）
  → 命中后 `_spawn_qi()` 弹飞剑 → 手感特效（抖屏/顿帧/刀光/音效）；
- **飞剑**：`_qi_list` 里的实体，朝"最近的另一个敌人"飞（560 像素/秒），到位后伤害＋小十字光，
  `pierce > 0` 就换下一个目标继续飞；画成细长光刃 ＋ 拖尾；
- **横扫**：`_slashes` 里 `wide = true` 的那条画**大弧**（两道弧，叠在一起），跟单体突刺一眼能分出来；
- **残影**：攻速叠到 3 层后 `_aspd_flash` 让刀光多留 0.12 秒（"前一刀没散就出下一刀"的感觉）；
- **界面**在 `kushou/kushou_v2.gd`：`_skill_pts`（每级 +1）· 技能钮右上角亮「＋」·
  ［技能］页＝**三选一**（机制红框/数值灰框，各带"动作："那一行）＋ 下面一张**当前招式表**
  （伤害 ×? / 攻速 ×? / 同时打几个 / 剑气数值）；
- 验收截图：`.shots/z50_skill_pick.png`（三选一）· `.shots/z53_qi_fly.png`（飞剑在飞，
  飘字 `剑 10` 与主伤害 `59` 分开）· `.shots/z52_skill_build.png`（当前招式）。

## 三·六、v3b：让"看得见"（用户："感觉不太明显 溅射和剑气 而且攻击时有个奇怪的鸟叫声"）

**那声鸟叫**：宠物咬人时放的是 `pet_chirp1`（一声鸟叫）——换成短促的 `melee`（−10dB，音高 0.92~1.12），
听着像"咬"，不像鸟。**这条是教训：音效名对不上动作，玩家第一反应就是"怪声"。**

**溅射**（原来就一道细弧，一闪就没了）：
- **扇形光幕**：从主角身前铺开一片半透明金光（13 点的扇形多边形，α 0.30）；
- **三道弧**（108/88/132 半径，越外越淡）＋ 一道**亮边**当刀锋；
- 被"溅"到的目标：闪白 0.30（比主目标更久）· 击退 ×1.5 · **橙色"溅"**飘字更大 ·
  每个目标一圈**冲击环＋八根放射线**（`_bursts`）；
- 音效：横扫那一刀额外加一声 `swing`（−3dB），跟单体刀声区分开。

**剑气**：
- 飞剑从 30 像素加长到 **52＋12×穿透**，**外光＋亮芯＋剑尖光点**；
- **三层拖尾**（越远越淡），飞过去留下一条光；
- 命中：**1.5 倍冲击环**＋放射线、抖屏 5、飘字改成大字 **「剑气 N」**、
  音效 `slash_light`(−6dB) ＋ `dart`(−10dB)。

验收：`.shots/z60_splash.png`、`.shots/z61_qi.png`（横扫的扇形光幕一眼可见）。

## 三·七、v3c：溅射改成"范围"（用户："溅射 可以改为范围吗 就是每一级范围 感觉更好一点"）

**改了**：从"同时打 N 个"改成**按范围**打——
- `splash_radius()`：没学＝0；学了一级 **84**，每多一级 **+26**（Lv5＝**188**，差不多半个横排宽）；
- 命中时把**命中点周围 R 以内**的敌人全部扫上（不再数目标数，目标多少是"圈多大"自然决定的）；
- 被溅到的每个目标：**70%** 伤害（"溅射伤害提升"每层 +15% 往回补）；
- **画面**：扇形光幕、三道弧、亮边、以及**范围边界那一圈淡光**都按 R 等比放大——
  玩家每点一级就能**看着圈变大**，比"+1 个目标"直观得多；
- **技能页**那一行也跟着变成 `横扫范围 N 像素（溅射 x/5）　被溅到 ×0.70`。

验收：`.shots/z70_splash_lv1.png`（R=84）与 `.shots/z71_splash_lv5.png`（R=188）对照着看。

## 三·八、v3d：剑气撤下、换上"剑光"（月牙）

- **剑光**是新的一条线（上表 5~10 条）：**几率触发 → 月牙慢慢向前推 → 碰到就伤 → 能穿几个**；
- 月牙的形状：三层弧光（外厚光 40w/12w、内亮线 46w/5w、内芯 34w/4w），**宽度随"剑光·宽度"整体放大**；
- 命中判定是**一条横带**（`|Δx| ≤ 46×宽` 且 `|Δy| ≤ 30`），带内没被这道光打过的敌人都算命中；
  每命中一个 `pierce -= 1`，**pierce ≤ 0 就散**（"穿透没有就碰一个造成一次伤害就没了"照这条实现）；
- 飘字写「**剑光 N**」（金色大字）＋ 命中炸环 ＋ 轻微抖屏；出手时 `swing` 一声；
- 三选一卡片里的数值占位（`<C>/<D>/<W>/<P>/<S>`）都会**替换成当前档位**，点之前就看得见现状。

验收：`.shots/z80_jianguang.png`（月牙在飞、命中飘"剑光 88"）· 池子抽样＝`["splash","dmg","jg_c"]`（剑气已不在池里）。

## 三·九、v3e：剑光按"出手方向"推（用户："攻击的方向推"）

- 原来月牙**固定朝上**（`dir = (0,-1)`）——主角站在敌人侧边时会"擦肩而过"；
- 现在 `_try_spawn_jg(base, dir)`：`dir = 被打那只 − 主角`，**月牙朝着挨打的那只推出去**；
  出刀点也跟着挪到 `hero_pos + dir × 40`（不再固定往上 40）；
- **命中判定跟着转**：从"横带"改成 `|rel·dir| ≤ 18` 且 `|rel·dir⊥| ≤ 46×宽`（垂直于前进方向的带）；
- **画法跟着转**：`draw_set_transform` 把坐标系转到"上＝前进方向"再画三层弧，
  画完**立刻还原**（不还原的话后面的飘字、碎屑会全跟着转——这是宠物那次的同一个坑）；
- 出界判定改成四边都算（斜着飞出去也能正确回收）。

**实测**：一道剑光连续几发的 `dir.x` 分别是 **−0.29 / 0.48 / 0.95 / 0.83 / 0.74**，说明确实按目标方向走；
截图 `.shots/z82_jg_dir.png` 里月牙是**斜着**推出去的。

## 三·十、v3f：走慢一点、别冲到顶（用户："主角人物走的再慢一点 起码让怪大部分出现在屏幕里"）

原来主角走位 168 像素/秒，怪一冒头他就冲到战场最上沿去打，**一屏只看得到怪的脚**。
- **走位速度**：主角 168 → **96**，宠物 190 → **124**；
- **主角上限线**：`HERO_TOP = 0.40`——主角**不许越过战场高度 40% 那条线**（704×0.4＝281），
  到线就**停住等怪自己走下来**；怪照旧朝主角走（`FOE_REACH = 66`），交战点自然落在屏幕中段。

**实测**（第 14 波、跑 10 秒）：主角停在上限 y=281，**8 只怪里 6 只在屏内**（另 2 只还在上面往里走）。
取景截图：`.shots/z90_framing.png`。

## 三·十一、v3g：宠物同样不冲顶（用户："宠物也是"）

宠物原来会**独自冲到战场最上面**去咬（它追的是"离主角最近的怪"，不认那条线）。
现在给它加上和主角同一条约束：
- `pet_pos.y = clamp(…, size.y × HERO_TOP + 12, …)` —— 上限比主角**低 12 像素**（跟着主人，不抢在前面）；
- `pet_pos.x` 也收进场地内（44 像素边距）；
- 行为上就是：**怪得自己走下来才咬得到**；没怪时照旧回到主角左后侧。

**实测**：主角 y=281（贴上限）、宠物 y=293（贴自己的上限），**9 只怪里 8 只在屏内**。
截图：`.shots/z91_pet_framing.png`。

## 三·十二、v3h：开场等几秒 ＋ "远快近慢"（用户："让主角刚开始等待几秒然后 走近了就慢、远了才快"）

**① 开场等待**：`INTRO_WAIT = 3.0` 秒——`start_run()` 一开就把 `intro_wait` 立起来，
这期间主角与宠物**站着不动、也不出手**（怪照常从上面走进画面），屏幕中上写一行
**"预备… N 秒"** 说明为什么还没动。壳里把 `_field.running = true` 换成 `_field.start_run()`。

**② 远快近慢**：速度不再是一个常数，而是**按距离插值**——
`_chase_spd(近速, 远速, 距离)`：距离 ≤ `CHASE_NEAR(96)` 时用近速，≥ `CHASE_FAR(230)` 时用远速，中间线性过渡。
- 主角：**近 96 / 远 178**（原来一直 168，怪刚冒头就被贴脸）；
- 宠物：**近 124 / 远 196**；
- 这样"追得动"，但贴上去以后是**慢慢挪**，不会在边界上蹭（配合 v2o 的回滞）。

**实测**：等待期间主角坐标**纹丝不动**（`hero_pos = (352, 608)`，逐帧采样比对 "动过吗=false"）；
开打后走到上限 y=281；速度曲线 远(400px)=178 · 中(160px)=135 · 近(80px)=96。
截图：`.shots/z95_intro_wait.png`（"预备… 1 秒"）· `.shots/z96_after_wait.png`。

## 三·十三、v3i：怪走快一点（用户："怪可以稍微再快一点"）

`FOE_SPD` **42 → 58** 像素/秒（boss 仍是它的 0.7 倍，跟着一起变快）。

**实测**（第 12 波）：**第 5.0 秒**第一只贴到主角面前（其中开场等待占 3 秒，也就是等完约 2 秒就接触上了）；
10 秒时场上 10 只、最近距离 65 像素（正打着）、已杀 1 只。节奏变成"预备 3 秒 → 怪压上来 → 立刻交手"。

## 三·十四、v3j~v3l：上限线 25% · 怪再快 · boss 正常速度

- **v3j**（"主角和宠物最高只能到战场高度 25% 那条线"）：`HERO_TOP` **0.40 → 0.25**
  （704×0.25 ＝ **176**）；宠物仍是"比主角低 12 像素"（188）。实测：主角 y=290（贴着自己那条线附近交战）、
  **10 只怪里 9 只在屏内**；
- **v3k**（"怪再快一点"）：`FOE_SPD` **58 → 74** 像素/秒；实测第一只**第 4.7 秒**贴上来（含等待 3 秒），
  开打后 9 只怪里 8 只在屏内、主角已开始掉血（有来有回）；
- **v3l**（"boss可以正常速度"）：boss 原来走 **0.7 倍**（74×0.7＝51.8），现在**和寻常怪同速**。
  实测：boss 每秒往下 **73.1 像素**（≈ FOE_SPD 74，0.7 倍的话会是 51.8）——确认已同步。

## 四、动工顺序

1. **技能数据 ＋ 三选一弹窗 ＋ 技能页**（看得见、点得动）；
2. **数值两项生效**（伤害/攻速）——最简单，先让手感有变化；
3. **溅射**（横扫动作 ＋ 多目标结算）；
4. **剑气**（飞剑实体 ＋ 飞行/命中/穿透）；
5. 冒烟验收：截图三选一、横扫多杀、飞剑穿透各一张。

## 五、还没定的

- 每级 1 点还是每 2 级 1 点（现按**每级 1 点**）；
- 数值层的封顶（现按 5/5/3/3）；
- 剑气飞剑的飞行速度与射程（现按 520 像素/秒、追到目标为止）。
