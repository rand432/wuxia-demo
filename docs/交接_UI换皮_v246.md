## 〇、一句话现状

- `UiKit.style_button()` 的 **disabled** 在皮肤下原来是
  `ink_box(Color(0.16,0.15,0.14,0.42))` —— 半透明深色压在纸上会变成**一块灰砖**。
- 现在改成 **墨底（0.075/0.066/0.060，alpha 0.94）+ 暗金边 + 暗金字**：
  - 禁用态看起来像"盖了印的墨牌"，不是系统灰按钮；
  - 所有走 `make_button` 的面板一起生效（货郎/山门/牢房/宗门/任务/事件…）。
- 可点按钮/正常态、hover、pressed 一个字没动。

## 三、踩过的坑（v246）

1. 禁用态墨底 **alpha 0.58 还是灰**——纸太亮，半透明深色会混成灰；要 **0.94** 才压得住。
2. 这是全局公共口：所有 `make_button` 的禁用态一起变；战斗 HUD 有自己 `_style_btn` 的不影响。
3. 货郎四颗「买」全灰是**钱不够/通缉**，不是样式丢件；禁用态现在仍读得出"买"字。
4. 暗底上的禁用按钮对比会弱一些；但字是暗金，仍可辨认，后续可按面板单独加亮边。
