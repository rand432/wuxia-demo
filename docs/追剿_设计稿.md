用户："追缴整体难度按照500关开始 每25关上浮整体25% 同时每一档提升50% 前80关难度降低50%"。

1. **基准**＝塔**第 500 关**的杂兵身板（固定不动——v139 之前是"跟着等价关往后爬"，现在不爬了）；

## 二之二、后台 / 离线推进（v143 新开）

用户："追缴无法离线和后台"。

爬塔那条路早就有（挂机 → `GameState._idle_climb` → `Tower.run_offline`）；追剿从 v129 起是**故意藏着**的
（`battle_lite` 的［回村·后台继续］在追剿里根本不显示）。v143 按同一套口径补齐：

- **触发**：`chase_auto` 开着 · 人不在战斗里（`battle_live`/`_battle_seen`）· 还有下一关；
  节奏与爬塔同一个闸（`CLIMB_MIN_SEC`＝**每 20 秒一拍**）——**在线后台**与**离线开局**走的是同一条路
  （离线那段时长由 `idle.cfg` 的 last_ts 补上，进游戏第一拍就结算）；
- **判定**：`Tower.run_offline`（与塔共用"血池 / 输出 / 每关耗时"那一套估算），
  敌情取 `GameState.chase_enemy_at`（所以 boss 的体型/多人加码都算得对）；
- **清关**：仍走 `chase_clear()`——银两 / 经验 / **2 个宝箱** / boss 关那件**整品**照发；
  批量推进时落盘一次（不逐关存）；
- **播报**：汇总那一行并进 `offline_note`，回村/在线每 20 秒那一拍由主界面弹 toast：
  `追剿（后台）：推进 54 关，到第 55 关（boss 赏 10 件）——这一关估算过不去，回来自己打`；
- **停**：出村面板那颗［自动］在"后台推进中"时变成［**停推**］，点一下把 `chase_auto` + `chase_bg` 一起收；
- **让位规矩**（与爬塔相同）：屏幕上真打着这一关时估算不推；战斗里点［回村·后台继续］
  ＝这一场既不算赢也不算败，追剿停在**当前这一关**，交给每 20 秒一拍的估算重判。

⚠ **估算看不见 boss 的特性＋专属被动**（号令/背水/护体罡气…），所以后台推 boss 关偏乐观——
这是"挂机估算"一贯的粗法（爬塔同理）。想让它保守：把 `GameState.CHASE_BG_HAIRCUT` 从 1.0 调到 0.9，
代价实测是**每个 boss 关都会卡住**（刚够打的队伍正好过不去），于是每推 4 关就要你回来打一口。

## 三、手牌模式（v135：战斗里的出牌）

用户口径："**追剿 的手牌说的是游历的那种出牌 直接加在战斗里设置即可**"。

- 轮到我方某人出手时，**这一手能用的东西摊成几张牌**：普攻（永远有）· 武学（冷却好了的各一张）·
  大招（怒气满了才有）；被封住的东西**根本不摊出来**（沉默→没有武学牌、封招→没有大招牌）；
- **点一张牌＝用那一张**；牌面写名字、底下写类型（普攻/武学/加持/大招），边框按"谁的牌"配色；
- 等牌上限 **20 秒**，超时按自动挑一张打出去；提示行右边常驻［**自动挑一张**］，绝不卡死；
- 战斗右上那颗［**出手：手动出牌 / 出手：自动**］**随时能切**（［手牌］入口就是把它默认拨到手动）；
- 手动**不改平衡**：挑出来的那张走同一套结算（`_member_act(m, force)`），只是"谁来挑"从 AI 换成玩家；
  挑到的牌若中途变成放不了（被缴械/封招/冷却被推），会验一遍后退回能放的那张，不空过一手。
- ⚠ 原来那条"用困兽牌桌打一剿"的路**已从入口撤下**（`kushou_mode.open_chase()` 保留但没人调；
  困兽本身仍是主界面 E 键的独立试玩）。

### boss 专属被动（v141 新开）

用户："增加 boss追缴有独立大招和被动"。

- **大招**本来就是各写各的（`BOSSES[].ult`，25 门各一个名字与倍率）；
  v141 补的是**被动**：**25 个 boss × 25 条，绝不重复**，一条只属于一门 boss；
- 判类口径：**特性（traits）**＝"每几手来一次的大动作"（号令/锁招/列阵/淬毒/换招，14 门有）；
  **被动**＝"一直在身上的底子"（25 门全有）。两者可以同时在身上；
- 引擎只认十种键（`data_chase.PASSIVES` 每条挑一到两种写）：
  `stat`（出场改身板）· `affix`（挂现成词缀，可 `all` 给全队）· `shield`（开局护盾）·
  `ward`（五行抗性）· `rage`（怒气）· `tick`（每 N 手一次：heal/poison/sealvein/rally/guard/guard_all）·
  `on_hit`（命中回血/打怒气）· `low_hp`（背水）· `execute`（处决残血）· `immune`（免控）；
- 敌情面板分三段写：**词缀 → 特性（可以针对）→ 被动「名字」＋针对**；开战战报也报一行被动；
- 出村面板上，boss 关的小字会带上被动名。

### 顺手修掉的老毛病（v58 起就哑着）

**五行从来没被抄进战斗**：`GameState.chase_enemy_at()/enemy_at()` 里明明有 `elem` 与 `{属}_res`，
但 `battle_lite._build_foes()` 那份敌字典从来没抄过它们 —— 于是 `_foe_elem()` **恒为空串**：
塔第 400 关往后的"元素怪"打的其实是物理，玩家的元素伤害也不吃它的抗性。
v141 把这十一个键（elem ＋ 五抗 ＋ 五伤）补进敌字典，实测第 305 关本体 `elem=water / water_res=30`、
`_foe_elem()` 真返回 water（追剿的「五行护体」被动也靠它才成立）。

### 顺手修掉的三处旧毛病（都有截图证据）

1. `_build_foes` 没把 `boss`/`realm` 存进敌字典 → 境界显示/首领提示/体型三条路一起哑（已修）；
2. 敌情面板读"当前盯着的那只"（副手没招）→ 现在**首领本体的招数一定列出来**；
3. 手牌/货架那类深色底上的说明原来用深墨写（看不见）→ 一律改纸色。

## 八、怎么调

- 难度：`HP_MUL / ATK_MUL / BOSS_HP / BOSS_ATK`（1.18 / 1.12 / 1.25 / 1.10）；
- 关数与节奏：`STAGE_MAX(400) / BOSS_EVERY(5) / UNLOCK_STAGE(500) / OFFSET(499)`；
- **赏格**：`REWARD_STEP(80) / REWARD_MAX_Q(3) / RW_SILVER(100) / RW_SILVER_STEP(50) /
  RW_EXP(400) / RW_EXP_STEP(200) / RW_CHEST / RW_BOSS_CHEST`；
- boss 性格：`BOSSES` 表（25 条）· 特性文案：`TRAITS` 表；
- 手牌：`battle_lite.HAND_WAIT(20 秒) / HAND_CARD_W / HAND_Y_OFF`。
