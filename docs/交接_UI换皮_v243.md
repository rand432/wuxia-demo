## 三、踩过的坑（v243）

1. 这些 HUD 是 `CanvasLayer` 里的绝对坐标；加条带后要把 `_toast/_wanted` 一起挪，否则压住食物/时段。
2. 条带只画一条边：`StyleBoxFlat.border_width_*` 单边设，别用 `set_border_width_all` 画成四边框。
3. 地图本身是 Node2D 相机画面，**不要给地图加纸面板**；条带只压屏幕上下沿，保留"走图"的感觉。
4. 新面板（POI/商队/宗门）还没逐个看；它们多数走 `UiKit.make_paper_panel`，已吃 v242 的全局金框。
