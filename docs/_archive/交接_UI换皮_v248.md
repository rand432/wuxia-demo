## 〇、一句话现状

- **凶物图鉴**：六只凶物原来是"名字/状态/专属/弱点/典故"五层字直接叠在一起，
  行与行之间没有分界。现在每只之间加一道 **1px 暗金细线**（x40 宽 540），
  六段一眼分得开；字色/字号/位置没动。
- **江湖后记**：抽查无重叠；正文按 `\n\n` 排版（行距约 41px），
  是"后记"要的疏朗感，这轮没改。底部大段留白是给"再入江湖"按钮/长文增长留的。
- 两个页面都已经是纸面金框 + 墨金按钮（v242/v246 的公共底）。

## 三、踩过的坑（v248）

1. 图鉴行高 112、最后一行典故落在 y≈1000，关闭钮也在 1000 附近；加线只能加在行首上方，
   不要加最后一行下方，否则会压到关闭钮。
2. 分隔线用 1px `ColorRect` + `MOUSE_FILTER_IGNORE`，不挡点击；颜色 `GOLD @ 0.22` 足够淡。
3. 后记的 `\n\n` 是有意的疏朗排版；改成 `\n` 会让正文缩在顶部、底部更空，别顺手改。
