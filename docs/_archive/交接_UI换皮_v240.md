## 三、踩过的坑（v240）

1. 梁和牌是**一起动的**：只改 `add_hang` 的 rx 不改 `add_beam`，绳子会挂空。
2. `add_hang` 的 `hang_y` 是牌顶位置；梁心 y 要留出牌顶到梁的绳长（这次梁 122、牌 122 起）。
3. 牌宽固定 76；两块并排时中心距 100（60/160），中间留 24，不叠。
4. 这组是 `page:"ui"`（固定层），不随画卷滑；搬位置不影响右栏/底部。
