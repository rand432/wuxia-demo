## 三、踩过的坑（v212 新增）

1. **TextureRect 先设 `size` 再设 `expand_mode` ＝ 白设**。贴图的最小尺寸会把 size 顶回 128×128。
   顺序：`expand_mode = EXPAND_IGNORE_SIZE` → `stretch_mode = KEEP_ASPECT_CENTERED` → `texture` → `size`。
2. **Label 先设 `size` 再设 `autowrap_mode` 也一样**：设 size 时按"整行不换行"算最小宽度（这次是 224），
   后面开了换行也不会缩回来。先设 `autowrap_mode`，再设 `size`。
3. **自己画刊头要打标**：`_panel.set_meta("skin_header", true)`，否则 `_skin_pass()` 再补一条 78 的自动刊头。
4. **装备图标格的长件名**（"生锈的铁剑（物理）"）：图标格只剩 190 宽，22 号字会折两行，而高度只给 26 →
   第二行溢出、还被右下「卸下」压住。现在：两行给 48 高、字号 21、「卸下」挪到 (198,68)。
5. 抠图：`tools/cut_white_bg.py` 只吃**与画布边界连通**的近白，不会把人物身上的浅色吃掉；
   生成的 `_cut.png` 要在 `--import` 之后才能 `preload`。
