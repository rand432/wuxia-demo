## 〇、一句话现状

### 面板开合
- 开面板：`_check_panel_anim` 里一声 `ui_open`（-16dB）；
- 关面板：`UiKit.hide_panel` 里一声 `ui_close`（-16dB）。
- 所有面板（v221/v222 接的那一批）自动都有，不用各面板写。

### 品酒坊
- 点客人开始斟酒：`ink_drop`（很轻的落滴，-17dB）
- 斟完结算：`drink`（一口下肚，-10dB）

### 鉴宝行
- 货仓撬开、开始逐格揭示：`chest`（-11dB，pitch 0.92）
- 收完且确实有货：`coin`（-12dB）

### 炼丹阁
- 开炉成功（`alchemy_start` 回"第 N 号炉开火"）：`wood_down`（-11dB，pitch 0.90）
- **成丹那一下**：
  - 该炉整行 `modulate` 闪金（1.30/1.14/0.72 → 白，0.55s）；
  - `levelup` 一声（-10dB）；
  - 底部消息写"第 N 号炉丹成——点［收丹］"。

## 三、踩过的坑（v223）

1. `open()` 时要**静默种一遍** `_fr_ready`：否则一开炼丹阁，所有"早就成了"的炉子都会被当成刚成，
   连响好几声、整排闪金。
2. `refresh()` 每 0.1 秒跑一次，成丹判定要"上一次 false → 这一次 true"才触发；
   收丹后炉位变空，`now_ready` 归 false，下一炉才会重新触发。
3. 炼丹开炉返回的是**字符串**不是 dict；用 `msg.contains("号炉开火")` 判成功。
4. 面板开/关音和按钮点击音会叠（先 `ui_click` 再 `ui_open/ui_close`），这是故意的——
   点击是"按下去"，开合是"门轴"；嫌吵可把开合音降到 -20dB。
