### 这轮修掉的报错

`_init_season()` 里原来直接调 `_sync_ambient()`。它在 `_ready()` 里跑，
此时 root 还在建子节点：

```
ERROR: Parent node is busy setting up children, add_child() failed.
ERROR: Playback can only happen when a node is inside the scene tree
```

改成：`_init_season` 只设季节/雾，初始环境音交给已有的 **deferred `_start_ambient()`**；
换季分支与测试键 N 仍在运行期直接 `_sync_ambient()`。

## 三、踩过的坑（v235）

1. **`_ready` 里不要 add_child 音频播放器**：root 还在建子节点，会失败；
   要么 deferred，要么等一帧。v230 修过 `play_ambient` 本身，v234 又把它从 `_init_season` 里直接调了一次。
2. 冒烟要按"打开→等 20 帧→关闭"走，别在同一帧开关；关闭有 0.13s 收起动画，
   同帧再开会撞上 `panel_closing` meta。
3. 全量 check 要用循环遍历所有改过的脚本；只 check `menu_sketch` 抓不到被它引用的面板错误。
