## 三、踩过的坑（v222）

1. `pet_panel / out_panel / formation_panel` 原来没 preload `UiKit`——加调用前先补，不然运行时报
   `Identifier "UiKit" not declared`（`--check-only` 能直接抓到）。
2. **"关 A 立刻开 B"的流程**：A 会多 visible 0.13s，`_top_panel()` 里 A 可能排在 B 前面，
   这 0.13s 里 `_top_panel` 仍返回 A（例如出村 → 出征整备）。目前接受；若以后要做
   "B 的开场动画"，需把 `_top_panel` 改成"跳过正在收起的面板"。
3. `closed` 信号仍在 `close()` 里**立刻**发；宝箱/升星的 `_on_*_closed` 会立刻刷新另一块面板，
   画面 0.13s 后才消失——目前没有依赖"关闭瞬间"的逻辑，所以安全。
