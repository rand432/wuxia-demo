## 〇、一句话现状

- v2 的弹窗（卡组/黑市/技能/挑战/存档/成就…）都是 `_open_popup()` 一个口子开的，这轮统一：
  - 纸面 **16px 圆角 → 4px 近方角**，朱砂边 → **金线**（跟百工坊/品酒坊/炼丹阁的纸面一套）；
  - 页标题 **毛笔 + 墨字描金边**（纸面不能用亮金）；
  - 右上「关闭」钮 **墨底金线 + 金字**（原灰蓝圆角）；
  - 大弹窗顶部状态带 **墨底金线**（原圆角深灰）。
- 页内的自绘控件（「十格卡组/吞噬记录」灰钮、黑市红「买」钮、卡牌详情等）**没动**——
  它们各自有语义色（红＝买），这轮只统一"外壳框"。

## 三、踩过的坑（v229）

1. 弹窗纸面是**深色字**，所以框可以换金、字不能换亮金；标题只能"墨字描金边"。
2. 页内控件别一刀切：黑市「买」的红是功能色（花钱），全局改金会丢掉"这是花钱"的提示。
3. 卡组弹窗是空的（探针没塞牌），扇形里是灰色空卡；要看成牌的效果，探针得先 `_card_gain` 几张。
