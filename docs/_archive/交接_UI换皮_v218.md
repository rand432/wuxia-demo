## 三、踩过的坑（v218）

1. **Label 的最小宽度 + 中文 = 顶出面板**：`WORD_SMART` 对没有空格的中文会把"整句"当成一个词，
   就算先设了 autowrap、后设 size 也照样横向长出去。**显式 `\n` 断行最稳**（这次按 `｜` 断）。
2. **改文案别只改一处**：品酒的 `_msg_lb.text` 在 `_build`、`_refresh_texts`、`_reset_note` 三处都会写，
   只给其中一处加 `.replace()`，开面板时又被另一处覆盖回整句。这次三处都改。
3. **数据里的 `**粗体**` 标记不会自动渲染**：鉴宝货仓描述带星号，直接显示成 `**最高只出到紫档**`；
   在 `refresh` 里 `.replace("**","")`。
4. 皮肤下的**亮色不能写在纸面上**：鉴宝的统计行在 96 刊头**下面**，得用深色；副题在刊头里才用浅色。
5. `_skin_pass` 只认"标题 Label + 宽面板"；自己画刊头一定要 `set_meta("skin_header", true)`。
