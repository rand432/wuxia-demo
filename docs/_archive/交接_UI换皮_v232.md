## 三、踩过的坑（v232）

1. `set_season()` 会重建粒子；**只在换季时调**，不要每帧调（会一直重置粒子的位置）。
2. `_season` 的初值在 `_init_season()` 里才定，而 mist 在更早的 `_ready` 里创建；
   所以 `_init_season` 末尾要补一次 `_mist.set_season(_season)`，否则开局总是春季粒子。
3. 秋叶是 4 点菱形、冬雪是圆点，都画在 `z -50` 的裁切层里；跨过画心边缘会被父级 clip 掉，不会漏到桌面。
4. 雪点在浅色纸上几乎看不见，主要落在山体深色处——这是正常的。
