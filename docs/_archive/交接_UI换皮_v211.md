## 三、踩过的坑（v211 新增）

1. **`--check-only` 查不出「标识符未声明」**。这轮把 `var pn` 删掉后 `--check-only` 仍 exit 0，
   真正报错要跑探针看日志：`Parse Error: Identifier "pn" not declared`。
   → **验收必须跑一次探针**（它会加载 menu_sketch.tscn 并打印真实解析错误）。
2. **MoneyHud 的 z 序**：它是独立 Node2D。建在牌子层**之前**会被顶栏墨带盖住（数字发黑）；
   建在牌子层**之后**才对。但面板一开牌子层整层 `visible=false`，钱条会单独浮着 →
   `_process` 里 `_money_hud.visible = _story_page < 0 and not _any_panel_open()`。
3. **封面页右栏要整栏收**：v210 时山洞/藏宝/百工坊是 `page:"village"` 会随卷滑走；
   改成 rail 之后不再滑，必须显式 `rail_on = not _cover_mode` 判据，否则封面书名被压。
4. **截窗口会缩**：直接开窗口是 450×800，且会被屏幕可用区裁（这次只有 596×1061）。
   用 **SubViewport 720×1280** 截（模板见下），又稳又清。
5. 新 PNG 要先 `--import` 才有 `.import`；否则 `preload` 直接失败。
6. `Ui.panel()` 的 `bracket` 会画四角 L 标；小 chip 用 `"bracket": false` 才不脏。
7. 大碑的竖向渐变**不要用两三块大色带拼**——横向接缝一眼可见。用一行行 1px `draw_line`（46 行），
   切角处按斜边收回即可，平滑且没有缝。

## 五、工作方法（照做）

```powershell
$godot = 'C:\Users\zq300\Desktop\Godot_v4.7.2-stable_win64.exe'
# ① 解析检查（不够，但先跑）
& $godot --headless --path D:\1\wuxia-demo --check-only --script res://menu/menu_sketch.gd 2>&1
# ② 新图先 import
& $godot --headless --path D:\1\wuxia-demo --import 2>&1
# ③ 探针截图（SubViewport 720×1280）
```

探针模板（存 `probe_v211x.gd`，跑完删）：

```gdscript
extends SceneTree
var frames := 0
var ps: Node = null
var vp: SubViewport = null
const OUT := "res://.shots/v211_x.png"
func _initialize() -> void:
	vp = SubViewport.new()
	vp.size = Vector2i(720, 1280)
	vp.render_target_update_mode = SubViewport.UPDATE_ALWAYS
	get_root().add_child(vp)
	ps = load("res://menu_sketch.tscn").instantiate()
	vp.add_child(ps)
func _process(_delta: float) -> bool:
	frames += 1
	if frames == 80 and ps != null:
		ps._sc = 0.0          # 村景页；封面页用 720.0
		ps._hint_used = true
	if frames == 220:
		vp.get_texture().get_image().save_png(OUT)
		print("probe saved ", OUT)
		return true
	return false
```

常用入口：`_open_char_panel()` / `_open_warehouse()` / `_open_shop()` / `_open_out()` / `_open_advance()`。
点牌子也可以合成事件：`ps._plaques._on_hit(ev, ps._plaques.find_i("stele"))`。
