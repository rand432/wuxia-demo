## 三、踩过的坑（v227）

1. `_panel()` 不只给 HUD 用，**战场底板也走它**——改圆角会同时影响战场外框（这次是有意的，外框也方了）。
2. `_circle_btn()` 目前只被左右六颗按钮使用；改成方牌后位置/尺寸（104×104）没变，命中区不受影响。
3. 皮肤判断用 `Ui.SKIN == 1`，保留 `else` 旧样式——以后要做"旧皮开关"不用回滚代码。
4. 外壳里还有一部分**自绘页面**（卡组/黑市/抽卡三选一/局终）用自己的纸面或深色卡，不在 `_panel` 管辖内；这轮没动。
