> 起因：用户 2026-10-19「给现有主界面换皮，参考影之刃，学习别人游戏的长处（背包/装备/属性怎么排版）」，
> 只提一个硬约束：**竖屏 720×1280**。其余皆可改。

> 本文是**施工口径**。代码入口：`menu/menu_theme.gd`（色板/形状/缓动）、`shared/ui_kit.gd`（全局按钮）、
> `menu/menu_plaque.gd`、`menu/menu_hud.gd`、`menu/menu_mount.gd`。

## 1. 色板（唯一真源：menu_theme.gd）

| 名 | 值 | 用途 |
|---|---|---|
| INK0 | `#0E0C10` | 刊头、最暗底 |
| INK1 | `#1F1B18` | 墨牌面（**暖黑，不是冷黑**） |
| INK2 | `#2E2823` | 悬停提亮 |
| GOLD | `#C8A24E` | 主金线 |
| GOLD_HI | `#F0D68A` | 高光金 / 暗底上的字 |
| CINN | `#A82A1E` | 朱砂：主按钮、印章、分区竖条 |
| CINN_HI | `#E04A32` | 可点的动作字 |
| PAPER | `#EDE7D8` | 纸面 |
| PAPER2 | `#F5F0E4` | 卡片面（比纸稍亮） |
| TXT | `#3A322A` | 纸面正文 |
| TXT2 | `#786C5C` | 纸面次要 |

**铁律：亮金只能出现在暗底上。** 纸面上写字用 TXT 或深金 `#9E7B2F`；
纸面上的「金字」做法是**墨字描金边**（draw_string_outline 金 + 填墨），远看才是金字。

## 2. 通用组件

### 2.1 刊头 header（所有面板统一）
- 高 **78**，INK0 底，底部 4px GOLD 线
- 左端 **6×36 朱砂竖条**，距左 26
- 标题：毛笔字（fonts/ink.ttf）36，GOLD_HI
- 右侧关闭：墨方 76×44，切角 6，金边，金 ×

### 2.2 分区标题 sect
- 左端 5×24 朱砂竖条；标题 22px TXT；右侧一条 GOLD 18% 细线拉到右边

### 2.3 卡片 card
- PAPER2 底，切角 10，1px GOLD(37%) 边；内边距 18；卡间距 **12**

### 2.4 按钮 btn
- 普通：INK1 底，2 圆角，1px GOLD(60%)，字 GOLD_HI
- 主按钮：CINN 底 + 金角标，字 `#FFF0D8`
- 按下：下移 2.4px（缓动驱动），松手弹簧回弹
- 禁用：灰底 + 字 30%

### 2.5 徽章 badge
- 红点 6px + 白字 12；呼吸缩放 1.0→1.15（2s 循环）

| 区块 | y 范围 | 要点 |

| 经验条 | 232–250 | 高 18，朱砂填充，内嵌白字 |
| 主按钮 | 366–426 | 升级(朱砂) · 连升 · 突破，各 200×60 |
| 属性 | 444–636 | **两列**，每行 36，标签左/数值右对齐，行间金线 18% |
| 装备 | 656–926 | **2×2 卡**，每卡 320×108：左 80×80 图标框 / 右名称+品阶+主属性 / 右下「卸下」 |
| 武学 | 948–1160 | 一列三行，每行 50；点右侧「改」换功法 |

**为什么这么排**：放置类 90% 时间在看「战力涨没涨」——属性区必须在前两屏内；
装备/武学往下沉；主操作永远朱砂色、固定在拇指区。

## 6. 属性排版

| 层级 | 内容 | 样式 |
|---|---|---|
| 一级 | 攻击/气血/防御/速度 | 32px 金色数字，2×2 |
| 二级 | 暴击/暴伤/命中/闪避 | 22px 纸面正文 |
| 三级 | 加成明细 | 折进「详细属性 ▾」，默认收起 |

- 数值**一律右对齐到同一条竖线**（x=170 / x=494），这是「看着舒服」的核心
- 涨落用颜色不用符号：绿升红降

## 7. 动效（丝滑的硬指标）

| 场景 | 曲线 | 时长 |
|---|---|---|
| 面板打开 | scale 0.96→1 + alpha，TRANS_BACK | 0.18s |
| 面板关闭 | scale 1→0.98 + alpha→0 | 0.12s |
| 悬停抬升 | 指数趋近 y-1.8px | rate 13 |
| 按下 | 阻尼弹簧 y+2.4px | k=420 d=27 |
| 点击涟漪 | 金环 10→74px，alpha→0 | 0.55s |
| 数值变化 | 数字滚动 + 金色闪一下 | 0.35s |
| 红点 | 缩放 1.0→1.15 呼吸 | 2.0s 循环 |

**禁止**任何「瞬间跳变」的可交互元素——必须走 `Ui.ease()` 或 `Ui.spring()`。
