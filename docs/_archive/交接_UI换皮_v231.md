## 三、踩过的坑（v231）

1. 一开始 alpha 0.02~0.045 **肉眼完全看不见**。为了确认是不是层级问题，临时在 `_draw` 里
   铺了一层 25% 红矩形——红能盖住画，说明层级对，纯粹是透明度太低。最后提到 0.10~0.16。
2. 雾要夹在 **画心（-100）与装裱（-40）之间**：放到 0 会盖在牌子上，放到 -100 以下会被画盖掉。
3. 裁切用父级 `Control.clip_contents = true`，不要自己算每条雾的裁剪；否则跨过画心边缘会漏到桌面。
4. 金尘在纸色封面上几乎看不见是正常的；它主要给深色山景用。
