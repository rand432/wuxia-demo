## 三、踩过的坑（v241）

1. 决斗背景是**深色山林**，HUD 不能沿用爬塔的深墨字；皮肤下必须翻成米白，否则名字/血量看不见。
2. `_paint_mode_btn/_paint_speed_btn` 每次切换都会重造 StyleBox——皮肤分支要写在这两个函数里，不能只在建钮时设一次。
3. 直接 `load("res://journey_test.tscn")` 会因 `first_journey_done` 退回主界面；必须先 `GameState.deploy_set` 给出征交接。
4. 探针退出时 Godot 会报 RID/ObjectDB 未释放——战斗节点未等帧释放的旧现象。
