## 〇、一句话现状

- 仓库/背包的格子**长按 0.4 秒**进入批量选择：
  - 被按的那张立刻选中；
  - 每张选中的卡加一道**金边**；
  - 面板底部滑出操作条：「批量选择 · 已选 N 件」＋［全选本页］［清空］［合成所选］［退出］。
- 批量模式下**短按格子 = 勾选/取消**（不再是开详情抽屉）。
- **合成所选**只对"已经凑齐的残卡套"生效：一次把选中的所有成套残卡各合一件，合完自动退出批量并刷新；
  一件都不成套时按钮灰着，点了也只回一句"还没凑齐"。
- 长按判定独立于 `tap_in_scroll`：短按仍是点开抽屉，拖超过 14 像素算滚动、不触发长按；
  长按触发后那一次抬手会被吞掉（不会又开抽屉）。

## 三、踩过的坑（v217）

1. **长按和 `tap_in_scroll` 会打架**：两个 `gui_input` 都挂在格子上。长按在 400ms 触发后，
   抬手时 `tap_in_scroll` 还会调 `_click_cell` —— 所以在 `_click_cell` 第一行吃掉 `_long_fired`，
   并且下一次按下时把它复位。
2. 长按判定要自己记**按下坐标**：`InputEventMouseMotion.button_mask != 0` 且位移 >14 就取消长按，
   否则滑动手势会被误判成批量选择。
3. 空格子不能选：`k >= _stacks_now.size()` 直接 return，不然"已选 N 件"里会混进空格。
4. `refresh()` 必须 `_exit_multi(false)`——页码/整理一变，旧下标就指到别的卡上了。
5. 选中框用**独立 Panel 盖在格子上**（透明底 + 3px 金边），不去改格子的 StyleBox；
   这样 refresh 重算格子样式时不会把选中状态冲掉。
