# 战斗离场与装备刷新审查（2026-11-22）

本轮接续导航和挑战奖励审查，不改变挑战金额、普通战斗奖励、首通奖励或锻造规则。

## 主动退出与结果页切换

实际发现战斗的退出确认和结果页仍直接调用SceneTree切换/重载：重复旧按钮会再次执行切换，主动退出也没有立即设置_run_over或停止核心。在旧场景离树但尚未释放的间隙，奖励和_end_run(true)回调仍可结算。

- 新增audit_battle_navigation，用真实按钮pressed复现，修改前在“abandoned battle must freeze immediately”断言失败，记录`.shots/audit_battle_navigation_before.log`。Godot断言失败仍可能返回退出码0，验证同时检查PASS和SCRIPT ERROR，不将退出码单独当作成功。
- 主动退出采用现有共享导航锁，切换成功后立即设置_run_over并停止核心，旧文钱、灵晶、挑战、击杀和首通回调被拒绝；切换未成功时不冻结战斗。
- 结果页要求当前已结束、有结果窗口、页面仍在树中且未切换；保存恢复失败时不锁页，继续允许点击重试；恢复成功后重开或返回只切一次。旧退出确认不能绕过结果页的保存检查。
- 专项在第六关测试主动放弃、旧按钮连点和迟到奖励不改变进度，损坏的待恢复日志阻止所有离场入口、移除隔离故障日志后重试成功，同关重开后可正常返回主页。故障注入只写隔离目录的reward_pending.cfg，不接触玩家存档。

## 角色页延迟重建

最小场景探针连续安排两次_rebuild再切页，实际记录`[true, false, false]`：首次正常建页后，离树页面又重建了两次。原回调只等待一帧，没有在恢复执行时核对页面归属。

- _rebuild入口和等待后均检查导航状态，同帧请求合并为一次；切页后取消，避免离树后重新加载装备并创建整页节点。
- 等待重建期间不打开装备、锻造或属性窗口，避免新窗口刚创建就随旧页面内容一起删除。
- 重建时清空旧属性窗口引用，重新打开时检查实例有效性；保留原属性数据适配器并按现有流程刷新数值。
- 新增audit_equipment_refresh，真实详情关闭引起重建，再次打开属性页显示已更新的装备数值；重复请求只重建一次，等待期窗口请求无效，切页后不再重建。修改前在同帧合并断言失败；另有最小探针证实离树重建，未将属性窗口缓存写成已复现的崩溃。

## 结果页与教学层归属

第一轮84项完整回归全部通过后，查看实际渲染截图又发现结果页被教学遮罩压暗，右上仍有“跳过”，说明仅测试按钮回调不足以证明界面可用。进一步在headless显式执行迟到教学回调，于“late tutorial must not cover result buttons”断言复现，记录`.shots/audit_battle_tutorial_before.log`。

- 结算和主动离场撤销当前教学；撤销只恢复原处理状态并清空回调，不执行教学目标动作或done信号，不误开下一步或黑市。
- `_tutorial`拒绝已结束、切换中或已离树的战斗页，延迟的开局教学不再盖住结果窗口。
- 扩充audit_tutorial验证重复撤销只恢复一次、不执行完成动作/信号；battle_navigation验证活动教学被结算撤销、旧教学按钮无效，以及结算后迟到教学不能重新打开。
- 图形复测通过、无ERROR/WARNING，已查看更新后的`battle_result_navigation.png`，结果窗口及两个按钮清晰，旧教学遮罩和“跳过”不再显示；`equipment_refresh_attributes.png`显示更新后攻击25及其他属性。截图源于隔离用例，不将“命尽但血条尚满”的强制结算测试画面当作自然战败过程。
