# 世界生成 V0.2 · 设计稿

> 目标：把现在的“单图换种子”改成泰拉瑞亚式世界——生成一次、固定下来；玩家在有限世界里探索、消耗、开区块，榨得差不多再换下一代。
>
> 本稿只定规则，不写代码。

---

## 1. 世界结构

- 一个存档只有一个当前世界。
- 世界生成一次后固定：地块 / 障碍 / 宝箱 / 材料点 / NPC / 怪点 / Boss。
- 同世界反复进图不重掷；没刷出来的 NPC 就是这个世界的。
- 生成新世界时，旧世界整个替换，不保留。

### 区块

初始 3 个区块：

| 区块 | Boss | 基础难度 |
|---|---|---|
| 山 | 山君 | D1 |
| 水 | 夜叉 | D2 |
| 林 | 老妖 | D3 |

后续解锁：

| 区块 | Boss | 基础难度 | 解锁 |
|---|---|---|---|
| 石 | 石傀（新增） | D4 | 2 舆图 |
| 雪 | 雪魈 | D5 | 3 舆图 |

- 世界地图直接列五个区块。
- 未解锁区块显示锁定与舆图价格。
- 解锁是当前世界永久；换世界重置。
- 换世界：1 舆图，旧世界替换。

### Boss

- 每个区块 Boss 固定，不按种子轮换。
- 一世界一次首通：打完就没了，不复活。
- 首杀奖励只拿一次；换世界才重新出现。
- 石傀新增图鉴 / 专属武器；雪魈沿用。

## 2. 世界生成一次

一个世界生成时，按顺序掷：

1. 世界种子（仅决定世界身份）。
2. 五区块是否初始 / 锁定。
3. 每区块：
   - 障碍、宝箱位置、POI、材料点、怪点、精英、Boss 位置。
   - 宝箱品质。
   - 材料点类型。
   - NPC 名册与位置。
4. 势力归属初始状态。
5. 繁荣度 / 世界档从 0 / 1 开始。

生成后写入当前世界数据；再次进入同一区块直接读，不重掷。

### 一次性

以下内容一世界一次，采完 / 开完 / 打完就没：

- 宝箱
- POI
- 材料点
- Boss 首通
- 大部分特殊奖励

换世界才重置。

---

## 3. 食物 = 行动值

不再使用“行动点”，统一为食物。

- 上限：999
- 开局：60
- 食物 0：可以免费回村；不能移动 / 战斗 / 交任务 / 触发 POI。

### 消耗

| 行为 | 食物 |
|---|---|
| 走路 | 每 5 格 -1 |
| 普通事件 / 战斗 | 1~3 |
| 宗门事务 / 演武 | 2~3 |
| 大战 / 决战 | 5 |

### 来源

- 挂机：主来源，低倍率，随挂机档位微涨，不爆炸。
- 爬塔里程碑首通：每 10 层给食物 / 干粮。
- 世界首通：
  - 区块首次清空 +10
  - Boss 首通 +15
  - 新世界第一次进图 +10
- 图内少量：
  - 茶棚热汤 +10
  - 兽肉 +10
  - 灵米 +5
  - 雪洞暖身 +5

### 移除

- 所有“加行动”的任务与奖励。
- 茶 / 上香 / 打水 / 避风等加行动效果改成食物或移除。
- 回村不再自动回满；吃饭 / 住店 / 做饭恢复。

## 4. NPC

### 随机 NPC

- 每世界 0~3 个。
- 行商不保证出现。
- 类型：
  - 行商（跑商）
  - 游医
  - 说书人
  - 落魄剑客
  - 偷儿
- 固定站位，不游荡。
- 不占长线 NPC 名额。

### 长线 NPC

两对，成对强制：

1. 青岚执事 + 听雨楼线人
   - 剧情需要时，两个都刷；只刷到一个就补另一个。
2. 阿石 + 货郎老赵
   - 老赵保持固定货郎 POI；
   - 阿石在剧情需要时强制刷在货郎附近。

- 陈石 + 苏青鸾不接入这套长线随机池。
- 长线 NPC 不占 0~3 随机名额。

---

## 5. 跑商

### 时段

- 晨 → 昼 → 夜 → 晨。
- 每消耗 20 食物推进一段。
- 进图时按当前时段。

### 价格

最终价 = 基础价 × 地区系数 × 时段系数 × 当地声望系数 × 随机浮动（0.9~1.1）

- 地区：山 / 水 / 林 / 石 / 雪。
- 声望：当前区域势力声望 0~100，每点约 0.2%，封顶 20%。
- 时段：夜黑市便宜、明面贵；晨粮食 / 药材便宜。

### 库存

- 货物每时段有限库存。
- 每种货 1~3 件 / 时段。
- 卖完等下一时段补。
- 换世界重置。

### 委托

- 可重复接。
- 首通 / 特殊奖励只给一次。
- 重复委托只给普通报酬。

## 6. 宝箱与材料点

### 宝箱品质

| 品质 | 概率 | 内容 |
|---|---|---|
| 普通 | 70% | 现收益 |
| 精制 | 25% | 材料翻倍 / 多一件杂物 |
| 秘藏 | 5% | 低概率舆图 / 金髓 / 稀有货 |

### 材料点

- 每图 3~6 个，按地脉加权。
- 山：矿 / 兽骨
- 水：草药 / 鱼获
- 林：草药 / 木材
- 石：矿 / 锻造石
- 雪原：草药 / 皮货
- 采集 1 行动，给 1~3 个；采完消失。

---

## 7. 世界繁荣 / 世界档

- 五区块共用。
- 只升不降。
- 换世界 / 新周目清零。

| 世界档 | 繁荣度 |
|---|---|
| 1 | 0 |
| 2 | 30 |
| 3 | 70 |
| 4 | 120 |
| 5 | 180 |

### 来源（一次性）

| 内容 | 分数 |
|---|---|
| 首次锻造出图鉴成品 | +2 / 每种 |
| 首次发现一种 POI | +2 / 每种 |
| 首次 Boss 首杀 | +10 / 每只 |
| 寨务每建一项 | +5 / 每项 |
| 宗门升内门 / 真传 | +5 / +10 |
| 首次拿下一张地图归属 | +3 / 每张 |
| 赤水寨平定 | +20 |
| 北境平定 | +20 |
| 首次完成密信 / 称号 | +5 |

### 难度

区块基础：

| 区块 | 基础 |
|---|---|
| 山 D1 | 1.00 |
| 水 D2 | 1.15 |
| 林 D3 | 1.30 |
| 石 D4 | 1.50 |
| 雪 D5 | 1.75 |

世界成长：

世界成长 = 1 + 0.10 ×（世界档 - 1）
最终强度 = 区块基础 × 世界成长

世界档还影响怪种、精英、宝箱品质、行商货品。

## 8. UI

- 世界地图：五个区块、锁定价格、当前时段、食物、世界档 / 繁荣。
- 进图前显示：区块难度、Boss、当前归属。
- 江湖关系 / 后记：世界档、繁荣、当前世界区块状态。
- 食物显示在探索 HUD；0 时提示回村。

## 9. 落地顺序

1. 世界数据 / 一次性标记 / 重置。
2. 食物替换行动值 + UI。
3. 区块锁定 / 舆图解锁。
4. 随机 NPC + 长线 NPC 对。
5. 商人库存 / 时段 / 价格。
6. 材料点 / 宝箱品质。
7. 繁荣度 / 世界档。
8. 验收：同世界固定、换世界重置、Boss 一世界一次、食物节奏、区块解锁。

## 10. 地图阴影与发现

### 世界地图

- 新世界：整张世界地图全阴影，只显示“未探索”。
- 区块不是选中就亮：
  - 实际进入区块后，累计走过 8 格，区块轮廓 / 名字 / 难度才亮。
- 特殊标记只在到过之后出现：
  - 城镇 / 村落 / 山门 / 赤水寨 / 黑风寨 / 听雨楼 / 雪洞等。
  - 走到 4 格内或触发后才标记。
- 同一世界内，已亮区块 / 已发现标记永久保留。
- 换世界全部重置。

### 行走地图

- 地形 / 道路 / 障碍 / 水面 / 雪地：全亮。
- 不再有“没走过的格子压暗”黑雾。
- 细节 4 格内才显示：
  - 宝箱、POI 图标、怪 / 精英、Boss、NPC、特殊建筑。
- 已发现细节在同一世界内永久显示。
- 换世界重置。

### 没有世界时

- 世界地图是一张全阴影羊皮纸。
- 不显示区块名 / 难度 / 标记。
- 生成世界后仍然全阴影，靠探索点亮。

### 实现要点

- 去掉行走地图的 `_explored` 迷雾遮罩。
- 新增“世界发现”状态：
  - 区块是否亮。
  - 区块内已发现的标记 / 细节。
  - 累计走过的格数（用于 8 格点亮）。
- 世界地图区块级阴影，不做区块内子格。
- 换世界 / 新周目清空发现状态。

### 边界

- 世界地图只到“区块”粒度，不做饥荒式一笔一笔画地图。
- 行走地图地形全亮，只藏细节，不藏地形。
- Boss / 怪靠近才显示，但不隐身，碰撞与战斗照常。

## 12. UI 壳与食物 HUD

### 全局壳

走路图 / 世界地图 / 村里共用同一套：

- 顶部左侧：食物条（饼）。
- 顶部居中：钟表 + 日历。
- 顶部右侧：很小的通缉 / 状态图标，不算按钮。
- 底部五按钮：
  - 角色
  - 背包
  - 地图
  - 记录
  - 退出
- 战斗 / 弹窗 / 面板打开时：底栏与顶部状态隐藏。
- 不再有独立的关系 / 图鉴 / 回村按钮。

### 五个按钮的分工

| 按钮 | 内容 |
|---|---|
| 角色 | 属性、装备、称号、宗门身份 |
| 背包 | 材料、食物、成品、舆图 |
| 地图 | 世界地图、区块选择、回村 |
| 记录 | 江湖关系、图鉴、战报、密信、后记 |
| 退出 | 保存并回主菜单 |

### 钟表日历

- 显示：晨 / 昼 / 夜 + 第 N 天。
- 每消耗 20 食物推进一段：晨 → 昼 → 夜 → 晨。
- 跨过夜后进入下一天。
- 不做月份 / 季节，先保留三段 + 天数。

### 食物 HUD

- 图标：一张饼，随主条减少出现咬痕。
- 0~100：饼逐渐被咬小 / 变缺。
- 超过 100：饼保持完整，外圈加暖金色光。

数值显示：

- 0~100：87 / 100
- 超过 100：237 / 100，下方小字「存粮 +137」
- 总上限 999：存粮最多 899。

消耗顺序：

- 食物 >100：先扣存粮，主条保持满；飘字「-1 存粮」。
- 食物 ≤100：主条和数字一起降；飘字「-1 食物」。
- 吃到 >100：主条先满，多出来的进存粮；飘字「+10 存粮」。

动画：

- 数字滚动，不瞬跳。
- 饼的咬痕 / 金色外圈缓动。
- 扣食物闪暖红；吃东西闪暖黄。
- 走路每 5 格合并成一次 -1，不逐格闪。

### 边界

- 食物条 / 钟表 / 状态图标不是按钮，不参与底栏五键。
- 关系 / 图鉴 / 回村都收进现有五键，不再额外占位。
- 战斗 / 弹窗期间隐藏全局壳，避免压 UI。

## 13. 奖励预算（V0.1）

目标：

- 3 区块世界完整清完约 60 分钟；5 区块约 90~100 分钟。
- 一个世界出 1 把铁砧成品（5 区块 1~2 把）。
- Boss 专属武器不算在“铁砧成品”里。

### 每区块平均产出

按 5 宝箱 / 5 POI / 6 怪 / 1 Boss 估：

| 来源 | 银两 | 锻造石 | 金髓 | 舆图 | 其他 |
|---|---|---|---|---|---|
| Boss 首通 | 100 | 4 | 1 | 1 | 专属武器（独立） |
| 宝箱 ×5 | 50 | 4~5 | 5% 概率 | 5% 概率 | 杂物 |
| POI ×5 | 40 | 2~3 | — | 约 0.5 | 食物 / 材料 |
| 普通怪 / 精英 ×6 | 30 | 2 | — | — | 兽骨 / 皮货 |
| 每区块合计 | 约 220 | 约 13 | 约 1.5 | 约 2 | |

### 世界总产出

| 项目 | 3 区块 | 5 区块 |
|---|---|---|
| 完整时长 | 约 60 分钟 | 约 90~100 分钟 |
| 银两 | 650~700 | 1050~1150 |
| 锻造石 | 38~42 | 62~68 |
| 金髓 | 4~5 | 7~8 |
| 舆图 | 6 | 10 |
| 铁砧成品 | 1 把 | 1~2 把 |
| Boss 专属 | 3 把（独立） | 5 把（独立） |
| 食物消耗 | 180~220 | 300~380 |

### 舆图收支

- 石地 2 + 雪原 3 + 换世界 1 = 6 张。
- 3 区块世界刚好 6 张：开满五区块，就没余量换世界。
- 5 区块世界 10 张：开满 + 换世界后，余 4 张。

### 锻造节奏

- 3 区块约 40 锻造石 / 650 银两：
  - 一把 +20 满锤约 20 石；余 18~22 石，刚够再敲半把或留到下个世界。
  - 想直接做第二把满锤，会明显缺石。
  - 不够把所有胚子都敲一遍。
- 想多做，留到下一个世界，或少升阶。

### 食物

- 战斗 / 宝箱 / POI 只给少量食物。
- 主要来源仍是挂机 / 爬塔里程碑 / 世界首通。
- 3 区块核心内容约消耗 180~220 食物，分 2~3 次玩完。

### 边界

- 这是调参起点，实际以试玩为准。
- 奖励按区块 D 和世界繁荣微调，不再只看旧世界档。
- Boss 一世界一次，奖励给足但不能重复刷。
