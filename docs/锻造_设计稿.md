## 0. 一句话

**选胚、备料、开炉、锤、收手或淬火；每一锤明牌，价值涨、风险涨；停手是本事，贪是赌；成品交单、装备、卖钱或拆料。**

---

## 1. 定位

- 锻造是**稳定产出**：想造什么造什么，上限在锻造。
- 地图掉落是**惊喜**：可能出成品 / 残兵 / 残装 / 图谱，但封顶建议比锻造低半档（待定）。
- 锻造在**村子**，是作坊的核心；地图供料，成品自己用或拿去卖。
- **不做订单、不做配方**：器型自带，材料说话，玩家想打什么打什么。
- 玩家是**铸剑人**；不是点一下等读条，是**一锤一锤敲**。
- 与现有系统关系：
  - 与**器物升星**：锻造出成品，升星吃同名 / 材料；不替代升星台。
  - 与**合成 / 仓库**：残兵 / 残装可合成或拆料；锻造吃料。
  - 与**专武**：专武可由锻造 / 剧情 / 宗门出，具体待定。
  - 与**战斗**：成品兵器 / 装备直接进角色装备栏。

### 1.1 与现有装备系统

- 装备槽沿用：**兵器 / 护甲 / 玉佩 / 披风**；锻造的「器型」只决定它进哪个槽。
- 品阶 / 词缀 / 数值沿用现有装备表：25 兵器、12+3 装备、25 词缀；锻造不另开一套数值。
- 成品可以**升星**（同名 / 材料），升星台照旧；锻造负责「产出胚子」，升星负责「养」。
- 专武 3 部走「特殊器型 + 特殊材料 + 锻造等级 / 宗门 / 剧情」，不靠随机爆；具体待定。
- 装备 UI 沿用角色面板的四个槽；锻造只负责把东西做出来，不重做装备面板。

## 2. 核心循环

~~~text
选图谱/剑胚 → 备料（主料/辅料/助燃/淬火） → 开炉（火候）
     → 锤（明牌概率，价值/风险涨） → 收手/淬火 → 成品
     → 交单 / 装备 / 卖钱 / 拆料 / 升星
     → 村子升级、工具、图谱、下一炉
~~~

- 一次开炉 3~10 分钟；一炉 10~20 锤；可中途收手。
- 玩家每一次都在问：**再一锤，还是收？**

## 3. 一次开炉

### 3.1 备料

| 料 | 作用 | 来源 |
|---|---|---|
| 器型 | 决定品类、基础品阶、可用词缀 | 自带目录 / 锻造等级解锁 |
| 主料（铁 / 寒铁 / 玄铁…） | 决定基础数值、品阶上限 | 地图矿、商人、宗门 |
| 辅料（炭 / 水 / 皮 / 药） | 火候、淬火、握柄、特殊效果 | 地图、村子、商人 |
| 助燃 / 符 | 改概率、防碎、入神、悔锤 | **探索（Boss / 宝箱 / 秘境）、宗门、黑市** |

- **材料主来源是探索**：主料 / 辅料从地图拿；商店只补缺口，价格高。
- **龙鳞、悔锤、定神香这类符，也全从探索来**；锻造只负责用，不负责产。
- 备料界面先给**预估**：可能品阶、大概数值、破碎风险、订单能不能交。
- 材料不够就开不了炉；**不白扣**。

### 3.2 火候（V0.1 不做）

- 本次拍板：**五结果就够了，V0.1 不加火候**。
- 火候留作以后：想加再做 0~100 的火候条；现在只做「备料 → 锤 → 收手」。
- 理由：先把「明牌 + 停手/继续」验爽，别让第二层管理稀释核心。

### 3.3 锤

每一锤明牌，结果五选一：

| 结果 | 效果 | 风险 |
|---|---|---|
| 大成功 | 价值 / 品阶大涨，可能出词缀 | 低 |
| 成功 | 价值 / 品阶涨 | 低 |
| 维持 | 不变 | 无 |
| 损伤 | 价值 / 品阶掉，加裂纹 / 破碎率 | 中 |
| 破坏 | 剑碎，本炉结束，留残料 | 高 |

- **五结果就是全部锤击结果，不加第六种。**
- 概率由：当前价值 / 品阶、工具、材料、匠人等级、入神状态决定；V0.1 先只看价值 / 品阶 + 基础概率。
- **玩家看得到概率**；看不到的是下一锤的命。
- 越往上敲，成功收益越小、破碎率越高——**边际递减**。

建议底表（待调）：

| 阶段 | 大成功 | 成功 | 维持 | 损伤 | 破坏 |
|---|---|---|---|---|---|
| 低（0~3 锤） | 10% | 45% | 25% | 15% | 5% |
| 中（4~7 锤） | 6% | 32% | 28% | 24% | 10% |
| 高（8 锤+） | 3% | 18% | 30% | 34% | 15% |

- 价值：大成功 +2、成功 +1、维持 0、损伤 -1；到 4 / 7 / 10 升品阶；大成功可出词缀。

### 3.4 入神（V0.1 就要）

- 每锤攒「入神」条；**6 格**满（建议值，可调）；满后可以**手动触发**，也可以设置自动。
- 入神期间：**接下来 3 锤不碎、成功 / 大成功率提升**；用完清零。
- **入神不是第六种结果**：五结果不变，它只是把概率往好里推；所以「五结果够了」和「入神要」不冲突。
- 触发方式：
  - **手动**（推荐）：留着，在冲品阶 / 交单前用；玩家自己决定「什么时候搏」。
  - **自动**：满了就进，适合不想管的人。
- 一炉一次；碎了也清零。
- **入神相关的符也从探索来**：定神香（+2 格）、剑胆（入神中大成功↑）、炉心（入神多 1 锤）；具体待定。

### 3.5 收手 / 淬火

- 任何时候可以**收手**：当前价值 / 品阶定稿，不再冒险。
- **淬火**：用水 / 油 / 符锁属性；淬火时机影响词缀 / 数值（待定细化）。
- 成品：品阶、数值、词缀、剑名、价值；可交单 / 装备 / 卖 / 拆 / 升星。

### 3.6 碎了怎么办

- 剑碎：本炉结束；**保留残料 / 残片**（可拆可回炉）；不删档、不扣已有装备。
- 保护手段（建议 1~2 种，不堆）：
  - **护剑符 / 龙鳞**：挡一次破坏；来源：探索（Boss / 宝箱 / 秘境 / NPC）。
  - **悔恨的发条**：撤销上一锤（含碎），一炉一次；来源：探索。
  - **炉运 / 命数**：当天运势，改概率；不保底。
- 碎了不是失败，是**这一炉的账**；材料还在，下一炉再来。

## 4. 工具与成长

### 4.1 工具位

- 建议 4~6 格：**锤 / 砧 / 炉 / 水 / 磨 / 符**。
- 每件工具改一个维度：成功率、大成功率、破碎率、火候上限、词缀倾向、价值倍率。
- 工具可有**词缀**（复用旧 25 词缀）；品阶 / 耐久 / 套装（待定）。
- 工具来源：锻造解锁、宗门、订单、地图稀有、黑市。

### 4.2 炉子 / 村子

- 炉子等级：锤位、工具位、火候上限、可造品阶。
- 村子建设：矿仓、炭窑、水井、磨石、学徒房（待定）。
- 学徒 / 帮手：可自动加炭 / 维持火候 / 递料；不替你决策（待定）。

### 4.3 匠人等级

- 锻造给匠人经验；升级解锁图谱 / 工具位 / 新炉。
- 匠人等级影响：基础成功率、大成功率、破碎率、订单上限。
- 与旧「阅历线」的关系：阅历线改见闻 / 图鉴（游历稿）；匠人另开一条，不混。

### 4.4 器型 / 见识

- 旧 25 兵器 / 12+3 装备 → **器型目录**；不做图谱 / 配方道具。
- 器型靠**锻造等级**解锁；宗门教的是**手法 / 见识**（成功率、词缀倾向），不是配方。
- 高品阶器型要匠人等级 / 炉子等级；玩家想打什么打什么，不用先捡配方。

## 5. 成品

### 5.1 品阶与数值

- 品阶：凡 / 良 / 上 / 极 / 绝（沿用旧口径）。
- 数值：基础攻击 / 防御 / 气血等；品阶越高，成长越高。
- 词缀：旧 25 条；按品阶 / 材料 / 火候 / 工具出；可洗 / 可锁（待定）。
- 剑名：可自定 / 随机；有名剑谱 / 图鉴（待定）。
- 价值：卖价 / 订单估价 / 声望；不是战斗数值。

### 5.2 用途

| 用途 | 给什么 | 代价 |
|---|---|---|
| 装备 | 队伍战力 | 占装备栏 |
| 交单 | 银两 / 声望 / 图谱 / 材料 | 交出去 |
| 卖 | 银两 | 失去成品 |
| 拆 | 材料 / 词缀材料 | 失去成品 |
| 升星 | 同名 / 材料 | 消耗成品 / 材料 |

- 专武：建议走「特殊器型 + 特殊材料 + 锻造等级 / 宗门 / 剧情」；不靠随机爆。

### 5.3 升阶 / 养剑（可碎）

- 升阶不是 100%：**可以碎**。成品多、装备 / 武器给得多，碎了再打一把。
- 触发：**3 星 / 5 星**各一次「回炉」；回炉沿用五结果：
  - **大成功**：品阶 +1，可能多一条词缀；
  - **成功**：品阶 +1；
  - **维持**：不变，材料白花；
  - **损伤**：不变，裂纹 +1 / 下次碎率更高；
  - **破坏**：剑碎，留残料；星数、词缀一起没。
- **保护**：龙鳞 / 护剑符（挡一次）、悔锤（撤销上一锤）、炉运（改概率）——全从探索来。
- **上限由器型潜力定**：凡品器型最高升到良品，良品到上品，绝品不能升；高潜力器型才值得赌。
- 升阶成功保留星数；名字 / 外观升级；NPC 会认。
- 不做「升阶必碎」：是赌，不是送死；玩家可以收手，不带碎。
- **装备 / 武器给多一点**：地图、宝箱、Boss、锻造都多出；碎了不心疼，才有胆赌。

## 6. 成品去哪（不做订单）

- **自己用**：装备给队伍，直接进战斗。
- **卖**：卖给商人 / NPC / 宗门 / 城里的市场；价格看品阶、词缀、名声。
- **拆**：拆回材料 / 词缀材料，回炉或做别的。
- **送**：送礼、还人情、换好感；剑也是关系网里的筹码。
- **不接订单、不刷交期**：锻造的动机是「我要用 / 我要钱 / 我要名」，不是打工。
- 市场有**偏好**（城里要好剑、宗门要礼器、山民要耐用），但不发任务单；玩家自己看行情。

## 8. 第一刀（V0.1）

- 1 座炉子；3 种器型（剑 / 刀 / 枪或剑 / 甲 / 佩），开局就会。
- 3 种主料；3 种辅料。
- **装备 / 武器掉得多**：地图、宝箱、Boss、锻造都多出，碎了再打。
- **10 锤一炉；五结果 + 入神 1 次；V0.1 不做火候 / 工具位**（V0.2 再加）。
- **1 片龙鳞 + 1 支定神香**：从探索里掉，V0.1 就能摸到。
- **不做订单**；成品自己用 / 卖 / 拆。
- 破碎 / 收手 / 淬火 / 成品；装备 / 卖 / 拆。
- 验收：
  - 2 分钟打出一把凡品；5 分钟冲一把良品；能碎一把。
  - 成品能卖 / 能拆；银两 / 声望有变化。
  - 成品能装备、能进战斗。
  - 三个词：有得选（继续 / 收手 / 火候 / 工具）？咬得上（材料 / 订单 / 装备 / 声望）？世界记得（铁匠 / NPC / 订单 / 剑名）？

## 9. 待定与风险

### 待定

- 回合制还是实时：建议**回合制 / 点击**；不做 ForgeTax 的 4 秒实时窗口。
- 火候：V0.1 不做；以后想加再做 0~100 的火候条。
- 入神：V0.1 就要；6 格满、3 锤、手动触发（可开自动）。
- 破坏代价：建议**留残料、不删档**；具体扣多少待定。
- 工具位 4 / 6 / 8；工具耐久 / 套装。
- 专武来路；升星与锻造的接口。
- 升阶：3 星 / 5 星的碎率；保护符；器型潜力；升阶后词缀保不保。
- 无订单：锻造动机靠装备 / 卖钱 / 名声；市场偏好怎么定。
- 器型解锁：锻造等级解锁哪些；宗门教什么。
- 匠人等级与旧阅历线的关系。
- 现有 forge / craft / star 面板的代码入口：施工时对齐；旧 forge_panel 可能已被 UI 改动。
- UI：纸白水墨铁砧面板；等换皮收工。

### 风险

- **UI 换皮进行中**：锻造面板是新 UI，别和换皮撞车。
- **数值**：价值 / 破碎率 / 订单奖励容易崩；先做小范围探针。
- **手感**：明牌概率 + 停手 / 继续是核心；做不出「再一锤」的冲动就白做。
- **旧系统**：升星 / 合成 / 仓库 / 鉴宝都要对接，别做成孤岛。
- **范围**：先 V0.1，不做全套工具 / 宗门 / 订单。
