## 0. 一句话

**选胚、备料、开炉、锤、强化、升阶；五结果明牌，+20 自动升阶；石头管够，材料稀缺，银两只在开炉和升阶收。**

---

## 1. 定位

- 锻造是**装备 / 武器的稳定来源**；地图掉落、商店是补充。
- **四槽**：兵器 / 护甲 / 玉佩 / 披风；锻造全部走**胚子**。
- **不做订单、不做配方、不做残兵残装三合一。**
- **不做装备升星**；旧五星 +20%／星折进强化（B 方案：+2%／级，+20 = +40%）。
- **角色星**（data_stars）是另一条线，不在锻造里。
- **不做专武、不做专属**：所有兵器 / 装备 / 功法都是通用的；谁都能用，只是难拿。
- UI 沿用角色面板四槽；锻造只出成品，不重做装备面板。

---

## 2. 核心循环

~~~text
探索 → 锻造石 / 材料 / 胚子 → 合 / 选胚 → 强化（五结果）
     → +20 自动升阶 → 强化归 0 → 下一轮
     → 成品：装备 / 卖 / 拆 / 送
~~~

- 一炉 10~20 分钟；一轮 20 级。
- 玩家每一锤都在问：**再一锤，还是收？**

## 3. 胚子

### 3.1 两条轴

| 轴 | 定什么 |
|---|---|
| **类型** | 兵器种类（剑 / 刀 / 枪 / 暗器）、甲 / 佩 / 披风；数值偏向、词缀池、升阶路线 |
| **品质** | 起始品阶、潜力上限、基础数值、稀有度 |

- **剑胚就是剑**：强化到 +20、升到什么品阶，还是剑；升阶只加剑的数值和词缀。
- **品质决定能走多远**：凡品胚潜力到良 / 上；绝品胚能摸到顶。
- **类型决定怎么用**：剑走暴击 / 连击，刀走单段 / 破防，枪走贯穿 / 反刺，暗器走绕后 / 毒。

### 3.2 品质与潜力（示意）

| 品质 | 起始 | 潜力上限（示意） |
|---|---|---|
| 凡 | 凡 | +20（良 / 上） |
| 良 | 良 | +30（上 / 极） |
| 上 | 上 | +40（极） |
| 极 | 极 | +50（绝） |
| 绝 | 绝 | +60（绝+） |

### 3.3 五结果性格（示意）

| 胚子 | 性格 | 大成功 | 成功 | 维持 | 损伤 | 破坏 |
|---|---|---|---|---|---|---|
| 青锋剑胚 | 稳 | 8% | 45% | 25% | 17% | 5% |
| 玄铁剑胚 | 赌 | 15% | 30% | 18% | 22% | 15% |
| 竹剑胚 | 便宜 | 3% | 35% | 40% | 17% | 5% |
| 龙鳞剑胚 | 贵 | 20% | 25% | 15% | 25% | 15% |

- 数字只是示意，后面再调；品质越高，整体越偏成功 / 大成功。
- **稳胚**适合冲高强化；**赌胚**适合搏大成功 / 升阶；**便宜胚**练手 / 量产；**贵胚**上限高但碎得也狠。

### 3.4 特殊胚

- **上品剑胚**：打完直接上品，省掉前面几阶；但可能**潜力封顶**，也可能**还能再升**。
- **天生剑胚**：稀有；自带**天生词条**（锋锐 / 不折 / 饮血）或特殊规则（不能升阶 / 强化必成）。
- **高开低走 vs 低开高走**：上品胚现在爽、后面可能没得升；凡品胚现在苦、后面能爬到绝。**选胚就是选路线。**
- **特殊胚来源**：Boss、秘境、宗门、古战场、黑市；有的只此一把，有的有特殊锻造限制。

### 3.5 胚子来源

- **探索**：稀有材料 / Boss / 秘境 / 宗门 / 黑市；好胚稀有、贵；烂胚管够。
- **图鉴合**：石头试组合，合中给图鉴；图鉴消耗材料生成胚子。

## 4. 强化 / 升阶

### 4.1 五结果（只在强化时掷）

| 结果 | 效果 |
|---|---|
| **大成功** | 强化 +2；可能出词缀 |
| **成功** | 强化 +1 |
| **维持** | 不变 |
| **损伤** | 强化 -1；裂纹 +1（下次碎率升） |
| **破坏** | 本炉结束；剑碎；留残料 |

- **五结果就是全部**；**升阶不另掷**。
- 概率由：当前强化、胚子性格、工具 / 符（V0.2）、入神状态。

### 4.2 20 级循环 / 7 锤入神

| 阶段 | 发生什么 |
|---|---|
| 0→10 | 正常强化，五结果 |
| 10 | 入神 10 格满；接下来 **7 锤**：不碎、成功 / 大成功提升 |
| 10→17 | 七锤全成功 = 17；大成功 +2 可提前 |
| 17→20 | **最后 3 锤没保护**，赌升阶 |
| 20 | 自动升阶；品阶 +1；**强化归 0**；进入下一轮 |

- 玩家可随时收手；停在 17 就停在 17，下次再赌。
- 入神**每轮一次**；下一轮 +0→+10 再攒。

### 4.3 升阶数值（B 方案）

- **强化**：+2%／级；+20 = **+40%**。
- **升阶**：品阶基础 **×1.5**；新阶 +0 = 旧阶 +0 的 1.5 倍；旧阶 +20 = 1.4 倍。
- **所以新阶 +0 一定压过旧阶 +20。**
- 旧装备五星 +100% 不再保留，压缩为 +40%（B 的取舍）。
- 例：凡 +20 攻 50 → 升阶 → 良 +0 攻 75（示意；按底子算）。

### 4.4 归 0 范围

- **只归强化等级**；品阶 / 词缀 / 名字保留。
- **裂纹清掉**；新阶新气象。
- 下一轮 +0→+10 再入神，每轮一次。

### 4.5 碎了

- 剑碎：本炉结束；**留残料**；不删档、不扣已有装备。
- 保护：龙鳞 / 护剑符（挡一次）、悔锤（撤销上一锤）、炉运（改概率）——**全从探索来**。
- 不做「碎了补刀」；碎已经是代价。

## 5. 费用与经济

### 5.1 费用

| 节点 | 收什么 |
|---|---|
| **每锤** | 锻造石 ×1（管够） |
| **开炉** | 银两 10~30（或免） |
| **升阶** | 银两 + 稀有材料 |
| **碎了** | 不收费、不修理 |

### 5.2 石头 / 材料

- **锻造石**：图 / 塔 / 宝箱 / 宗门 / Boss 多给；**不能卖银两**。
- **材料**：探索主来源；商店只补缺口、价格高。
- **稀有符**：龙鳞 / 定神香 / 悔锤 / 剑胆 / 炉心——全从探索来。

### 5.3 卖价：银两很稀有

| 品阶 | 参考卖价 | 备注 |
|---|---|---|
| 凡 | 5~10 | 不如拆料 |
| 良 | 20~30 | 勉强回本 |
| 上 | 60~90 | 有人要 |
| 极 | 180~260 | 城里有价 |
| 绝 | 500+ | 名剑，看人 |

- 强化 / 词缀 / 剑名再加价；但**材料成本 + 开炉费**要高于卖价。
- 城里出价高、宗门换人情 / 材料、山民认耐用；商人压价、黑市折价。
- **卖成品不如拆成品**；**锻造吃银两，不产银两。**

## 6. 图鉴 / 合

- **不预设配方**；玩家把石头 / 材料放进炉子试。
- **合中**：图鉴 +1；以后点图鉴，扣材料直接生成胚子。
- **没合中**：只亏石头，材料不动。
- **试错成本 = 石头**（管够）；**正式成本 = 材料**（稀缺）。
- 提示：NPC / 宗门 / 遗迹给方向，不直接给答案。
- 图鉴也是收集：填满一页，比多一把剑更有成就感。

## 7. 装备 / 武器

### 7.1 四槽

- 兵器 / 护甲 / 玉佩 / 披风；胚子决定进哪槽。
- 25 兵器 / 12+3 装备 → **器型目录**；开局会一部分，锻造等级解锁更多。

### 7.2 旧底子（实际 item_stats）

| 槽 | 凡 | 良 | 上起 |
|---|---|---|---|
| **兵器** | 攻 15 · 伤 2 | 攻 24 · 伤 3 | 攻 34 · 伤 4 |
| **护甲** | 气 190 · 防 3 | 气 310 · 防 7 | 更高档 |
| **玉佩** | 暴 2 · 气 64 | 暴 4 · 气 140 · 防 5 | 更高档 |
| **披风** | 闪 9 · 速 3 · 气 30 | 速 7 · 闪 8 · 气 … | 更高档 |

### 7.3 公式

- **成品 = 品阶基础 × (1 + 强化 × 2%)**。
- **升阶**：品阶基础 ×1.5。
- 旧五星 +100% → +40%（B）。
- 新阶 +0（1.5×）> 旧阶 +20（1.4×）。

### 7.4 无专属

- **不做专武 / 专属装备 / 专属功法 / 专属卡**；所有东西都是通用的，谁都能用。
- 稀有度靠品阶、词缀、强化、名字，不靠“只有某人能用”。
- 旧 3 部专武直接移除；想保留名字，可以改成普通高阶器型。

### 7.5 角色星

- **角色星**（data_stars）是角色养成，**不在锻造线**；本稿不碰。

## 8. 2D 第一人称

- **铁砧下半屏**；剑胚横在砧上；锤 / 手从右下入画；炉火在左；背景退后。
- **点砧 / 点锤 = 一锤**；锤声、火星、震屏、剑身晃、结果字、价值条。
- **五结果**：金光 / 白光 / 闷响 / 裂纹 / 碎屑。
- **入神**：泛红金、锤子残影、连敲 7 下。
- **升阶**：剑身亮、名字浮出、品阶变。
- **不做 3D**；第一人称是镜头，不是模型。

## 10. V0.1

- 一张**铁砧屏**；点一锤 = 一锤。
- 2 种类型（剑 / 刀 或 剑 / 甲）；2 档品质；1 个特殊胚（上品青锋）。
- 20 级一炉；入神 7 锤；17 后赌 3 锤；升阶 ×1.5；归 0。
- 锻造石管够；材料稀缺；开炉 / 升阶收费。
- 1 条图鉴；合中给图鉴，图鉴一键造。
- 不做：升星、残卡三合一、订单、配方、火候、工具位、3D。
- 验收：
  - 2 分钟凡品；5 分钟良品；能碎；能升阶。
  - 点得爽、五结果看得懂、入神有爆发。
  - 银两不被刷爆；石头管够。
  - 三个词：有得选？咬得上？世界记得？
