## 二、地图面板细节

- **纸面**：`#e9dfc7` + 暗金 2px 外框 + 1px 内金线；地图视口再加一圈暗金细框。
- **字体**：标题/副题/提示/缩放/「你」全部 `UI_FONT = res://fonts/ink.ttf`。
- **未探索**：铺 `Color(0.075,0.085,0.065)` 暗格，不再纯黑；全图 24×30 格可见，但地形不泄露。
- **图例**：金点地标、棕点宝箱、红点敌人、白圈红心你；颜色与实际画点同源。
- **缩放**：滚轮、双指、图例右侧 −/+ 三套；范围 0.8–3.0×，缩放后 `_clamp_nav()` 夹回边界。
- **返回**：面板［返回］、手机返回/Esc 都只关地图；世界页取消回地图，选区块才重载场景。

## 三、验收方式

```powershell
$godot = 'C:\Users\zq300\Desktop\Godot_v4.7.2-stable_win64.exe'
& $godot --headless --path D:\1\wuxia-demo --check-only --script res://journey/explore/explore_map.gd 2>&1
```

- 地图/面板：SubViewport 720×1280 加载 `explore_map.tscn`，`_open_nav_map()` 后截图。
- 世界页：`_open_world_from_nav()` 后截图；取消走 `_side_panel.close()`。
- 所有会写档的探针：跑前备份 `%APPDATA%\Godot\app_userdata\江湖游历\save.cfg`，跑完还原。
