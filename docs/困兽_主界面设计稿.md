# 困兽 · 主界面设计稿（v2 改版 · 2026-10-09）

> 用户口径（这一轮拍的）：
> · **一局 30 分钟**（"a 30分钟 你看着安排"）· **浴血没问题** · **怪多一点**（"怪你看着来 最好还是多一点"）
>   · "小人可以简笔简约小一点"
> · **战斗里所有按钮都能点，点了战斗照常进行**，点按钮**出弹窗**（"b战斗都可以点 同时战斗还在进行中 点击按钮出弹窗"）
> · **卡池暂定**——先做几张把效果跑起来（"卡池暂定 我回头再出你随便做几个 先实现效果"）
> · **招募队友＝继承成长＋技能，越招越强**（"原先是 1 招募为 3 那么成长提升至 3 再招募一个为 5 那么提升至 5"）
> · **挑战和本波怪并存**（e）
> · **独立存档、暂不和村里流通**；**抽卡要灵晶**；**通关那些货币都会重置**；**货币要加图标**（f）
> · 上一版草图定下的：**独立模式（重做）** · **即时自动战斗** · **竖屏** · 十格卡组 · 三流派 ·
>   事件/宠物/经验条/技能＋/装备＋ · 一阶 boss 倒计时 · 存档/成就

## 一、定稿参数（第一版就按这个做）

| 项 | 定 | 备注 |
|---|---|---|
| 一局时长 | **30 分钟**（1800 秒）| 时间到＝通关（按成绩结算） |
| 波 | **每波 60 秒 × 30 波** | 波是**时间单位**，不是"打完才推进" |
| Boss | **每 5 波一个**（第 5/10/15/20/25/30 波）＝**6 个** | 阶：第 1~2 个＝**一阶**、3~4＝**二阶**、5~6＝**三阶**（血攻递增） |
| Boss 预告 | 到达前 **10 秒** HUD 报 `一阶 boss 还有 xx 秒到达` | 草图上那一行 |
| 事件 | **每 45 秒**触发一次，场上出现六边形「事件」 | 4 秒不点＝替你随机选一个（不卡节奏） |
| 同屏怪 | 上限 **24 只**（常规维持 12~18） | "怪多一点"，但要给手机留活路 |
| 小人 | **简笔**，小怪 **26×30**、主角 **34×40**、宠物 20 | 只画线条＋一两块色，不描边不出图 |
| 队友 | **不出现在动画里** | 只在头像弹窗与数值里体现 |
| 战斗中 | **所有钮都能点，战斗不暂停**，弹窗浮在上面 | 弹窗同一时刻只开一个 |
| 主角倒下 | **浴血**：免死 1 次（回 50% 血 ＋ 成长 +1），再倒＝整局结束 | 沿用上一版 |
| 货币 | **文钱（局内）· 灵晶（局内抽卡）· 名声（局外，结算才给）** | 文钱/灵晶**通关清零**；名声跨局保留 |
| 抽卡 | **20 灵晶 / 次** | 十格满时可"替换其中一张" |
| 存档 | **自己一套** `kushou.cfg`，跟村里 save.cfg 不流通 | 名声只在本模式花 |
| 入口 | 村里加一块木牌（E 键保留做快速试玩） | 待做 |

## 二、一局时间轴（30 分钟长什么样）

| 时间 | 发生什么 |
|---|---|
| 0:00 | 开局：选**流派**（三选一）→ 进场，给 **40 灵晶**（够抽 2 张）＋ 3 张本流派基础卡 |
| 每 60 秒 | 波数 +1；怪的整体强度 +12% 血 / +8% 攻 |
| 每 45 秒 | 场上刷一个「事件」六边形 → 点开三选一（见 §6.3） |
| 第 5 波前 10 秒 | `一阶 boss 还有 10 秒` → 5:00 **一阶 boss** 入场（清场后小怪继续刷） |
| 5:00 / 10:00 / 15:00 / 20:00 / 25:00 / 30:00 | 六个 boss（一阶×2 · 二阶×2 · 三阶×2） |
| 达成条件时 | **招募队友**（见 §6.4）：等级每 +5 触发一次招募机会 |
| 30:00 | 时间到——**通关结算**：按 波数/杀敌/boss/成就 给**名声**，文钱与灵晶清零 |

## 六、战斗与局内系统

### 6.1 战斗（即时自动 · 割草）
- 主角＋宠物在**左三分之一**，怪从**右侧**涌进来（同屏上限 24）；主角**自动普攻最近的怪**，技能按 CD 自动放；
- 伤害＝攻击 × 技能倍率 − 怪防（沿用主游戏那套 `GameData.after_def`，不另造公式）；
- 怪死：飘字 ＋ **掉文钱**（1~3 文；"金币怪"20~60 文）；
- 每只怪头顶一条 4px 血条；主角血条在底部（§3 那张图）；
- **boss 入场**：清掉半屏小怪 → boss 从右侧走进来（体型 ×2.2）＋ 名字条 ＋ `一阶 boss` 标记；
- **演出复用**：`journey/stick_fighter.gd`（火柴人骨骼与挥砍）＋ `journey/actor_factory.gd`（建人）；
  ⚠ 按用户"简笔简约小一点"：**只保留线条与两三个色块**，不做立绘/描边。

### 6.2 卡组（十格 · 三流派）
- **十格**：满格后再抽到 → 进"**替换**"模式（点一张换掉），或选 **保留效果 / 移除格子**；
- **吞噬升星**：抽到**已有同名卡** → 直接吞噬升星（1★→2★→3★→4★→5★，效果按星乘系数），不占新格；
- **三流派**：技能流 / 攻击流 / 盾牌流，开局选一个（本流派卡出现率 ×3）；
- 三个钮：**查询**（看当前十格全部效果合计）· **放弃**（放弃这次三选一，换 **+1 次刷新**）· **刷新**（重摇三张，**5 灵晶**）。

### 6.3 事件（每 45 秒）
场上出现六边形「事件」，点开三选一，**4 秒不点自动随机**（节奏不卡）。事件池第一版 8 条，例：
- `捡到钱袋` 文钱 +150 ／ `灵晶矿` 灵晶 +8 ／ `伤药` 回 30% 血
- `武学残页` 随机一张卡升 1 星 ／ `赌局` 押 100 文，五五开翻倍或没
- `牢友` 招募机会 +1（见 6.4）／ `狱卒巡查` 不掉血但清空半屏怪
- `血祭` 最大生命 −10%，全属性 +15%（一局内可叠）

### 6.4 招募队友（用户口径：**继承成长＋技能，越招越强**）
- **触发**：等级每 **+5** 给一次招募机会（场上出现「牢友」标记，点它招募）；
- **招募＝继承**：把主角的**成长值**直接**提升到队友的成长值**，并把队友的**技能**全部并进来；
  `自己 1 → 招到 3 的队友 → 成长变 3 → 再招到 5 的 → 成长变 5`（用户原话就是这条）；
- 成长值作用：**每级给的全属性加成**按成长值走（成长 3＝每级 +3 攻/+30 血，成长 5＝+5/+50）；
- 队友**不出现在画面里**（草图上那句），只在头像弹窗列出"已继承：××的技能"。

### 6.5 技能 / 装备 / 挑战
- **技能**：开局 1 个主动技（流派定），升级给**技能点** → 升星（1→5 星，消耗 1/2/3/4 点）；
  技能钮右上角有可升时亮 **＋**（草图上那句）；
- **装备·宝物**：一个入口、六个格子（兵器/护甲/玉佩/披风/宝物×2）；来源＝**装备挑战**与 boss 掉落；同一件有品质（凡/良/上/极）；
- **挑战六个**（**与本波怪并存**）：
  | 挑战 | 冷却 | 点了会怎样 |
  |---|---|---|
  | 金币挑战 | 60s | 刷 4 只**金币怪**（掉 30~60 文） |
  | 灵晶挑战 | 90s | 刷 2 只**晶怪**（每只掉 6~10 灵晶） |
  | 装备挑战 | 180s | 刷 1 只**甲士**（必掉一件装备/宝物） |
  | 宝物挑战 | 240s | 刷 1 只**宝箱怪**（掉宝物或大量文钱） |
  | boss 挑战 | 每波 1 次 | 立刻把下一个 boss 提前叫出来（打赢额外名声） |
  | 自动以上挑战 | 开关 | 开了就按冷却**自动**依次刷（挂机向） |

### 6.6 存档 / 成就（局外 · 跨局）
- **名声**＝局外货币，只在 **结算** 时给：`波数×2 ＋ boss×10 ＋ 杀敌/50 ＋ 成就加成`；
- **存档**（商店）：花名声买**永久效果**，第一版 6 条：开局 +20 灵晶／开局带一张指定流派卡／
  主角基础攻 +2／基础血 +40／抽卡 -2 灵晶／事件池多 2 条好事；
- **成就**：每条 = 一个条件 + 一个"下局生效"的小效果（例：`一局杀 500` → 下局开局攻 +3；
  `不用抽卡通关` → 名声 +20%）。第一版 8 条。
