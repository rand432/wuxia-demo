## 3. 外壳 ↔ 战场 的接口

- 外壳持 `_field`（战场实例），通过 `_sync_battle_stats()` 把一切数值塞进 `_field.hero` 字典：
  `atk / hp_max / mp_max / aspd / cut / hp_regen / mp_regen / elem_amp / crit / crit_dmg / lucky /
  dmg_all / cut_all / res_elem / dmg_elem / dmg_true / thorns / cg_*（触发卡开关）`；
- 战场信号：`kill(n)` → 外壳 `_on_kill()`；`coin_drop` / `special` / `chal_drop(kind, at)` /`hero_down`；
- 战场对外函数：`spawn_challenge(kind, n)`（挑战刷怪）、`reset_run()`、`reset_partners()`、`_push_float()`；
- **加新数值的口径**：外壳算好写 `_extra[...]` 或直接写 `_field.hero[...]`，战场只读不推算。

## 5. 踩过的坑（**照抄这些结论，别再踩**）

1. **UI 文本里不要用 `**`**（会被当字面量），不要用嵌套双引号 → 用「」；
2. **GDScript**：`var x := 字典.get(...)` 会因 Variant 报错 → 写 `var x: String = str(...)`；
   不能用带类型的局部变量接**已释放**的实例（弹窗 Label 关了就是 freed）；
   没有隐式换行续行；`match` 分支要缩进；
3. **字典取值一律 `.get(key, 默认)`**：探针塞的手工怪漏键会每帧刷 `Invalid access`（`boss`/`scale` 都栽过）；
4. **`_apply_dmg()` 里元素加成必须放最后乘**：中间每个元素分支都会用 `amount` 重算 `final`，写在前面会被覆盖；
5. **别把函数从 `if` 分支里挪出去**：黑市的［存］［卖］按钮曾画在 `if` 外面 → 跑到宝物页上压住格子；
6. **`_ready()` 是 deferred**：`open()` 里设 `visible=true` 会被它覆盖（用 `_want_open` 标记）；
7. **自动关弹窗的规则要排除「局终」**，否则一死就看不到结算页；
8. **卡 id 的解析**：`card_id(set, part) = set + "_" + part`，取套名走 `str(id.split("_")[0])`
   → **套名里不要再带下划线**（`sayi_0` 曾导致进化完全不触发，改成 `sayi0`）；
9. 加卡/加伙伴/加宝物**都是填数据**（`CARD_SETS`/`CARD_PARTS`/`PARTNER_INFO`/`TREA_POOL`/`BONDS`），
   通用遍历已经写好，别去改循环。
