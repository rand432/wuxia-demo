# 江湖游历

Godot 4.7.2 竖屏放置武侠游戏。主场景 `menu_sketch.tscn`。

## 目录结构

| 目录 | 内容 |
|---|---|
| `menu/` | 主界面、爬塔战斗、各功能面板 |
| `journey/` | 游历玩法（走路 / 节点 / 遭遇 / 结算 / 战斗演出 / 火柴人动画） |
| `shared/` | 数据表与全局状态（卡表 / 词缀 / 状态 / 天赋 / 存档） |
| `kushou/` | 「困兽」独立模式（开发中） |
| `docs/` | 设计文档 |
| `tools/` | 构建与自动化脚本 |

## 版本控制与备份

由 Windows 计划任务 **`wuxia-autocommit`** 每 30 分钟自动执行一次
（脚本 `tools/autocommit.ps1`，任务定义 `tools/autocommit-task.xml`，
日志 `.git/autocommit.log`）：**有改动才提交，没改动不产生空提交**，
然后把提交推送到全部远端。

| 远端 | 位置 | 作用 |
|---|---|---|
| `origin` | Gitee 私有仓库 | 异地备份 |
| `backup` | `E:\wuxia-backup.git` | 本机第二副本（裸仓库） |

手动存档一次：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\1\wuxia-demo\tools\autocommit.ps1
```

## 运行

用 Godot 4.7.2 打开本目录，主场景 `res://menu_sketch.tscn`；竖屏 720×1280。

本机常用命令：

```powershell
& 'C:\Users\zq300\Desktop\Godot_v4.7.2-stable_win64.exe' --path 'D:\1\wuxia-demo'
```

存档：`%APPDATA%\Godot\app_userdata\江湖游历\save.cfg`。

## 当前主循环

进图 → 走路 / 宝箱 / POI / 精英 / 遇敌 → 宗门 / 赤水 / 北境 / 听雨楼 → 回村 → 锻造 → 再进图。

- **世界**：主界面「游历」先开世界窗口；无世界时一键生成，首次默认简单难度。初始山 / 水 / 林，石 / 雪可由一键默认自动加（舆图够就扣）；同世界布局 / NPC / 材料 / 宝箱固定。
- **世界窗口**：进入世界 / 游历记录 / 创建新世界；创建时选难度（首次不显示），旧世界只留一条记录。
- **探索**：五地各有专属 POI（药圃 / 渡口 / 猎户 / 矿洞 / 雪洞）；行走图无雾，地形全亮，细节 4 格内发现；材料点 / 宝箱品质 / 精英词缀 / 通缉捕快。
- **食物**：行动值改名食物，上限 999；每 5 格 -1；时间晨 / 昼 / 夜，每 20 食物推进一段；爬塔 / 追剿清关是主要存粮来路。
- **探险丹药**：气血 / 怒气 / 攻 / 暴击 / 守 / 疾 / 闪 / 暴伤 / 破军，地图上开背包服用；下一场战斗生效；探险不回血，回村才满。
- **怒气丹**：固定满怒气，不分品质；其余战斗丹分凡 / 良 / 上 / 极 / 绝。
- **探险难度**：普通怪 / Boss 常驻气血 ×1.20、攻击 ×1.10，丹药是主要续航。
- **世界难度**：世界生成时定死，之后不再改；简单 / 普通 / 困难 = 资源 ×1.0 / 1.3 / 1.6，首次世界默认简单。
- **货仓 / 宝箱丹药**：都能开出带品质的战斗丹；品质越高，回复 / 怒气 / 攻击加成越高。
- **NPC / 跑商**：每世界 0~3 个随机 NPC（行商 / 游医 / 说书人 / 剑客 / 偷儿），按区块分配；行商与货郎按时段有限库存；价格随区块声望浮动；密信长线 NPC 成对强制。
- **战斗**：火柴人决斗、五区域 Boss（山君 / 夜叉 / 老妖 / 石傀 / 雪魈）、雪魈寒霜 / 冰甲 / 半血狂暴 / 碎裂反击；高周目隐藏 Boss「无相」。
- **新周目事件**：轮回旧梦 → 旧梦余响 → 旧梦终章 → 轮回台无相 → 无相刃 / 破梦人后记。
- **锻造**：五种胚子、锤打、升阶、词缀、图鉴、成品库、Boss / 听雨楼 / 北境专属武器。
- **鉴宝行货仓**：全能来路，含整本功法 / 丹药 / 碎片 / 材料；装备格不出装备，按品质改成锻造材料。
- **爬塔 / 追剿**：功法残页 + 食物存储；首领不出整本、不出装备；追剿 boss 给功法残页。
- **宝箱**：银两 / 锻造石为主；角色碎片、功法残页极低概率；不出装备。
- **游历**：丹药材料 + 装备材料为主；不抢功法 / 碎片 / 整装。
- **宗门**：青岚山门四门考验、杂役、藏经阁、门规、叛门 / 赔礼、演武场。
- **地盘**：赤水寨拔寨 / 归属 / 寨务四建 / 决战 / 平定金；北境黑风寨真实决斗 / 平定 / 哨站 / 驻军 / 哨税；每图势力归属影响货价 / 敌人 / 战利品。
- **社会**：货郎人情价、通缉、黑市、销赃、洗白、牢房、听雨楼名声 / 委托 / 密信。
- **叙事**：听雨楼密信 → 后续场景 → 楼主结局 → 称号 → 江湖后记 → 天下太平。
- **世界繁荣**：首次 Boss / POI / 地图归属 / 平定金涨繁荣，世界档 1~5，换世界清零。
- **UI**：顶部食物 / 时间 / 通缉 / 区块状态；底部角色 / 背包 / 地图 / 记录 / 退出；江湖图为区块节点 + 黑雾 + 已发现地标。
- **新周目**：双平后「再入江湖」；重置世界，保留锻造 / 称号 / 材料；敌人与 Boss ×(1+0.15×周目)；无相为保底可胜版。

## 已知边界

- 尚无真正的多势力地图争夺；两寨火并是选择结算。
- 随机 NPC 现在按世界 0~3 个，但可能全花在前几个区块。
- 江湖图是区块节点图，不是连续大陆 / 羊皮纸一笔一笔探索。
- 无相只有半血狂暴一个阶段，数值是保底可胜版，后续可抬。
- 缺省胜负长战仍需实际试玩调手感。
